# 부산 신고 지도와 분석 결과 — 제출 분석 보관본

기준일: 2026-09-18. 신고기간은 2020~2024년이며 실시간 서비스가 아니다.

이 폴더는 주 분석 P555,786건을 설명하는 별도 제출 분석 보관본이다. 최신 원격 지도·결과·그림 모음 UI는 [`web/final/`](../final/README.md)에 보존한다. 두 웹의 분석 조건과 화면 구성을 구분하며 이 보관본으로 최신 원격 웹을 덮어쓰지 않는다.

## PC에서 열기

Python 3가 필요하다. 프로젝트 루트에서 다음 명령으로 실행한다. 최신 지도와 동시에 열 수 있도록 포트 8766을 사용한다.

```powershell
python web/submission/serve.py --port 8766
```

이 폴더 안에서는 `python serve.py --port 8766`을 실행한다. 기존 `실행.cmd`의 기본 포트는 8765이므로 다른 지도가 실행 중이면 위 명령을 사용한다.

- 부산 지도: http://127.0.0.1:8766/
- 분석 결과·시각화: http://127.0.0.1:8766/analysis/

이 주소는 실행 중인 PC의 로컬 서버다. 인터넷 공개 배포 주소가 아니다. 정적 HTML을 직접 더블클릭하면 시설 JSON과 배경지도에 브라우저 제한이 생길 수 있으므로 HTTP 실행을 사용한다.

## 재현과 검증

아래 코드는 `web/submission/`을 생성·검증한다. 원본·중간 집계·원격 스냅샷을 별도로 갖춘 분석 환경에서만 재실행하며, 웹 열람에는 필요하지 않다. 검증 스크립트 실행 전 이 보관본의 서버를 포트 8766에 띄운다.

```powershell
.venv-check/Scripts/python.exe scripts/build_current_web_20260918.py
.venv-check/Scripts/python.exe scripts/verify_current_web_20260918.py
```

빌드는 검증된 CSV·인구 집계와 보존된 원격 스냅샷을 읽는다. 공개 데이터에는 접수번호·정밀 신고 위치를 넣지 않는다. 기존 검증 기록의 경로는 `data/processed/최신웹연결-20260918/`이며, 원래 실행본에서 PC1920×1080·1600×900·1366×768을 검사한 기록이다. 이번 폴더 분리는 해당 브라우저 검사를 다시 수행한 결과가 아니다.

이 보관본의 두 진입점은 지도와 `analysis/`이며, 최신 원격 웹의 `results/complete/`와 별도로 동작한다.
