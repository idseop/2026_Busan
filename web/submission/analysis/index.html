01 / 분석의 출발점

접수 건수만으로는 지역에 필요한 지원을 정할 수 없습니다.

이 프로젝트는 어느 지역의 어떤 신고가 반복되는지부터 확인합니다. 그 유형을 유지한 채 동 단위로 좁히고, 주민 구성과 실제 운영 중인 서비스를 대조합니다. 소방관서 수가 적다는 사실이나 고령 주민이 많다는 사실을 서비스 부족의 증거로 대신 사용하지 않았습니다.

확인된 결과는 지역 선정과 서비스 연결의 근거입니다. 현재 주민의 미지원이나 제안 시행 후 신고 감소 효과를 확인한 결과는 아닙니다.

02 / 부산 전체에서 우선 볼 지역

5개년 접수 규모는 부산진구 → 해운대구 → 사하구 → 사상구 → 북구 순입니다.

아래 순서는 주 분석 조건의 접수 건수 순서입니다. 코드 순서나 인구 대비 위험 순위가 아닙니다. 각 구의 주요 유형을 같은 유형의 동별 분석으로 연결했습니다.

03 / 같은 유형을 유지하며 동으로 좁히기

규모와 구성비를 함께 보면, 집중할 동과 시간대가 달라집니다.

상위 5개 구에서 주요 3개 유형의 동별 상위 조합 45개를 비교했습니다. 5년 반복성, 한 해 제외 시 순위, 결측 제외·처리 조건에 따른 구성 변화, 시간 패턴을 함께 확인했습니다.

표의 시간은 해당 동명·세부 유형의 5년 합계입니다. 같은 동명에 여러 행정동이 대응하면 신고를 인구 비례로 나누지 않습니다.

04 / 주민 배경에서 별도 보건 근거로

질병 신고의 반복과 교육 참여 지표를 연결했습니다.

인구는 매년 12월 말 주민 구성이며 신고자의 나이가 아닙니다. 동별 주민 배경을 유지하면서, 별도의 2024년 지역사회건강조사로 구 전체의 의료 이용과 질환관리 교육 경험을 확인했습니다. 구의 조사 비율을 동별 질병률로 바꾸지 않았습니다.

사하구 → 다대동

다대동 명칭의 질병 신고는 5년간 4,054건. 사하구의 고혈압·당뇨 교육 경험률은 각각 4.6%·5.5%였습니다.

다대센터와 구의 교육은 이미 운영됩니다. 시설 부재를 주장하기보다 상담에서 기존 교육 참여까지 연결되는 단계를 검토했습니다.

북구 → 금곡동

금곡동 명칭의 질병 신고는 5년간 3,615건. 북구의 고혈압·당뇨 교육 경험률은 각각 4.7%·8.0%였습니다.

금곡센터의 무료 상담·교육과 북구 등록관리를 확인했습니다. 현재 이용자의 실제 교육 연결 누락은 별도 확인이 필요합니다.

교육 경험률은 조사 대상 질환 진단 경험자 등 지표별 분모를 사용합니다. 신고접수 건수와 합산하지 않으며, 조사 비율이 낮다는 사실만으로 서비스 결함을 확정하지 않습니다.

05 / 기존 대응과 연결한 보완 결과

신설보다, 기존 상담에서 교육 완료까지의 연결을 시범 후보로 제시합니다.

입증한 범위 — 지역별 신고·주민·보건 근거와 기존 서비스의 연결, 두 시범 후보의 시행 조건·평가 지표를 정리했습니다. 현재 동별 이용 누락과 119 감소 효과는 아직 입증되지 않았습니다.

부산진구 → 부전동: 부상 1,178건 중 20시–다음 날 08시가 55.09%였습니다. 질병외·부상의 높은 구성비는 비교 조건에서도 유지되지만, 실제 사고 기전과 장소는 미확인입니다. 이 단계에서 교통·음주·낙상으로 원인을 정하거나 특정 시설·인력을 제안하지 않았습니다.

해운대구·사상구: 주민 건강교육과 마을건강센터 운영을 확인했습니다. 접수 규모가 큰 동과 구성비가 일관되게 높은 동을 구분했으며, 개별 동의 서비스 부족은 확정하지 않았습니다.

06 / GitHub 최신 작업과 연결

develop의 지도 개선과 부산진구·중구 비교 결과를 함께 반영했습니다.

develop 222159a의 소방관서 위치·인원·차량 표시, 뒤로가기, 유형 구성 개선을 연결했습니다. 비교 분석 원본 cfbdbe7의 집계·12그림은 develop 4bcb9e3에도 동일하게 공유됐습니다. 이후222159a의 연도 필터 왼쪽 배치·일반지도/접수 비중 조작·간결한 상세 헤더·캐시 방지 설정까지 반영했습니다.

최신 두 구 보고서의 비교 조건에는 벌집제거가 포함됩니다. 아래 표로 현재 주 분석과의 차이를 대조했습니다. 16개 구·군 모두 동일 조건의 기존 집계와 일치했습니다.

develop 통합 분석 원본 PDF · 정책제안 분석 설계 PDF

원본 문서는 해당 조건의 비교·설계 자료입니다. 설계안을 이미 시행한 정책이나 입증된 효과로 표시하지 않습니다.

중구가 원본 표 첫 행에 나온 것은 구·군 코드 순서였습니다. 주 분석 건수는 14,460건으로 16개 구·군 중 16번째입니다. 2024년 말 65세 이상 주민 비중은 32.4%로, 접수 규모와 별개의 주민 배경입니다.

관서의 소재지별 수와 접수 기록의 센터 명칭은 일대일로 같지 않습니다. 지도에는 제공 자료의 관서 위치·인원·차량을 표시하지만, 실제 출동 가용량·도착시간·서비스 부족으로 해석하지 않습니다.
