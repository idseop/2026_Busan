05 · 분석에서 정책으로

기존 서비스를 연결하는 세 가지 정책 후보

분석 기반 시범사업 제안 · 시행 확정 아님

신규 시설·인력 수량을 먼저 정하기보다, 대상과 운영 공백을 확인한 뒤 작은 범위에서 실행·평가할 제안입니다.

제안 01 · 부산진구시범사업 후보

생활권 건강·돌봄 연결

도움이 필요한 주민이 안내에서 멈추지 않고 기존 서비스 이용까지 이어지도록 합니다.

분석 근거

2020–2024년 C 신고 65,302건, 구급 비중 83.7%. 구급 수요를 세분해 검토할 근거이며, 미충족 돌봄 수요를 직접 측정한 결과는 아닙니다.

연결된 분석 그림 →

대상

비식별 구급 세부유형·시간 분석과 기존 사업 이용 현황을 대조해 선정할 생활권. 참여 주민은 본인 동의와 해당 서비스의 자격 확인을 전제로 합니다.

실행 흐름

  1. 구급 세부유형·시간대와 기존 보건·돌봄 사업의 대상·운영시간을 대조합니다.
  2. 지원 필요가 확인된 주민에게 동 행정복지센터 등 협력 창구가 이용 가능한 서비스를 안내·연결합니다.
  3. 연결 후 실제 상담·이용 완료와 연결되지 못한 사유를 확인해 안내와 절차를 보완합니다.

기존 사업과의 차이

새 기관 설치보다 기존 안내·의뢰 절차에서 이용 완료를 확인하는 부분을 우선 검토합니다. 동일한 연계사업이 이미 있다면 별도 사업을 만들지 않고 개선 항목으로 반영합니다.

협력 주체·시행 조건·성과 확인

협력 주체

협의 대상(안): 구 보건소, 동 행정복지센터, 기존 돌봄 수행기관. 소방기관은 적법하게 제공 가능한 비식별 집계의 협의 대상으로 검토합니다.

시행 전 확인

서비스별 자격·시간·정원·대기·실제 이용 자료와 구급 세부유형을 먼저 확인해야 합니다. 공개 신고 집계로 개인 지원 대상을 정하지 않습니다.

어떻게 평가하나요?

동의한 연결 대상 중 상담·이용 완료율, 의뢰부터 첫 이용까지 걸린 시간, 미연결 사유를 기록합니다. 기존 방식의 기준값 또는 유사 생활권과 같은 기간으로 비교합니다.

제안 02 · 중구시범사업 후보

고령층 안부·생활안전 동행

노인 일자리와 기존 돌봄을 연결해 일상적인 안부 확인에서 전문 지원으로 이어지는 접점을 검토합니다.

분석 근거

2024년 65세 이상 주민 비율 32.4%, 5년 C 신고 중 구급 비중 81.7%. 고령 주민의 지원 여건을 살펴볼 근거이며, 고령자의 신고·독거·고독사 위험을 입증한 결과는 아닙니다.

연결된 분석 그림 →

대상

기존 돌봄 담당자가 서비스 이용·중복 여부와 본인 의사를 확인한 고령 주민. 동행 참여자는 해당 일자리 사업의 자격과 업무 적합성을 확인한 뒤 선정합니다.

실행 흐름

  1. 기존 안부·방문 돌봄의 대상·방문 주기·미이용 사유를 확인하고 참여 의사를 묻습니다.
  2. 교육받은 동행 참여자가 정해진 범위에서 안부 확인, 생활안전 안내, 도움 요청 전달을 맡습니다.
  3. 발견한 지원 필요는 전담 보건·복지 담당자에게 연결하고 처리 여부를 회신받습니다. 긴급 상황은 119 등 정해진 연락 절차를 따릅니다.

기존 사업과의 차이

노인 일자리를 단순 방문 횟수 확대가 아니라 기존 돌봄 담당자에게 도움 요청을 전달하는 역할로 설계합니다. 전문 돌봄·의료 판단을 대체하지 않으며 기존 유사사업과 역할 중복을 먼저 확인합니다.

협력 주체·시행 조건·성과 확인

협력 주체

협의 대상(안): 구 노인복지 담당부서, 노인 일자리 수행기관, 보건소, 기존 돌봄 수행기관. 운영 가능 여부와 담당기관은 아직 확정하지 않았습니다.

시행 전 확인

현행 사업의 참여 자격·업무 범위, 감독 인력, 교육·보상·안전 체계와 수요를 확인합니다. 개인정보·방문 동의 절차를 마련한 뒤 시범 여부를 결정합니다.

어떻게 평가하나요?

약속한 안부 확인 이행률, 전문기관 연결 완료율, 연결 소요시간, 이용자 만족과 참여자 업무 부담을 함께 봅니다. 개인정보·안전 문제도 기록해 지속·수정·중단을 판단합니다.

제안 03 · 부산진구·중구시범사업 후보

소방·보건·복지 대응 연결 점검

구 경계와 기관 구분 때문에 놓치는 대응·지원 경로가 있는지 확인하고, 확인된 병목부터 보완합니다.

분석 근거

중구 신고 기록에 서구 소재 부민·충무119안전센터가 나타납니다. 소재지 기준 센터 수만으로 대응 범위를 계산하기 어렵다는 단서이며, 실제 지원 출동을 확인한 결과는 아닙니다.

연결된 분석 그림 →

대상

두 구와 관계 소방기관의 관할·상호지원 및 비응급 보건·복지 연계 절차. 개인별 신고 내역을 공개하지 않고 기관 간 집계와 업무 절차를 검토합니다.

실행 흐름

  1. 분석 시점과 맞는 관할·상호지원, 출동·도착 시각, 교대 가용 인원·차량 자료를 확보합니다.
  2. 시간대·생활권별 도착시간과 업무량, 기관 간 의뢰·회신 절차를 대조해 병목 후보를 확인합니다.
  3. 근거가 확인된 구간부터 연락 창구·의뢰 기준·회신 절차를 시범 정비하고, 시설·인력 확대 필요성은 별도로 판단합니다.

기존 사업과의 차이

센터 수가 적다는 이유로 신설을 제안하는 대신 실제 운영자료로 문제를 좁힙니다. 기존 협약이나 협업 절차가 있다면 미작동·중복 구간을 점검하는 방식으로 보완합니다.

협력 주체·시행 조건·성과 확인

협력 주체

협의 대상(안): 관계 소방기관, 두 구 보건소·복지 담당부서. 자료 제공 범위와 업무 역할 합의가 선행돼야 합니다.

시행 전 확인

출동·도착 로그, 당시 가용량, 도로 통행조건, 기존 협약과 의뢰 처리 자료가 필요합니다. 현재 자료로 센터 부족이나 지연 지역을 확정하지 않습니다.

어떻게 평가하나요?

기관 간 의뢰 회신율·처리시간과 미연결 사유를 비교합니다. 도착시간은 같은 유형·시간·통행 조건에서 중앙값과 상위 지연 구간을 별도 검토하며, 절차 개선의 효과로 바로 단정하지 않습니다.

06 · 단계별 추진 조건

1단계 · 착수 판단

기존 사업과 실제 수요 확인

지원 대상·시간·정원·대기 및 관할·가용량 자료를 확보합니다. 담당기관·자료 범위·동의 절차를 합의하고, 기존 사업으로 해결할 수 있는 부분을 먼저 정리합니다.

2단계 · 제한된 시범

대상과 업무 범위를 명시

시범 생활권·참여 규모·기간·예산·담당 역할을 협의해 정합니다. 시작 전에 비교 기준과 중단 조건을 정하고, 참여자 부담과 안전 문제를 함께 기록합니다.

3단계 · 유지·수정·확대 판단

연결 완료와 이용 결과 평가

기존 방식 또는 유사 생활권과 같은 기간으로 비교합니다. 신고 감소를 곧바로 성공으로 보지 않고 이용 완료·소요시간·미연결 사유를 확인해 다음 단계를 결정합니다.

자료와 해석 기준

상세 근거는 한곳에서 확인할 수 있습니다

자료 범위·선택 영향

원신고 4,552,768행 중 부산 명시·선택 17개 완전기재 A 704,689행, 정상 처리 B 579,412행, 업무성 기록 제외 C 574,662행입니다. 결측 제외에 따른 접수경로·지역 구성 변화가 있어 전체 신고의 대표성을 보장하지 않습니다.

신고 지역명, 주민 행정동, 상권 법정동과 현재 경계의 단위를 구분합니다. 신고 건수는 사건·환자·출동 건수가 아닙니다.
