이번 확장에서는 194개 지역명·5개 유형, 2024년 시점 분리 점검, 지도 내부의 근거 연결과 실제 2D/3D 구현을 추가했다. 19~23절은 새 작업이며 앞선 자료와 지역별 근거를 삭제하지 않았다.

이 문서는 핵심 결론, 기초·보조자료, 실행한 분석, 지역별 근거, 기존 대응, 보완 결과, 검증과 재현 방법을 한 파일에 담는다. 기존 13개 그림 위주의 요약에서 빠졌던 상권·생활인구·주택·시설·후속 사업 결과를 통합하고, 상권 20분기와 생활인구 시계열을 추가 분석했다. 과거 판단을 수정한 근거와 아직 확정할 수 없는 현장 판단도 함께 기록한다.

최종 전달은 ① 전체 분석·시각화 묶음 ② 부산 지도 웹서비스 ③ 이 단일 MD 보고서의 세 가지다. 화면을 통과하는 것과 지역의 정책 효과를 입증하는 것은 다른 완료 기준이다.

1. 문제제기: 왜 이 분석을 했는가

지역별 신고 건수만으로는 무엇을 예방하고 어떤 지원을 연결해야 하는지 결정할 수 없다. 같은 신고 지역명 안에서도 주민 구성·낮과 밤의 활동·주거형태가 다르며, 과거 현장 문제를 조사한 뒤 이미 정비나 지원이 이뤄졌을 수 있다. 신고 양상만 보고 시설·인력을 추가하면 실제 원인과 맞지 않거나 이미 수행한 대응을 다시 제안할 수 있다.

소방청 2025년 자체평가 결과보고서(2026년 1월, PDF10쪽)는 분석·시각화의 현장업무 연계와 활용·환류 보완을 제시한다. 같은 보고서는 분석 제공과 정책 활용도 기록한다. 따라서 정부가 분석이나 예방을 전혀 하지 않았다는 전제는 사용하지 않았다. 국가 평가에서 제시한 활용 과제를 부산의 공개자료와 지역 탐색 시제품으로 구체화한 것이다.

또한 공식 급성심장정지 조사에서 부산의 기록된 일반인 CPR 시행률은 2021년 20.8%에서 2024년 13.8%로 낮아졌다. 주민 조사에서는 교육·마네킹 실습·AED 실습의 경험률이 다르게 나타났다. 이는 교육과 실제 실습·이용조건을 나누어 검토할 배경이다. 특정 동의 교육 부족이 CPR 저하를 일으켰다는 인과를 입증한 것은 아니다.

핵심 목적은 반복 신고를 지역 배경과 기존 대응에 연결해, 근거가 있는 예방·지원 정보와 보완 범위를 구체화하는 것이다. 정부가 보지 못한 공백이라는 결론을 먼저 정하지 않고, 공식 자료가 이미 확인한 문제·이미 수행한 조치·아직 연결되지 않은 근거를 분리했다.

공식 배경: 소방청 자체평가, 질병관리청 급성심장정지 통계.

2. 부산 전체에서 지역으로 좁힌 분석 흐름

부산 전체 신고 → 연도·유형·시간·선택 영향 → 지역별 반복과 주민 연령 구성 → 소수 사례 및 비교 사례 → 필요한 상권·생활인구·주택·현장 근거 → 기존 시설·서비스·사업 상태 → 확인된 보완 → 시각화와 웹 결과.

지역이나 해결책을 먼저 정하지 않았다. 벌집제거는 전체 신고 검산 외의 집중 검토·보완 후보에서 제외한다. 신고접수, 실제 사건, 출동, 환자, 주민, 방문 추정값, 업소, 주택, 점검표 행은 각각 다른 단위다. 서로 합쳐 임의 종합점수나 위험 순위를 만들지 않는다.

6. 상권과 생활인구를 더 깊게 분석한 결과

상권·생활인구 시계열 확장 결과

새로 확인한 내용

보유한 상권2020~2024년20분기 전체를 읽어 부산,16구·군,파일에 등장하는 모든 법정동의 업소 수와 대분류 구성을 계산했다. 법정동별 업종 비중은 같은 분기의 소속 구와 부산 비중에 비교했다. 동일 분기의 전년 비교와 같은 해 분기별 구성비 범위도 제공한다.

이번 입력20개에서 실제 관측된 대·중분류 코드·명칭 사전은 모두 동일했다. 초기 과거ZIP은 중첩ZIP이고 일부ZIP파일명은CP437/CP949해석이 필요했다. 내부 부산CSV까지 찾아 현재CSV와SHA256이 일치함을 검증했다. 따라서 파일 밖의 분류 개편을 임의로 적용하지 않았다. 다만 관측 사전이 같다고 실제 과거 분류제도와 등록범위가 불변이었다는 뜻은 아니다. 코드를 다른 분류에 강제 매핑하지 않았다.

19. 실제 구현한 부산 2D·3D 지도

부산 전체를 읽는 기본 화면은 2D로 유지하고 확대 지역에서 3D를 선택하도록 구현했다. MapLibre 단일 카메라로 배경·경계·지명을 함께 움직인다. 3D 전환, 기울기, 좌우 회전, 북쪽 정렬, 부산 전체 및 선택 지역 보기가 작동한다. 지도와 검색 목록·연도·종별·처리조건·상세 선택을 유지한다. 인구의 필터 기준과 고정 5년 심층 분석은 각각 표시한다.

높이를 임의로 만드는 대신 OpenStreetMap의 명시적 height가 있는 닫힌 건물 way를 확보했다. 부산 범위에서 원자료1,092개 중1,081개를 채택하고11개는 부산 도형에 완전히 포함되지 않아 제외했다. 건물 폴리곤 전체가 부산 도형에 포함되는지 확인했다. 타일의 render_height, 층수 배수, 기본 높이를 사실 높이로 바꾸지 않았다. OSM에 기재된 높이는 독립 실측 정확성을 보증하지 않는다. 관계형 건물·부분 건물·높이 없는 건물은 입체 자료 범위에 들어가지 않는다.

건물은 지역을 이해하는 배경이며 과거 신고를 해당 건물에 배정하지 않았다. 신고 값으로 건물 높이를 변경하지 않았고 사람·차량의 가짜 이동도 추가하지 않았다. 산악 지역에 DEM 고도를 적용한 것은 아니다. 산악 3D 화면은 지도를 기울인 화면이며 산의 실제 높이 모델로 소개하지 않는다.

건물 획득과 OSM 기준 시각은 map/building-manifest.json에 보존한다. OpenFreeMap/OpenMapTiles/OpenStreetMap 및 SGIS 출처와 각 라이선스를 유지한다. 외부 타일은 화면에 필요한 범위만 요청하며 ZIP에 수집·재배포하지 않는다. 건물 파생자료의 ODbL 출처는 따로 명시한다. API 키는 필요하지 않다. 외부 연결 실패·WebGL 미지원은 대체 표시와 상태 안내로 처리한다.

3D를 전 지역 기본값으로 삼지 않은 이유는 부산 전체 경계·비교를 먼저 읽고, 건물 배경이 필요한 확대 단계에서 공간을 살펴보도록 하기 위해서다. 3D 자체가 신고 위치를 정확하게 만들거나 사고 위험을 입증하는 것은 아니다. 혁신의 범위는 지역별 근거와 공간 탐색을 같은 지도에서 조작하도록 연결한 실제 기능에 있다.

순서대로 읽고 필요한 곳까지 들어가는 지역 상세

지역 결과는 ①신고 특징 → ②주민·지역 배경 → ③기존 대응 → ④보완 결과의 네 단계다. 단계 버튼과 이전·다음으로 이동하며, 전체 흐름과 현재 단계를 함께 표시한다. 첫 단계는 유형 구성·5년 변화·시간 패턴, 두 번째는 후보별 주민·생활·주택·상권, 세 번째는 실제 서비스 조건·운영 시점·출처, 네 번째는 근거가 있는 보완 내용을 제공한다. 근거가 없는 지역에는 확정한 보완안이 없다는 상태를 표시한다. 내용을 확인하기 위해 지도 아래로 긴 페이지를 내려가지 않도록 상세 패널 안에서 읽는다. 전체 연령·세부 업종·시간표는 각 단계의 ‘지역 상세 자료 보기’에서 같은 지역·유형·C조건으로 이어진다. 새 탭으로 열어 지도 탐색 상태를 유지한다.

지도에는 선택한 구·군의 작은 핀 하나를 표시한다. 주민 후보를 고른 뒤 ‘배경 위치 보기’를 명시적으로 누른 경우에만 해당 후보의 공식 대표 위치로 이동한다. 대표 위치는 SGIS 2025-06-30 경계에서 구한 내부 점이며 개별 신고 위치나 과거 신고의 행정동 배정을 뜻하지 않는다. 구·군과 동명이 유일하게 대응하는 경우에만 허용하고, 복수·불일치 대응을 임의로 추정하지 않는다. 다른 지역·후보 선택, 상세 닫기와 초기화에서는 이전 핀을 정리한다. 단계 이동 자체로 지도 위치를 계속 바꾸지 않는다.

21. 실제 영향은 어디까지 입증했는가

이번 연구의 필요성은 반복 신고의 규모만이 아니라 지역 배경과 운영 조건이 서로 다른 자료에 흩어져 있고, 과거 최고 시기나 사업 완료를 잘못 해석할 수 있다는 데 있다. 공식 소방청 평가의 현장 활용 과제, 부산 CPR·주민 조사, 현장 조사와 현재 사업 상태가 각각 그 문제의 서로 다른 근거다. 기존 정부 업무가 없었다거나 모든 주민에게 실제 이용 장벽이 발생했다고 주장하지 않는다.

웹의 작동, 사람의 이해, 실제 참여, 피해 변화는 다른 결과다. 자동 브라우저로 검증할 수 있는 것은 기능과 표시 정확성이다. 사람들이 더 잘 이해하거나 더 빨리 신청한다는 효과에는 참가자 관측이 필요하고, 사고 감소에는 사건·현장·대조군·시간 교란을 고려한 설계가 필요하다.

건강정보의 구조를 바꾼 원 무작위 실험은215명을 분석했지만 지식 향상의 직접 차이(P=.36)와 전체 만족도(P=.07)가 통계적으로 유의하다고 확인되지 않았다. 이는 우리 화면에 효과가 없다는 증거도 아니고 효과가 있다는 증거도 아니다. 화면 구성만으로 이해도 개선을 당연시하지 않도록 하는 반대 근거다. 원 논문 · 정보구조 체계 검토 · 온라인 건강정보 역량 중재 검토

다음 효과 실험의 구체적 설계

동일한 정보량과 최신 기준일을 가진 링크 목록과 지도 결과 화면을 비교한다. 참가자에게 기간이 지난 점검 공고, 교육용/실제 AED, 이미 완료된 정비, 복수 주민 후보를 포함한 과제를 제공한다. 무작위 순서 또는 순서를 균형 배정하고, 정답률·잘못된 신청 가능 판단·필수조건 누락·완료 시간·내용 이해를 측정한다. 디지털 숙련도와 중도 포기를 기록한다. 표본 규모는 사전 효과크기 가정과 검정력으로 정하며 임의 성공 기준을 결과 후에 바꾸지 않는다.

동의를 얻은 후 실제 안내 클릭→신청→참여와 기관의 신청·대기·취소 자료를 연결하면 이용 효과를 검토할 수 있다. CPR 실기와 유지율, 보행환경 개선, 화재·수난 결과는 다른 측정이므로 웹 클릭으로 대신하지 않는다. 이번 작업에는 참가자 모집·기관 연락·현장 중재를 수행하지 않았다.

23. 최종 전달과 완료 범위

최종 전달은 전체 분석·시각화 ZIP, 2D/3D 지도 웹 ZIP, 이 단일 MD 보고서다. 이전 ZIP은 비교 기록으로 보존하며 최신본과 이름을 구분한다. 지도 웹은 압축을 푼 뒤 Python3 환경에서 실행.cmd 또는 python serve.py로 연다. 결과·그림·표·지역 상세는 파일 직접 실행을 지원하며 배경 타일은 인터넷이 필요하다. WebGL 미지원·네트워크 실패의 대체 표시도 검사한다.

이번에 완성한 것은 검증된 선택 신고의 지역별 특성, 전지역 배경 연결, 과거 특성의 이후 기간 대조, 기존 대응을 반영한 예방 안내, 실제 2D/3D 탐색과 지도 내부 근거 연결이다. 실제 대응 부족·정책 최적 배치·시민 효과·피해 감소를 모두 해결한 사업으로 표현하지 않는다. 확보하지 못한 현장 자료와 각 효과의 다음 측정 방법까지 같은 문서에서 이어서 확인할 수 있다.
