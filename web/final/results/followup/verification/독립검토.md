# 후속 입증 분석 독립 검토

검토일 2026-09-16. 작성자 코드의 결과를 그대로 재사용하는 검사와 구분하여, 원 전처리 gzip 5개에서 지역·유형·시간 집계를 별도 코드로 재계산했다. 이 검토자가 작성한 `outdoor/`는 독립 검증 대상에서 제외했다.

## 부산 전체 신고 후속 분석

`verify_followup.py`: 43,944개 검사 통과. 입력 해시, 연도, 704,689개 선택 신고와 A/B/C 처리조건 합계, 관측된 지역명 194개 × 5유형 × 3조건 2,910행을 확인했다. 선택 이전 비교 집합은 기존 적합성 CSV의 해시와 연도별 값을 대조했으며 원 신고와 혼합하지 않았다.

지역별 연도·월·요일·시간·지역 내 비중을 다시 계산했다. C조건 연도×요일×시간 교차표 34,377행은 41,720건이며 전체 인덱스와 건수까지 일치했다. 반복·증감 방향이 세 조건 모두 유지되는 325조합과 최소 연도 건수1·5·10·20별 민감도도 독립 계산과 일치한다. 기본 기준의 비교 가능한322조합 중144조합은 앞·뒤 기간 주말/평일 일평균 비율이1을 가로지른다. 0.9·1.1은 통계적 유의성이나 정책 선정선이 아니다.

고층건물 분류는 기장읍56·온천동76건이며 연도별 값과 선택 전후 증감 방향을 별도로 확인했다. 기장읍은 선택 전후 방향이 반대다. 해당 분류에는 3층 이상 건물이 포함되어 아파트만의 신고로 해석하지 않는다. 포털 등록 특정 건물에 배정하지 않았다.

14개 현장점검 지점 중11곳의 신고지역명 대응은 공식 법정동 후보 이름의 배경 비교로만 구성했다. 해당 지점의 실제 신고 건수로 배정하거나 복수 후보를 합산한 코드가 없다.

## 주택 배경과 공식 교통 후속 근거

`verify_supplemental.py`: 11,622개 검사 통과. SGIS 원 ZIP과 내부 파일 해시, 부산 원 공표값·비공표 셀, 지역별 공표 합계를 독립 확인한다. 2024 통계와2025-06-30 경계는 별도 시점이며206행정동 자료를 과거 신고의 확정 배정으로 사용하지 않는다. 주택이외 거처는 주택총계에 더하지 않는다.

BDI 원 PDF67·70쪽을 직접 열었다. 4개 지역20개 구간, 총5,113.4m, 보차분리12·미분리8 구간과 지역별 표 수치는 추출본과 일치한다. 30대 여성 조사원이 노인체험복을 착용한 관찰이며 실제 고령자 모집단의 평균 속도가 아니다. 속도표의 신평 외부도로1구간 제외와2024 관찰 시점이 명시돼 있다. 못골시장2025 사업 완료 및2026 효과평가 후 상태로 사용할 수 없다.

남포사거리 자동 주정차 CCTV의09~21시와11:30~14시 단속 유예는 공식 운영표와 일치한다. 긴급 대응 공백을 의미하지 않는다. 거제천로101~121 펜스200경간 제안과3740만원 위원회 삭감은 회의록과 일치하나2023 현장점검 항목의 취소·현재 미설치를 입증하지 않는다. 14지점 단기122·중장기19 항목을 현재 미해결 수로 집계하지 않았다.

## 현재 시설점검·서비스 자료

원 HWP4개를 독립 해제·추출하여 행번호와 판정·비고를 대조했다. Windows 저장 과정의 빈줄 차이를 제외한 본문은 일치한다. 조사표132행 중131행 판정, 불량이 하나라도 기록된19행이다. 기장6불량행은 현지시정이 함께 기재돼 있고, 금정3·부산진10행의 비고 공란은 미시정 증거가 아니다. 동래 학교명 중복·부산진 동일주소 표기 때문에 고유시설 수로 표현하지 않는다. 일부 조사대상 선정 결과로 소방서별 위험률을 비교할 수 없다.

AED 대여는 기장 공식 페이지에서 실제 장비와 교육용 대여를 구분했다. 최대2주(공휴일 포함), 방문수령·장비 점검 절차는 확인되지만 실제 대여·사용실패 실적은 확보하지 않았다. 부산시 AED 원문은 일부 설치정보와 행정시스템 불일치를 인정하지만 불량대수·구별 미이용 환자수를 제공하지 않는다. 계획상의 취약가구 지원수를 보급 완료수나 잔여 미지원수로 바꾸지 않았다.

## 상권 후속 분석과 통합 보고서 검토

`verify_commerce.py`: 2,349개 검사 통과. 2024년 네 분기 원 CSV를 원 배포 ZIP의 부산 멤버와 해시 대조하고, 업소 ID 유일성·필수값 제외·16개 구군 코드·법정동 코드를 확인했다. 부산·구군·4개 동 대분류와 중분류별 건수·구성비·동과 부산 간 퍼센트포인트 차이를 별도 계산했다. 2024년 9월 말 부산 143,964업소, 부전동 6,216·대연동 4,314·광안동 3,203·신평동 1,081업소가 일치한다. 분기 합산으로 고유업소 수를 만들지 않았으며 시장 반경이나 방문량을 추정하지 않았다.

상권 그림 `commerce_four_area_context.png`를 직접 열어 10개 분류·100% 축·개별 분모·범례를 확인했다. 과거 파일 분류개편 시점 설명은 별도 지적했다. 보유 2022년 12월 파일이 이미 새 10대분류이므로 ‘2020~2022 / 2023 이후’라는 단순 구분은 부정확하다. 작성자가 코드·JSON을 ‘파일별 분류·목록 범위의 시점 차이를 확인해야 하므로 장기 추세 제외’로 수정했다. 이번 2024 집계 자체에는 영향이 없다.

통합 보고서·문제제기 문서·탐색기 작성 코드를 별도 읽었다. 사고접수, 상가목록, 조사표 행, 체험복 실험, 소방서 점검, 계획 및 준공은 서로 다른 단위로 유지된다. 시민 미충족 수요·부족 인력·피해 감소를 확정하지 않으며 현재 미조치와 기록 미확보를 구분한다. 재현 명령에서 services `analyze`·`report` 누락과 출처등록부의 상권·서비스 누락을 지적했고 수정됐다. 생활인구 최종 통합까지 포함한 `verify_delivery.py`의 1,125개 검사가 통과했다. 205개 생활인구 프로파일 전체가 원 집계와 동일하게 전달되며, 신고조건·주민연도와 별도로 2024년 후보를 각각 표시한다. 결과는 `delivery-independent.json`에 기록한다. 이 검사는 브라우저 조작을 대신하지 않는다.

## 생활인구 추가 검토

`verify_living.py`: 1,049개 검사 통과. 보유 XLSX 두 개와 해시를 대조하고, 2024년 시간 59,040행·연령 14,760행의 모든 선택 원값을 공개 전처리표와 대조했다. 205동의 12기준월 동일가중 평균, 세 유형 각각의 00시·12시 비율·최대시간, 월별 정오/자정 대소관계를 독립 계산했다. 기존 검증 dashboard 해시와 후보코드를 확인했고 복수 동은 각각 유지된다. 세 유형·24시간 합계나 시간×연령 추정값은 생성하지 않았다.

`living_hour_context.png`를 직접 열어 여섯 행정동의 개별 곡선과 상이한 세로축 범위가 명시되는지 확인했다. 기준월과 실제 관측월의 완전 일치를 주장하지 않으며, 방문인구를 등산객·관광객·신고대상 인구로 바꾸지 않는다. 부전1·2동의 정점 14시·19시와 정오/자정 비율 3.33·1.35는 원값과 일치한다. 보조자료 선택판단 문서에서 이 분석의 채택 목적, 보유 2023~2025 중 2024 선택, 비채택 시간×연령 교차를 구분한 설명도 검토했다.

메타 JSON에 없던 ‘주거지·직장지 동일 시 주거로 분류’ 정의는 공식 시간자료 HTML의 데이터 한계 항목에 있는 것을 확인했다. 작성자가 해당 원문을 보존하고 해시·출처를 추가했으며, 별도 `living-definition-review.json`에 확인 기록을 남겼다. 운송·택배 등 오래 체류하지 않는 직업군의 직장 분류 제외 가능성도 명시됐다.

공식 주소·명칭이 연결된 조사표는 6행·5개 동명이다. 기장읍 1행은 아난티 공식 사업장 목록의 ‘아난티 앳 부산 코브 / 기장읍 기장해안로 268-32’와 조사표 대상·주소가 일치한다. 인접한 268-31 사업장과 구분했다. 이 호텔의 점검 결과를 과거 일반주택 신고나 기장읍 전체 시설로 일반화하지 않는다.

## 그림 검토

교통 신규 그림 `field_study_experiment.png`, `field_study_road_conditions.png`, `traffic_followup_all14.png`와 서비스 신규 그림 `current-fire-inspection.png`, `current-service-evidence.png`도 직접 열었다. 노인체험복 조사원의 관측, 2024년 시점, 신평 1구간 제외가 표시돼 있다. 14지점 표는 현재 미개선 건수를 주장하지 않는다. 소방 점검의 132행·131판정·19불량 표기는 원표와 일치하며 현지시정과 비고 공란을 구분한다. 2026년 가구 지원은 계획으로 표시하며 완료 실적으로 계산하지 않는다.

신규 `district_type_composition.png`, `time_strategy_sensitivity.png`, `building_fire_selection.png`를 직접 열어 한글·축·분모·범례를 확인했다. 구군 열지도는 선택 신고 전체를 분모로 유지하고 표시5유형만100%로 재정규화하지 않는다. 매우 작은 비중은0.00%로 반올림돼도 실제 건수가 함께 표시된다. 시간 민감도 차트의144/322 등 분모는 기준별로 달라지며 표기와 일치한다. 고층건물 차트는 두 비교 집합과 동일 축을 유지한다. 이 기록은 현장 사고·시설 상태의 직접 조사나 별도 브라우저 실행 증거가 아니다.
