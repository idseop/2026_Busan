# 고도화 선택영향·현재 대응 독립 검토

2026-09-16. 이번 검토자의 작성 범위인 `traffic/`는 아래 독립 검증에서 제외했다. 교통 출처는 다른 작성자가 아닌 별도 검토자가 확인한다.

## 신고 선택 영향

`../verify_selection.py`의 68,082개 검사와 `../verify_selection_tvd.py`의 12,984개 검사가 통과했다. 기존 입력 10개 gzip의 SHA256을 확인했으며, 기초8·완전17의 2020년과2024년 네 파일은 청크별로 직접 읽어 같은 지역·유형·처리조건·채널·요일·시간의 전체 교차값을 새로 계산했다. 작성자 교차표와 동일하다.

중간 2021~2023 원접수→교차는 이번 독립 검사에서 새로 계산하지 않았다. 기존 검증과 입력 해시를 재사용하고, 5년 전체 출력교차→달력 일수·주말비율·주간비중·24시간 TVD·같은 이동전화 비교·2024−2020 가산분해를 별도 계산했다. 검증 범위를 원본5년 전수 재검사로 확대 보고하지 않는다.

기존325개 반복 유지 조합에서 동일 이동전화의 선택 전후 주말비율이1을 가로지르는 조합33개, 0.9와1.1을 넘어 달라지는2개가 맞는다. 매년 최소5건 조건에서는 후자가0개다. 이 결과는 이전 ‘기간 전반부/후반부’ 시간변화144개와 다른 비교다. 둘을 같은 민감도 수치로 합치지 않는다. 0.9·1.1은 유의성 기준이나 정책 선정선이 아니다.

신규 `same_mobile_weekend.png`와 `channel_decomposition.png`를 실제 열어 축·범례·기간·분모를 확인했다. 전자는 지역명×유형 조합, 후자는 선택 전 기초8 접수의 경로 구성이다. 다른 채널 제외와 이동전화 내부 제외가 구분돼 있으며 인과 분해·현재 위험 순위를 주장하지 않는다.

## 공개 조치 검색 및 AED 지침

`../verify_response.py` 57개 검사 통과. 2026년3월 보건복지부 AED 제8판 원 HWPX의 ZIP/XML을 별도로 읽었다. 유효기간 초과·좌표 미설정의 외부표출 제한, 장비 접근·사용 가능 시간, 장비 교체 후 월점검 정보 수정 경로가 실제 원문에 있다. 배포처 대덕구의 실적을 부산 실적으로 사용하지 않았고 전국 관리기준만 채택했다.

기존 조사표 해시 및19불량행·6현지시정행은 일치한다. 3개 소방서×4개 키워드의 공식 게시판 본문 검색 결과수와9/1~9/16 기간을 원 HTML과 대조했다. 검색한 첨부 전체나 비공개 조치대장까지 확인했다고 주장하지 않는다. 새 후속 연결0건은 실제시정0건·미조치19건의 증거가 아니다.

사상구 기존 안내표지판 안내와 부산 전통시장 AED 업무협약은 원 게시문에 있는 것을 확인했다. 안내 자체가 존재함을 보여줄 뿐, 개별시설 설치완료나 실제 접근을 보증하지 않는다. 공개된 E-GEN 등록목록은 전체 등록장비의 무작위표본으로 간주할 수 없으며, 표출기준 때문에 표본 밖의 장비가 남을 수 있다. 부산의 누락대수·장비고장률·환자 미이용을 새로 추정하지 않았다.

검토 결과는 JSON에 남겼으며 실제 브라우저·이용자 테스트나 기관 현장 확인을 대신하지 않는다.
