# 최종 연결 화면 독립 브라우저 검증

실행: `python data/processed/최종마감-20260916/verification/check_browser_final.py`

Chrome에서 실제 실행한 221개 확인 항목이 모두 통과했다. 상세 결과·검사별 판정·대상 파일 SHA256은 `browser-final.json`에 있다. 이번 검증은 최신 화면 연결과 이미 검증한 웹 집계의 일관성을 확인했으며, 원본 신고 전수 재집계를 반복한 검사는 아니다.

- PC 1920×1080, 1600×900, 1366×768에서 최종 허브·그림 모음·보고서·지도를 열고 가로 넘침을 검사했다.
- 지도 9개 사례 선택이 정확한 구·지역명·유형·C 조건 쿼리로 연결되고, 별도 2020~2024년 분석임을 표시하는지 확인했다.
- 실제 연도 버튼을 눌러 연산동 구급 2024년 4,645건을 웹의 검증 집계와 대조했다. 단일 연도 선택 강조 및 aria-pressed 상태를 확인했다.
- 지도 확대·전체 보기, 연산 주민 후보 8개와 후보 변경, 존재하지 않는 검색어의 빈 목록을 확인했다.
- 그림 13개를 각각 Enter로 열고 실제 이미지 로딩을 확인했다. Escape 닫기와 원래 버튼으로 초점 복귀, 그림 분류 필터를 확인했다.
- `file://` 직접 실행과 새 허브·갤러리·보고서·검증 페이지의 로컬 링크를 확인했다. JavaScript 예외는 없었다.

실제 캡처 중 `final-index-1600.png`, `final-map-1366.png`, `final-gallery-1366.png`, `final-report-1366.png`, `final-map-selected-1600.png`를 열어 글자·배치·선택 표시를 직접 확인했다. 마지막 선택 화면에서는 ‘2024’만 강조된다. 초기 즉시 캡처에 연도 전환 중 색상이 함께 보였으므로 최종 캡처는 전환이 끝난 뒤 저장했다. 이후 작성자가 연도 버튼 전환 효과를 제거한 수정도 재실행해 즉시 상태 일치와 최신 CSS 해시를 확인했다. 도로 지도를 새로 추가하거나 실제 신고 위치를 새로 배정한 작업은 없다.

그림 목록·설명의 원저작 검토는 별도 작성·검증 담당의 근거를 사용한다. 이번 검사는 링크·화면·조작 검증이며 실제 주민 이용 효과, 서비스 부족 또는 사고 감소를 입증하지 않는다. 외부 공식 사이트의 전수 현재 접속 가능 여부도 이번 범위에 포함하지 않았다.

미완료 항목: 없음. 변경된 웹 파일은 검사 JSON에 해시를 기록했다. 파일이 이후 달라지면 해당 변경을 다시 확인해야 한다.


최종 상태 안내 갱신 후 검증 페이지를 다시 열어 내용 90개·브라우저 221개 통과 표시와 두 JSON 기록을 확인했다. 기존 링크 검사 범위의 재확인이므로 221개 검사 수는 그대로 유지했다. 해당 페이지 해시를 갱신하고 1600×900 첫 화면 전용 캡처를 저장했다.
