# 부산 신고 지도 · 2D/3D와 지역별 근거

2026-09-17 확장: MapLibre 단일 카메라의 2D·3D 전환, 회전·북쪽 정렬, 명시적 OSM 높이가 있는 건물1,081개를 추가했다. 높이는 독립 실측 값이 아니며 신고가 발생한 건물 표시가 아니다. 높이 없는 건물은 평면 배경으로 남는다. 산의 DEM 고도는 적용하지 않았다. 확대13단계 이상에서 건물 입체를 볼 수 있다.

지도 오른쪽 ‘지역 결과’에서194개 지역명·5개 유형의 특성, 주민·생활·상권·주택 배경과9개 사례의 대응·보완을 확인한다. 해당 심층 분석은2020~2024 전체·정상 처리·업무성 기록 제외의 고정 기준이며 지도 상단 필터와 별도로 표시한다. 기존 상세 페이지의 전체 연령·시간·업종도 유지한다. 전체 통합 결과는48그림·73집계표·23절 단일보고서로 갱신했다.

지역 결과는 ‘신고 특징 → 주민·지역 배경 → 기존 대응 → 보완 결과’를 단계 버튼과 이전·다음으로 읽는다. 주민 후보의 ‘배경 위치 보기’는 SGIS 2025-06-30 경계의 대표 위치로 이동한다. 과거 신고 지점이 아니며, 위치가 확정되지 않은 신고 동은 소속 구·군만 강조한다. 다른 지역·후보 선택 또는 초기화 시 이전 위치 표시를 정리한다.

2026-09-16 갱신. 부산만 탐색하며 산림·수역·해안·시가지·도로 형태를 유지한다. 도로명·시설명·큰 숫자 기호는 숨긴다. 현재 경계를 과거 신고의 정확한 위치나 면적별 위험도처럼 표현하지 않는다.

## PC 실행

`실행.cmd` 실행 후 http://127.0.0.1:8765/ . 별도 ZIP 실행에는 Python 3 필요. 다른 환경은 `python serve.py` 또는 `python serve.py --port 8766`. 서버는 로컬 127.0.0.1에만 연결한다.

전체 결과는 http://127.0.0.1:8765/results/complete/ 에서 읽는다. 전체 시각화48종, 집계표73개, 상세 단일보고서, 지역별 분석이 연결돼 있다. 기존 results/final의 결과·그림·보고서 주소는 이 최신 결과로 이동한다.

상세 지리 배경에는 인터넷이 필요하다. 연결 실패 또는 파일 직접 열기에서는 지역 경계와 기존 분석 결과를 계속 제공하고 배경 로딩 상태를 표시한다. 실시간 재난 서비스가 아니다.

## 화면 읽기

- 지도 주제: 지형·지역 / 신고 분포 / 심층 분석 지역.
- 신고 분포는 선택한 조건의 부산 신고 중 각 구·군 이름별 접수 비중이다. 위험도나 주민당 발생률이 아니다. 합계 0이면 자료 없음을 표시한다.
- 심층 분석 지역은 고정된 9개 지역·유형 사례를 검토한 구·군 안내다. 현재 연도나 종별의 위험 순위가 아니다.
- 왼쪽 심층 분석 버튼은 해당 지역과 종별을 선택한다. 연도·처리조건은 유지한다.
- 모든 지역의 오른쪽 패널에서 ‘지역 분석 전체 보기’로 이동할 수 있다. 이 별도 화면은2020~2024년 전체와 예방 관련5유형을 다루며, 지도에서 보던 연도·종별을 그대로 적용한 값으로 표시하지 않는다. 9개 심층 사례는 유형까지 지정한 바로가기를 제공한다.
- 지역 상세는 신고와 주민 외에20분기 상권, 생활인구2023~2024비교 및2025별도, 주택·AED·현재 대응을 연결한다. 자료가 연결되는 지역과 기준일은 각 결과에 표시한다.
- 상세 첫 화면은 선택 지역과 나머지 부산의 유형 구성비·시간대를 비교하고 반복성·주민·기존 서비스·보완안 상태를 연결한다.
- 구·군·동 지명은 SGIS 2025-06-30 지도 안내용이다. 현재 206개 읍면동과 과거 인구 자료 205개 동을 강제 결합하지 않는다. 원문 동 검색 결과의 지도 강조는 소속 구·군까지다.
