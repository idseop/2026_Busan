# 동을 클릭해 신고 특성과 정책 후보를 살펴보는 단일 웹페이지

> 2026-09-14 사용자 구체화 반영. 화면·정책 검토 설계이며 실제 관측 결과나 구현 완료 화면이 아니다.
> 현행 분석 기준: `docs/30-아이디어/신고데이터-정책제안-실행계획.md`.

## 핵심 사용자 흐름

**부산 전체 행정동 지도 → 동 클릭 → 신고 유형·시간·계절 특성 → 인구 연령 구성·상권/현장 특성 비교 → 근거와 추가 확인 항목이 있는 정책 후보**.

한 페이지 안에서 지도를 유지하고 선택한 동의 상세 패널을 갱신한다. 별도 사이트나 페이지로 이동하지 않고 두 분석 축을 함께 볼 수 있게 한다.

```text
[자료 기준기간·출처·확보 상태] [기간] [신고 유형] [지도 지표]
┌ 부산 전체 행정동 지도 ───────┬ 선택한 동의 상세 정보 ──────┐
│ 동 선택·선택 해제            │ ① 어떤 신고가 많은가       │
│ 지표 범례·결측 구분          │ ② 언제 집중되는가          │
│ 전체 보기로 복귀             │ ③ 어떤 연령 구성이 있는가  │
│                             │ ④ 어떤 상권·현장이 있는가  │
│                             │ ⑤ 어떤 정책을 검토할까     │
└─────────────────────────────┴────────────────────────────┘
[결합·제외 기록, 해석 한계, 정책 근거와 추가 자료]
```

작은 화면에서는 지도 아래에 같은 순서의 상세 패널을 둔다. 동을 선택하지 않았을 때는 부산 전체 현황과 선택 안내를 보여준다. 자료가 없으면 해당 구역에 미확보/미검증을 표시하고 가짜 결과로 채우지 않는다.

## 동 상세에서 보여줄 정보

| 순서 | 질문 | 표시 내용 | 해석·상호작용 |
|---|---|---|---|
| 1 | 어떤 신고가 많은 동인가? | 구급·구조·화재 등 실제 유형별 건수와 구성비, 관측기간 | ‘많음’은 건수·구성비·부산 전체 대비 차이 중 어떤 기준인지 명시. 구조가 많은 동이라는 이유만으로 아동 사건으로 이름 붙이지 않음 |
| 2 | 언제 집중되는가? | 시간대·요일·월·계절별 분포와 누락 기간 | 유형 선택과 함께 갱신. 연간 주기와 반복 관측이 부족하면 관측기간의 차이로 표현 |
| 3 | 어떤 인구가 거주하는가? | 동별 연령 구간별 인구수·비율, 기준일, 전체 인구 | 신고와 별도 출처로 계산. 연령·기간 필터로 존재하지 않는 대상별 신고를 생성하지 않음 |
| 4 | 어떤 상권·현장 특성이 있는가? | 업종별 점포수·구성비·기준일, 확인된 건설현장 위치·공사기간 | 상권과 건설현장은 구분. 선택 지역·기간의 실제 자료만 표시 |
| 5 | 어떤 정책을 검토할까? | 관측 근거, 검토 가설, 필요한 추가 근거, 정책 후보, 담당 업무, 평가 방법 | 데이터 부족 시 검토 가설로 표시. 소방 신고를 근거 없이 경찰 순찰 업무로 연결하지 않음 |

지도 기본 지표는 선택 기간의 신고 건수로 하고 구성비·적절한 분모를 가진 보정 지표는 구분해 선택한다. 동의 유형별 구성비를 비교할 때 부산 기준은 해당 범위 건수 합으로 계산하고 동별 비율을 단순 평균하지 않는다. 분모가 0이면 비율을 만들지 않는다.

신고 필터는 신고 집계만 바꾼다. 인구·상권은 실제로 선택 가능한 스냅샷의 기준시점을 따로 표시한다. 신고에 연령이 없다면 인구 연령대를 클릭해 신고가 연령별로 필터링되는 UI를 만들지 않는다.

## 사용자가 제시한 정책 연결 사례: 검증할 가설

아래는 관측 결과나 확정 권고가 아니다. 실제 신고 분류·업무 근거를 확인한 뒤 채택 여부를 정한다. 데이터가 가설을 뒷받침하지 않으면 후보를 보류한다.

| 함께 확인할 지역 특성 | 정책 검토 방향 | 연결을 위해 추가로 필요한 근거 | 단정하지 않을 내용 |
|---|---|---|---|
| 구급 신고 부담 + 고령인구수·비율 | 안부 확인·생활지원·고립 예방 관련 기존 사업 보완 검토 | 구급 세부 유형·대상 연령 집계가 가능한지, 독거·고립 관련 공식 집계, 기존 서비스 범위·업무 | 고령인구가 구급 신고 당사자라는 결론, 구급 신고만으로 고독사 위험 판정 |
| 위의 지원 필요성이 확인된 지역 + 적합한 활동 | 노인일자리 사업과의 연계 가능성 검토 | 사업의 실제 허용 업무·참여 조건·교육·감독·가용 인력, 기존 사업과 중복 여부 | 신고가 많으면 노인일자리가 필요하다는 자동 결론, 참여자에게 응급대응 임무 부여 |
| 구조 신고 부담 + 아동인구수·비율 | 아동 이용공간의 안전 점검·교육·환경 개선 검토 | 구조 세부 유형·장소·시간, 실제 아동 관련성, 이용시설·학교 주변 자료와 업무 근거 | 구조 신고가 아동에게 발생했다는 결론, 모든 구조를 어린이 위험으로 표현 |
| 건설현장 주변의 화재 신고 | 현장 화재예방 점검·장비 접근성·추가 설치 필요성 검토 | 운영 중인 현장 위치·공사기간, 화재 실제 장소·원인, 기존 장비·접근성·관리 주체·설치 기준 | 주변 신고를 현장 화재로 확정, 현장 자료 없이 상가 업종만으로 건설현장 판정 |
| 주점 비중이 높은 상권 + 구조·구급 신고의 시간대 집중 | 상권 안전 안내·예방활동·취약시간대 순찰 등 후보 검토 | 실제 신고 세부 유형·음주 관련성 확인 가능 여부, 유동인구, 기존 활동, 기관별 담당 업무·조정 가능 시간 | 주점이 신고를 유발한다는 인과 결론, 소방 수요 증가만으로 경찰 순찰 효과 확정 |

**인구·상권은 정책을 검토할 지역 맥락이다. 신고 당사자를 식별하는 대체 변수가 아니다.** ‘구급이 많으므로 노인이 많다’가 아니라 신고와 인구를 각각 확인하고 두 특성이 함께 관측되는지 비교한다. 대상 관련성이 부족하면 대상 특화 정책을 확정하지 않고 지역 일반 안전정책 후보 또는 추가 조사 과제로 남긴다.

## 정책 카드 표시 규칙

각 카드에 다음 항목을 둔다.

- 확인된 사실: 실제 신고·인구·상권 지표, 비교 기준·기간·출처.
- 검토 가설: 두 지역 특성이 정책 검토에 관련될 수 있는 이유. 미확인 관계는 명시.
- 추가 확인: 사건 세부 분류·대상·기존 서비스·시설·담당 업무 등 부족한 자료.
- 정책 후보: 대상·지역·시기·활동. 인력·시설 추가는 실행 조건 확인 후 구체화.
- 상태: 추가 확인 필요 / 근거 확인 후 검토 가능 / 근거 부족으로 보류. 자동 효과 보증이나 추천 점수로 표시하지 않음.
- 평가 계획: 정책 시행 전에는 평가 방법으로 표시하고, 실제 효과와 구분.

정책 후보는 검증된 분석 결과와 공식 업무·사업 근거를 연결해 작성한다. 웹은 검토 근거를 보여주는 도구이며 임의 수치·가중치로 확정 정책을 자동 생성하지 않는다.

## 데이터 실사 우선 확인

사용자가 **‘부산소방재난본부 신고 접수 현황 엑셀 파일에 지역 위경도가 있다’**고 설명했다. 파일명·공식 출처·전체 원본·실제 컬럼은 아직 직접 확인하지 않았다. 기존 구급출동 상품과 같은 자료라고 가정하지 않는다.

원본에서 다음을 확인한다.

1. 위경도가 실제 사건 발생지인지, 신고자 위치·접수 기관·대표 좌표인지. 좌표계·결측·반복 대표좌표·부산 밖 좌표를 검사한다.
2. 발생일시가 있는지, 접수시각만 있는지. 접수시각만 있으면 ‘접수 시간 특성’으로 명시하며 발생 시간으로 바꾸지 않는다.
3. 구급·구조·화재를 구분할 실제 유형 컬럼·코드북, 세부 유형과 중복 신고 처리 기준.
4. 부산 전역 포함·기간 누락·전체 행 수와 원본/집계 건수 일치.
5. 공간 매칭 후 행정동별 집계가 가능한지, 인구·상권과 기준시점을 맞출 수 있는지.
6. 사건 좌표의 이용·공개 조건. 공개 지도에는 동별 집계를 기본으로 사용한다.

건설현장은 일반 상가 자료의 필수 컬럼으로 가정하지 않는다. 해당 사례를 분석하려면 위치·공사기간이 있는 별도 공식 자료가 필요하다. 이를 확보하지 못해도 동별 업종 구성에 기반한 상권 축은 별도로 진행할 수 있다.

## 구현 완료 판단

- 부산 전체 → 동 선택 → 신고·시기·인구·상권·정책 패널이 같은 선택 지역을 가리킨다.
- 기간·유형을 바꿀 때 신고 집계·범례·비교 기준이 일관되게 갱신된다.
- 인구와 상권의 독립 기준일이 드러나고 없는 연령별 신고 필터가 없다.
- 결측·0·미확보가 구분되며 부분 확보를 부산 전역 결과로 표현하지 않는다.
- 정책 카드의 관측 사실·가설·추가 확인·평가 계획을 구분한다.
- 원시 사건 좌표·신고 내용이 공개 파일에 포함되지 않는다.
