# 현재 결과 웹페이지

현재 주제는 「부산 동별 119 신고 특성에 따른 맞춤형 예방안 제안」이며 분석 기간은 2020~2024년이다.

**현재 진입점은 [final/index.html](final/index.html)이다.** 파일을 브라우저로 열면 동작하도록 데이터와 지도를 함께 제공한다. 실행·재생성 방법은 [final/README.md](final/README.md)를 따른다.

`final/`은 검증된 17개 완전행의 집계·전체 연령 인구·선택 영향·동 대응·기존 서비스 근거만 포함한다. 이 폴더 바깥의 옛 시제품 `index.html`, `assets/`, `data/`는 현재 입력·웹 결과·배포 묶음에 사용하지 않는다. 원본이나 기존 작업 파일을 확인 없이 삭제하지 않았다.
