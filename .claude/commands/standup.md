1. 가상환경 Python(`.venv/bin/python`, Windows `.venv/Scripts/python.exe`)으로 `scripts/check_harness.py`를 실행하고 결함부터 보고한다.
2. 실제 오늘 날짜와 `docs/00-공모요강.md`의 일정을 대조한다. 고정된 D-day 문구를 재사용하지 않는다.
3. `docs/30-아이디어/신고데이터-정책제안-실행계획.md`에서 현행 주제와 두 분석 축을 읽는다.
4. `data/raw/`의 00_경계·01_신고·02_연령인구·03_상권·04_정책자원 실물과 카탈로그를 함께 확인한다. 카탈로그가 없다는 이유만으로 원본 0건을 단정하지 않는다. 파일은 있는데 미등재면 결함으로 보고한다.
5. analysis·notebooks·figures의 00_공통·01_신고시공간·02_연령연계·03_상권연계·04_정책제안·05_검증과 web·보고서의 실제 진척을 확인한다.
6. 출력: 오늘·일정 / 주제 확정과 실사 상태 / 축별 진행·조건부·보류 / 확보 증거와 품질 / 다음 작업과 완료 기준.

동별 연령은 신고 당사자의 연령이 아니다. 새 원본 확보와 기존 후보 발견을 구분하고, 문서 갱신을 분석 완료로 보고하지 않는다.
