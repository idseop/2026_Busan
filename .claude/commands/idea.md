부산 현안에서 Track 1 출품 아이디어를 만들고 채점한다.

**대상: $ARGUMENTS** (비어 있으면 전 영역 — 인구·고령화·청년유출 / 관광·상권·소상공인 / 교통·이동·주차 / 안전·재난·기후 / 주거·도시재생 / 복지·의료 / 해양·항만 을 고루 훑는다)

## 절차

> ⚠️ **주제는 이미 확정됐다**(`docs/30-아이디어/SHORTLIST.md`).
> 이 커맨드는 **데이터 실사에서 NO가 나서 주제를 다시 잡아야 할 때만** 쓴다.

1. `docs/20-데이터카탈로그/INDEX.md`가 있으면 먼저 읽어라 — **실사로 확인된 데이터만이 출발점이다.**
2. 아이디어를 **6~10개** 만들어라. 각각 아래 형식으로.
3. 채점하고 상위 3개를 `docs/30-아이디어/SHORTLIST.md`에 갱신 저장하라.

## 아이디어 형식

```
### <제목 — 결론이 드러나게>
- 분석 질문: (1~3개, 구체적으로)
- 필요 데이터: (데이터셋명 + 예상 소스. 없으면 "미확인"이라 쓴다)
- 핵심 시각화: 어떤 그림이 나오는가 (한 문장)
- 정책 제안: 결과가 어떤 의사결정으로 이어지는가
- 부산 고유성: 왜 다른 도시가 아닌 부산인가
```

## 채점 (각 5점)

| 항목 | 기준 |
|---|---|
| 데이터 실현성 | 실제로 받을 수 있고 입도가 맞는가 (**가중치 ×2 — 1순위 탈락 사유**) |
| 부산 고유성 | 전국 일반론이 아닌가 |
| 시각화 잠재력 | 그림이 눈에 그려지는가 |
| 제안 구체성 | 행정이 집행 가능한가 |
| 차별성 | 남들이 뻔하게 낼 주제가 아닌가 |
| 후원사 적합 | 부울경 광역 이슈(경남연구원) 또는 외국인·다문화·관광(부산외대)에 닿는가 |

## 규칙

- **데이터 실현성이 낮으면 아무리 멋져도 버린다.** 미련 갖지 않는다.
- "뻔한 주제"를 정직하게 표시하라. 고령화·관광객 수 같은 건 출품이 몰린다.
- 채점은 후하게 주지 않는다. 5점은 정말 뛰어날 때만.
- 마지막에 **"다음으로 `/datacheck`할 아이디어 1~3개"**를 지목하라. 실사 없이는 확정하지 않는다.
