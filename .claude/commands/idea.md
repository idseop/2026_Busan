대상: $ARGUMENTS

먼저 `docs/30-아이디어/신고데이터-정책제안-실행계획.md`와 실제 카탈로그를 읽는다.
현행 주제는 사용자 결정으로 확정했다. 기본 작업은 신고 시공간 × 연령 구성, 상권 × 신고 특성의 두 축을 구체화하는 것이다.

- 질문 → 실제 확보 데이터 → 비교단위·방법 → 시각화 → 정책 판단 → 검증을 연결한다.
- 데이터 제약은 축별로 판단하고 가능한 대체 집계와 보류 범위를 명시한다.
- 동별 연령을 개인 연령으로, 상권 인접을 업소 사건으로, 상관을 원인으로 해석하지 않는다.
- 인력 배치·동선·예측은 요청과 자료가 있을 때 별도로 검토한다.
- 주제 변경 요청이 없으면 과거 관광·의료·폭염 주제로 자동 전환하거나 SHORTLIST를 덮어쓰지 않는다.

출력은 질문 / 데이터 증거·부족 항목 / 분석·지도 / 정책 결정 / 완료 기준 표로 간결하게 작성한다.
