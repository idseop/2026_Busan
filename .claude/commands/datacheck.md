대상: $ARGUMENTS

1. `docs/30-아이디어/신고데이터-정책제안-실행계획.md`와 `busan-data` 스킬을 읽는다.
2. 인자가 없으면 **01_신고 → 00_경계 → 02_연령인구·03_상권 → 04_정책자원** 중 미실사 자료를 확인한다. 신고의 위경도·발생일시·유형·부산 전역 포함 여부가 우선이다.
3. 자료의 제목·소개문·컬럼 확인·전체 원본 확보·품질 검증을 구분한다. 실제 파일 전체의 행 수·기간·결측·중복·좌표계·지역코드·컬럼 의미·공개 조건을 기록한다.
4. 새 원본은 해당 `data/raw/` 도메인에 저장하고 기존 원본을 덮어쓰지 않는다. 실제 최초 확보 시 `docs/20-데이터카탈로그/INDEX.md`를 만든다. 후보·요청 중 자료를 확보 완료로 등재하지 않는다.
5. 카탈로그에는 자료명 / 출처 URL / 파일·원본 해시 / 다운로드일 / 기간 / 공간·시간·개체 단위 / 실제 컬럼 / 전체 행 수 / 품질 / 결합 키 / 이용·공개 조건 / 축별 판정을 기록한다. 기존 기록은 보존하고 변경 이유·재검증일을 남긴다.
6. 축 1과 축 2를 각각 **진행 / 조건부 / 보류**로 판정한다. 진행은 필수 원본·품질·결합 기준을 실제 확인했을 때만 가능하다. 조건부는 부족한 항목과 해결 경로·미허용 산출물을 명시하고, 보류는 필요한 추가 원본 또는 가능한 축소 분석을 제시한다.

연령이 없어도 지역의 연령인구와 비교할 수 있으나 개인 연령을 추정하지 않는다. 위경도 없는 공식 동별 집계는 대안으로 명시하고 점 위치가 있는 것처럼 표시하지 않는다. 신고 총건수를 연령비율로 나누거나 점포수로 나눠 대상별 사고율을 만들지 않는다.

자료 실사 실패가 사용자의 주제 결정을 자동 취소하지 않는다. 가능한 부분을 남기고 범위 조정을 제안한다. 원본을 받지 못한 항목은 미검증으로 남긴다.
