# 기획서 작성 규약

## 심사 현실

접수 9/18 → 결과 9/23. **5일**만에 심사가 끝난다. 심사자는 서류를 정독하지 않는다.
**첫 페이지·첫 문단에서 승부가 난다.** 뒤에 아무리 좋은 내용이 있어도 거기까지 안 읽는다.

## 문서 구조 — 공식 서식을 그대로 따른다

> 원본: `refs/2026-공모-작성서식.hwpx` 붙임 2 · 상세는 `docs/00-공모요강.md`
> **임의로 목차를 만들지 마라.** 서식이 정한 구조가 있고, 그게 사실상 배점표다.

**분량 10P 이하(표지 제외), "준수 필요" 명시.** 6개 절을 이 안에 담아야 한다.

```
표지         제목 / 접수번호(작성 안 함) / 날짜
1. 분석개요
   ▢ 문제 정의   ◦ 배경(분석을 시작한 배경·문제인식)  ◦ 필요성(현안 해결 필요성)
   ▢ 분석 요약   ◦ 활용데이터  ◦ 분석도구  ◦ 분석기법  ◦ 추진과정
   ▢ 분석결과
   ▢ 활용방안 및 기대효과
2. 분석방법
   ▢ 활용데이터  → 표: 데이터명 / 형식 / 대상기간 / 출처 / 비고
   ▢ 분석방법    ◦ 분석도구(툴)
                 ◦ 데이터 전처리 내용 및 검증 여부
                 ◦ 분석기법 및 분석절차
                 ◦ 분석결과 검증방법     ★ 별도 항목
                 ◦ 시각화 방법
3. 분석결과   인사이트 / 시각화 결과 / 검증 결과 / 결과의 한계 및 보완점
4. 활용방안   ▢ 적용부문  ▢ 정책 활용 방안
5. 기대효과   ▢ 정량적  ▢ 정성적
6. 기타       참고문헌
붙임 4       ★ 추가 가점 — 오픈랩 방문 / 데이터웨이브·브라이텍스 사용
```

### 1절이 사실상 요약본이다
`1. 분석개요`에 문제·데이터·기법·결과·활용이 전부 압축돼 들어간다.
심사자가 여기만 읽고 판단할 수 있다. **1절을 마지막에, 가장 공들여 쓴다.**

### 서식이 특별히 요구하는 두 가지 — 빠뜨리면 감점
- **분석결과 검증방법** — "결과가 맞다는 걸 어떻게 확인했나". 교차검증, 다른 연도 재현,
  민감도 분석, 현장 사실과의 대조 중 실제로 한 것을 쓴다. 안 했으면 하고 나서 쓴다
- **결과의 한계 및 보완점** — 서식이 한계를 쓰라고 명시했다. 숨기면 오히려 감점이다

### ★ 붙임 4 — 가점을 버리지 마라
| 항목 | 적을 것 |
|---|---|
| 데이터 오픈랩 방문 | 방문일시 / 방문자 / 사용데이터 |
| Big-데이터웨이브 사용 | 데이터명 + **브라이텍스 사용결과 캡처** |

공개 데이터만으로 분석을 완결시키되, **가점 재료를 추가로 얹는다.**
서식 예시에 `동백전 사용내역 … 출처: 부산 빅데이터 오픈랩`이 있다 —
오픈랩은 민간데이터를 제공하며, 주최측이 참가자에게 제공하는 데이터가 있다.

### 함께 제출할 것
- **개인정보 수집·이용 동의서** (붙임 1) — 참가자별 서명·날인
- **분석에 쓴 엑셀·한글 데이터 파일** — 서식에 "제출 필요" 명시

## 원칙

- **문제 정의에 숫자를 박는다.** "고령화가 심각하다" ✗ → "영도구 고령인구 비율 27.3%로 부산 평균 21.8%를 5.5%p 상회 [출처: KOSIS, 2025]" ✓
- **분석 질문은 3개 이하.** 많으면 아무것도 깊지 않다는 신호다.
- **데이터를 이미 확보했음을 보여준다.** 이게 1차 통과의 핵심 변별점이다.
  "활용 예정" ✗ → "확보 완료, 2019~2025년 월별 12만 행" ✓
- **그림을 넣는다.** Track 1 심사자는 시각화를 본다. 초안 차트라도 실물이 있는 쪽이 이긴다.
- **제안이 구체적이어야 한다.** "개선이 필요하다" ✗ → "○○구 3개 동에 우선 배치" ✓
- 모든 수치에 `[출처: 기관, 연도, URL]`. 근거 없는 숫자는 심사에서 즉사한다.
- 분량·양식은 미확인이다. `docs/00-공모요강.md`의 작업 가정(A4 5~10쪽 PDF)을 따르되,
  양식에 종속되는 구성은 최소화해 나중에 재배치가 쉽게 쓴다.

## 자주 죽는 패턴

| 패턴 | 왜 죽는가 |
|---|---|
| 문제가 전국 일반론 | "부산" 대회다. 부산 고유의 조건이 없으면 탈락 |
| 데이터 확보 불확실 | 5주 안에 못 끝낼 팀으로 읽힌다 |
| 분석 기법 자랑 | 기법이 아니라 무엇을 알아냈는지를 본다 |
| 제안이 추상적 | 행정이 집행할 수 없는 제안은 점수가 안 된다 |
| 시각화 없음 | 트랙 이름에 시각화가 들어 있다 |

후원이 **경남연구원 · 부산외국어대학교**다. 작년 대회는 후원기관별 특별상이 따로 있었다.
[출처: DX Challenge, 2025, https://www.dxchallenge.co.kr/events/bigdataanalysis2025 · 2026-08-19 확인]
- 부산-경남 광역 이슈(통근·물류·인구이동·의료권)를 다루면 경남연구원 계열 사정권
- 외국인·다문화·관광 국제화를 다루면 부산외대 계열 사정권
