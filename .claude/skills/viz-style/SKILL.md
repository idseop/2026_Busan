# 시각화 규약

트랙 이름이 "빅데이터 분석 **및 시각화**"다. 시각화는 부록이 아니라 채점 대상이고,
최종은 **발표평가**다. 화면에 띄웠을 때 3초 안에 읽히지 않으면 실패한 그림이다.

- 파일명은 `NN_주제_내용` 순번 접두사. 기획서·슬라이드에서 순서대로 참조한다.

## 차트 선택

| 보여줄 것 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 지역 간 비교 (구·동) | 가로 막대 (값 순 정렬) | 파이차트 |
| 시간에 따른 변화 | 선 그래프 | 3D, 이중 축 |
| 공간 분포 | 단계구분도(choropleth) + geopandas | 점만 흩뿌린 지도 |
| 두 변수 관계 | 산점도 + 추세선 | 상관계수만 표로 |
| 구성비 | 누적 가로 막대 | 도넛 여러 개 |
| 밀도·집중 | 격자 히트맵, KDE | 마커 클러스터만 |

**파이/도넛은 쓰지 않는다.** 항목이 3개를 넘으면 사람이 각도를 못 읽는다.

## 색 규칙

- 범주형은 `CAT` 순환색. **한 그림에 5색을 넘기지 않는다.**
- 강조는 **하나만**. 나머지는 `C["neutral"]`로 죽인다. 다 강조하면 아무것도 강조되지 않는다.
- 연속형: 위험·부담 `SEQ`(YlOrRd) / 규모 `SEQ_COOL`(Blues) / 증감 `DIV`(RdBu_r, 0 중심)
- 의미 고정: 악화 `C["bad"]`, 개선 `C["good"]`. 이 대응을 그림마다 뒤집지 않는다.
- 색만으로 구분하지 않는다. 흑백 인쇄·색각 이상에서도 읽히게 위치·라벨·패턴을 병행한다.

## 지도 (단계구분도)

```python
import geopandas as gpd
gdf = gpd.read_file("data/raw/경계/부산_행정동.shp", encoding="cp949")
gdf = gdf.to_crs(4326)                       # 좌표계 확인 필수
gdf = gdf.merge(df, on="행정동코드")          # 코드로 조인. 이름으로 조인하지 말 것
ax = gdf.plot(column="값", cmap=SEQ, scheme="quantiles", k=5,
              legend=True, edgecolor="white", linewidth=0.4)
ax.set_axis_off()
```

- 조인 키는 **행정동/법정동 코드**. 동 이름은 중복·개편으로 반드시 깨진다.
- 조인 후 **결측 지역 수를 반드시 출력해 확인**한다. 조용히 빈 지도가 나오는 게 최악이다.
- 원 데이터가 절대량이면 **인구·면적으로 정규화**한다. 인구 많은 구가 다 빨간 지도는 정보가 없다.
- 계급 구분은 `quantiles` 기본, 분포가 치우치면 `fisher_jenks`.
