GitHub의 HTML 파일 화면은 실행 중인 웹사이트가 아니다. 지도는 다음 방법으로 PC에서 실행한다.

## 실행

Python 3이 설치된 PC에서 저장소 루트 기준으로 실행한다. 웹 열람에는 추가 Python 패키지가 필요하지 않다.

```powershell
python web/final/serve.py
```

- 지도: http://127.0.0.1:8765/
- 전체 결과: http://127.0.0.1:8765/results/complete/
- 포트를 사용 중이면 `python web/final/serve.py --port 8766`
- 지도 ZIP을 풀었다면 `실행.cmd` 또는 `python serve.py`
- 분석 ZIP은 압축을 풀고 `index.html`을 열면 인터넷 없이 읽을 수 있다.

배경지도 타일과 외부 공식 출처에는 인터넷 연결이 필요하다. 지도 API 키는 필요하지 않으며 서버는 로컬 PC에서만 열린다.

## 분석과 화면의 흐름

부산 전체 신고 → 지역·유형별 반복과 선택 영향 → 주민·현장 배경 → 기존 대응 → 근거가 있는 예방·지원 보완 결과 순서로 구성한다.

지도에서 지역을 선택하면 **신고 특징 → 지역 배경 → 기존 대응 → 보완 결과**를 단계별로 읽는다. 각 단계의 상세 링크는 동일한 지역·유형·처리조건을 유지한다. 전체 탐색은 2D, 확대 지역은 선택적으로 3D를 사용한다. 배경 지역의 대표점은 실제 신고 지점이 아니다.

현재 결과는 194개 신고 지역명·5개 집중 유형과 9개 심층 사례를 연결한다. 전체 모음에 기존 결과를 포함한 48개 시각화·73개 집계표·23절 보고서가 있다. 출처·분모·연도 및 판단 기준은 [통합 보고서](docs/40-분석결과/부산-119-지도와입증-통합보고서-20260917.md)에 정리했다.

신고 집합이 부산 전체 위험도나 특정 연령층의 사고를 대표한다고 검증한 것은 아니다. 과거 계절 양상의 이후 기간 재현 여부와 기존 사업의 완료 상태를 확인했으며, 웹 기능의 검증과 시민 이용·피해 감소 효과는 구분한다.

원본 신고·행 단위 전처리 자료·개별 접수번호·정밀 신고좌표는 Git에 포함하지 않는다. 공개 웹에는 검증된 집계와 출처를 제공한다. OSM 건물 윤곽·높이는 공개 배경자료이며 신고 건물 배정이 아니다. 원 분석 재생성에는 보고서의 입력 명세에 맞는 원본과 중간 산출물이 별도로 필요하다.

분석·지도 재생성의 패키지는 `requirements.txt`, 최종 렌더링·브라우저 검증 환경의 고정 버전은 `requirements-final-delivery.txt`에 있다. 재생성 환경에서는 둘을 함께 설치한다.

```powershell
python -m pip install -r requirements.txt -r requirements-final-delivery.txt
```

기존 결과·검증의 이력은 보존한다. 날짜가 앞선 분석 문서·카탈로그는 당시의 기록이며, 이후 정정된 수치와 판단은 최신 통합 보고서를 따른다. 최신 결과의 진입점은 `web/final/`이며 그 밖의 이전 시제품은 현재 웹에 사용하지 않는다.
