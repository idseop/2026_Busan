## 2. 분석의 기준과 결과

2020~2024년 부산 119 신고를 같은 포함 조건으로 비교하고, 구·군의 주요 신고 유형을 유지하며 동별 규모·반복성·시간 특징을 확인했다. 주민 연령 구성과 지역 배경, 기존 대응을 연결해 적용 조건과 평가 기준을 갖춘 예방 보완안을 제시했다.

| 포함 조건 | 접수 건수 |
|---|---:|
| 선택 17개 항목 완전 기재 A | 704,689 |
| 정상 처리 B | 579,412 |
| 업무성 기록 제외 C | 574,662 |
| 벌집제거 추가 제외 P — 제출 주 분석 | **555,786** |

출처: [5개년 통합 분석 정리](docs/40-분석결과/부산-119-5개년통합-우선지역과제안연결-20260918.md), [공개 집계표와 검증 기록](output/submission-analysis-20260918/).

접수 건수 순위를 위험 순위로 해석하지 않는다. 주민 구성은 신고 당사자의 연령이 아니며, 보완안의 정책 효과나 서비스 공백이 실증된 것으로 해석하지 않는다. 자료상 소방 인원·차량은 현재 실시간 출동 가용량이 아니다.

## 3. 지도와 분석 페이지

| 위치 | 용도와 버전 |
|---|---|
| [web/final/](web/final/) | GitHub develop `0dcef8f`의 최신 지도·결과 갤러리. 이번 게시에서 기존 파일을 변경하지 않았다. |
| [web/submission/](web/submission/) | 로컬에서 정리한 제출 주 분석 P 기준 지도와 분석 페이지. 현재 파일을 별도 보관했다. |

두 웹의 분석 조건과 화면 구성이 다르므로 같은 분모로 섞어 읽지 않는다. 제출 주 분석은 P이며, 기존 웹과 두 구 비교의 C 집계는 벌집제거를 포함한다. 지도는 지역·유형·기간을 반복 비교하고 분석 근거를 찾아보는 구현물이다. GitHub에 소스를 올린 것만으로 공개 웹서비스가 배포된 것은 아니다.

제출 분석 웹을 로컬에서 실행하는 명령:

```powershell
.venv-check/Scripts/python.exe web/submission/serve.py --port 8766
```

Python 환경을 별도로 만든 경우 해당 환경의 Python 실행 파일을 사용한다. 실행 후 지도는 `http://127.0.0.1:8766/`, 분석 페이지는 `http://127.0.0.1:8766/analysis/`에서 확인한다. 지도 배경 타일은 외부 서비스에 연결한다.
