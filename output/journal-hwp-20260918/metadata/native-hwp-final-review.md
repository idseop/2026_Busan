# 그림 전용 한글 파일 제작 후 확인

확인일: 2026-09-18. 그림 제작 담당과 분리하여 6개 그림을 검토한 뒤 이미지 전용 한글 문서를 구성하였다. 원본 보고서·사용자의 기존 한글 문서는 열거나 수정하지 않았다.

## 실제 확인 결과

- 기존 한글 프로세스 PID 22848과 다른 독립 프로세스 PID 26292에서만 열기·저장·닫기를 수행하였다.
- 한글 저장 전 6쪽, 저장된 **HWP 파일을 실제 재열었을 때도 6쪽**이었다. HWP 파일 시그니처는 native OLE 형식이다.
- 저장된 HWPX에는 그림 객체 6개와 이미지 파일 6개가 있다. 삽입된 이미지 바이트의 SHA256 집합이 최종 PNG 6개와 모두 일치하였다.
- HWPX 본문 텍스트는 비어 있으며 머리말·꼬리말·쪽번호 객체가 없다. HWP 각 페이지 텍스트에는 제어문자만 있고 글자·숫자 본문이 없다.
- A4 세로, 한 페이지에 그림 하나를 원래 비율로 가운데 배치하였다. 그림 폭은 HWP 단위 반올림 기준 약 180mm, 높이는 약 220.6~221.0mm이다. 별도 표지·제목·설명문·쪽번호는 없다. 그림 본체의 축·범례·단위·패널 글자·지역명은 유지된다.
- 한글에서 만든 내부 검사용 PDF도 6쪽이다. 각 페이지에 이미지 하나가 있으며 종이 중심과 이미지 중심의 차이는 출력 단위 반올림에 따른 0.05mm 이내다. PDF는 최종 전달을 위한 추가 요구물로 취급하지 않는다.
- `rendered/figure-01.png`부터 `figure-06.png`까지 **전체 6쪽을 직접 열어 확인**하였다. 위아래·좌우 여백이 균형을 이루며 그림, 축, 수치, 범례가 잘리지 않는다. 이미지 왜곡이나 페이지 간 그림 누락을 발견하지 않았다.
