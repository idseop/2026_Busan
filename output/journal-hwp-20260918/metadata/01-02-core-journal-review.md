# 통합 그림 01·02 제작 및 확인

2026-09-18. 검증된 집계 CSV만 재표현했다. 원시 119 재분석·기존 자료 수정 없음. 두 그림은 180×221mm 설정, PNG 500dpi(3543×4350px)와 SVG다. 코드 및 표시값 JSON은 별도 저장했다.

- **01**: 중립 구·군 윤곽과 면적 비례 원 / 건수 순 점도표 / 부산 전체 상위 6유형의 구·군별 log2 구성비 특화 행렬. 현재 경계는 2025-06-30 위치 참고용이며 과거 신고를 재배정하지 않았다. EPSG:4326 입력을 EPSG:3857 수식으로 표시 변환했다. 2020년 일부 경계 변경 때문에 과거 집계를 현재 경계에 채색하지 않았다. 원 면적∝건수, 2·4·6만 건 크기 범례. 위험률·실제 신고 위치·거리 분석이 아니다.
- **02**: 기존 상위 5구의 구내 질병 규모 상위 3동씩, 원문동 15개를 표시. 질병 규모×동 내 구성비, 같은 구 전체의 질병 비중과 동 비중 연결, 동−구 차이(%p)를 결합했다. 다대동=청록, 금곡동=주황. 구 기준에는 해당 동이 포함된다. 부산 모든 동 분포나 행정동 재배정 결과가 아니다. 다대 +2.60%p, 금곡 +2.65%p는 기술적 차이이며 효과·유의성 검정이 아니다.

각 PNG를 실제 열어 지도 구명과 산점도 라벨을 조정했다. 최종본에서 값·축·범례의 잘림을 발견하지 못했다. 숫자/분모 대조 및 그림 제약 검사 136개 통과. 입력·출력 해시와 변환 정의는 `01-02-core-journal-metadata.json`, 표시값은 각 그림의 `*-display-data.json`에 보존했다. 제목·서술·출처·각주는 그림 안에 넣지 않았다.
