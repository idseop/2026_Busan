## 08-health-treatment-education

파일: `01-clean-original/08-health-treatment-education.png`, `.svg`; `02-paper-style/08-health-treatment-education.png`, `.svg`.

**외부 캡션:** 2024년 사하구와 북구의 고혈압·당뇨병 진단 경험자 치료율과 관리교육 이수율. 점은 조사 가중비율, 가로선은 기존 집계의 근사 95% 구간이다. 치료 이용과 관리교육 경험을 구분해 살펴보기 위한 비교다.

- 기간·분모: 2024 지역사회건강조사, 30세 이상 해당 질환 진단 경험자. n은 비가중 표본 수, 비율은 가중 공표값이다.
- 정확한 수치: 사하 고혈압 94.4/4.6(n282), 사하 당뇨병 98.5/5.5(n141), 북구 고혈압 93.9/4.7(n243), 북구 당뇨병 98.0/8.0(n123). 순서는 치료율/교육 이수율(%).
- 주의: 구 지표를 다대·금곡 또는 119 신고 당사자의 건강 상태로 해석하지 않는다. 교육값 4개 모두 상대표준오차 25% 이상이다. 치료율과 교육 이수율의 차이를 같은 사람의 미교육 규모나 미충족 수요로 해석하지 않는다.
- 구간: 입력 CSV의 `estimate ± 1.96×SE`, 0–100 범위로 제한한 근사 95% 구간. 새 가설검정·인과분석을 수행하지 않았다.
- 입력: `data/processed/신고보건심화-20260917/health-district-summary-2024.csv`. 대조용 복사 8행: `support-metadata/08-health-source.csv`.
- 원 공표 XLSX: `data/processed/신고보건심화-20260917/sources/chs2024-사하구.xlsx`, `chs2024-북구.xlsx`. 숨겨진 data 시트 행: 치료/교육 각각 고혈압 4964/5030, 당뇨병 5516/5582.
- 출처: 질병관리청·구 보건소 [지역사회 건강통계](https://chs.kdca.go.kr/chs/recsRoom/healthStatsMain.do).

## 09-proposal-counselling-education-evaluation

파일: 두 스타일 폴더의 `09-proposal-counselling-education-evaluation.png`, `.svg`.

**외부 캡션:** 다대·금곡의 기존 상담·교육을 바탕으로 실제 연결 누락을 확인한 뒤 교육 예약·완료 연계의 시범 도입 여부를 판단하는 제안 흐름이다. 이미 시행한 사업이나 실증 결과를 나타내지 않는다.

- 상태: 기존 센터·서비스 존재는 공식 안내로 확인. 실제 연결 누락·시범 시행·정책 효과는 미확인·미측정. 파일명 `proposal`과 ‘후보’ 노드에 제안 상태를 유지하였다.
- 기관명 약칭: 그림의 ‘다대센터’는 다대 건강생활지원센터, ‘금곡센터’는 금곡 마을건강센터다.
- 적용 전 조건: 최근 교육 이용·완료 실적, 참여 희망 적격자, 미참여 이유, 교육 정원, 기존 절차 중복을 확인한다. 같은 절차가 이미 작동하면 추가하지 않는다.
- 30일 지표: 교육 희망 적격 신규 참여자 중 첫 교육 완료 비율. 90일 지표: 첫 교육 완료자 중 약속된 상담 이행 비율. 기간은 제안이며 모집 전에 운영기관과 고정한다. 신고 감소·예산 절감·도착시간 단축을 의미하지 않는다.
- 입력: `data/processed/신고보건심화-20260917/regional-improvement-and-evaluation.csv`, H1·H2. 복사: `support-metadata/09-proposal-source.csv`.
- 출처: [다대 건강생활지원센터](https://www.saha.go.kr/health/contents.do?mId=0404060000), [사하구 질환관리](https://www.saha.go.kr/health/contents.do?mId=0404040000), [북구 마을건강센터](https://www.bsbukgu.go.kr/health/index.bsbukgu?menuCd=DOM_000000503001006000), [북구 질환관리](https://www.bsbukgu.go.kr/health/index.bsbukgu?menuCd=DOM_000000503001004000). 2026.9.18 기존 출처 점검 기록을 사용한다.

## 10-web-exploration-cycle

파일: 두 스타일 폴더의 `10-web-exploration-cycle.png`, `.svg`.

**외부 캡션:** 구현된 지도에서 신고 조건과 지역을 선택하고, 동별 상세와 분석 근거를 확인한 뒤 조건을 바꿔 다시 비교하는 이용 흐름이다.

- 실제 기능: 신고 연도·종별·세부 유형·처리 조건·구군/동명 검색, 선택 지역의 시간·주민 후보·보완안 상세, 분석 페이지 이동·CSV 다운로드·이전 지역 복귀.
- 구현 근거: `web/final/index.html`, `web/final/assets/current-map.js`, `web/submission/analysis/index.html`（GitHub 게시 시 경로 변경）.
- 기간: 신고자료 2020–2024. 분모는 선택 연도·유형·처리 조건에 따라 달라진다. 주민 자료는 배경이며 신고 당사자의 속성이 아니다.
- 범위: 업무시간 단축·정책 효과는 측정하지 않았다. 기관 실적 자동 갱신·기관 API 연계는 별도 협의·개발이 필요한 향후 과제이며 이번 도식에 구현 단계로 넣지 않았다.

## 16-unmet-healthcare-2024

파일: `02-paper-style/16-unmet-healthcare-2024.png`, `.svg`만 생성했다.

**외부 캡션:** 2024년 북구·부산진구·사하구의 연간 미충족의료율(병의원) 공표값과 표준오차 기반 근사 95% 구간. 해당 연도 조사에서 병의원 진료가 필요했던 응답자를 분모로 삼는 구 단위 비교다.

- 값: 북구 13.7%(n873), 부산진구 9.8%(n898), 사하구 4.9%(n822). 가중비율과 비가중 n을 구분한다.
- 주의: 구별 차이는 동별 서비스 공백이나 119 신고 당사자의 미지원 상태를 뜻하지 않는다. 차이의 통계적 유의성이나 제안의 효과를 검정한 결과가 아니다.
- 기간 제한의 근거: 2023년과 2024년 공표 XLSX의 분모 문구가 달라 두 해를 동일 정의의 추세로 연결하지 않았다. 실제 산출식 변경 여부를 확정한 것은 아니다. 정확한 문구·시트·행은 `metadata/support-new-finding.md`에 보존했다.
- 입력·출처·구간·단위: 위 신규 확인 문서와 `support-metadata/16-unmet-healthcare-2024-source.csv` 참조.
