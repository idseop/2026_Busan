# 그림만 남긴 시각화 자료

제작일: 2026-09-18. 기존 보고서와 원래 그림은 보존하고, 검증된 집계 결과를 재표현하였다. 이번 자료는 보고서 삽입용 그림 모음이며 대회가 요구하는 별도 1장 시각화 PDF의 완성본은 아니다.

## 1. 바로 사용할 파일

| 구분 | 폴더·파일 | 구성 |
|---|---|---|
| 기존 도표 설명 제거판 | `01-clean-original/` | 01~10, PNG 10개·SVG 10개 |
| 논문 스타일판 | `02-paper-style/` | 기존 내용 01~10 + 추가 내용 11~16, PNG 16개·SVG 16개 |
| 기존 도표 PDF | `pdf/01-기존도표-글자확대-그림만.pdf` | 한 쪽에 한 그림, 10쪽 |
| 논문 스타일 PDF | `pdf/02-논문형도표-추가포함-그림만.pdf` | 한 쪽에 한 그림, 16쪽 |

PNG는 450dpi로 저장했다. 한글에 삽입할 때 PNG를 사용하고, 원본 비율을 유지하면 된다. 기본 그림 폭은 약 180mm이며 지나치게 줄이면 글자도 함께 작아진다. SVG는 선과 글자를 확대할 때 유리하다. 열지도 색상 영역에는 래스터가 포함되므로 모든 요소가 순수 벡터인 것은 아니다. PDF는 SVG에서 변환했다.

## 2. 반영한 수정

1. 그림 내부 제목·부제·설명문·출처·쪽번호를 삭제했다.
2. 해석에 필요한 축 이름·단위·범례·수치·흐름도 단계명은 남겼다.
3. 눈금 13pt, 축 이름 14pt, 범례 12.5pt, 수치 최소 12pt를 적용했다.
4. 논문 스타일판은 흰 바탕, 얇은 축, 최소한의 격자, 절제된 파랑·회색·주황을 사용했다.
5. 기존 05번은 연도별 선그래프를 남기고 반복성·민감도 검토 설명 블록을 제거했다. 분석 자체를 취소하거나 값을 바꾼 것은 아니다.

## 4. 그림 밖에 보존한 근거

- 01~07의 기간·분모·출처: `core-01-07-sources-and-captions.md`
- 08~10 및 16의 캡션·출처·제안 상태: `support-metadata/support-captions.md`
- 11~15의 캡션·분모·입력 경로: `metadata/additional-captions.md`
- 11~15의 원자료·기존 독립검증 대조: `additional-source-audit.md`
- 16의 연도별 분모 문구 확인: `metadata/support-new-finding.md`
- 최종 그림 검토: `metadata/final-visual-review.md`
- 추가 그림의 수치 대조: `metadata/final-data-review.md`

제목과 출처가 필요한 보고서에는 이 안내를 그림 밖 캡션으로 옮겨 쓸 수 있다. PDF에는 이 안내문을 넣지 않았다. 개별 제작자 메타데이터의 `pdf_created: false`는 PNG·SVG 제작 단계의 기록이며, 최종 PDF 생성 기록은 `metadata/pdf-generation.json`이다.

## 5. 해석에 필요한 최소 조건

1. 신고자료는 2020~2024년이다. 주 분석 555,786건은 선택한 17항목 완전 기재·부산·정상 처리에서 업무성 기록과 벌집제거를 제외한 접수다. 전체 환자 수·사고 발생률·위험 순위가 아니다.
2. ‘나머지 유형’은 질병·질병외·부상을 제외한 종별×세부유형을 합한 값이다. 원자료의 종별 ‘기타’ 하나를 가리키지 않는다.
3. 주민 연령은 행정동 배경이며 신고자 연령이 아니다. 원문 동명 신고를 행정동 후보에 임의 배분하지 않았다.
4. 08·16의 점은 가중 추정치, n은 비가중 표본 수, 가로선은 표준오차로 계산한 근사 95% 구간이다. 구 단위 지표로 동의 서비스 부족이나 제안 효과를 확정하지 않는다.
5. 09는 연결 누락 확인을 선행 조건으로 둔 제안이다. 10은 구현 기능의 이용 흐름이며 업무시간 단축 실증은 아니다.
6. 13의 두 패널은 같은 색상 척도다. 각 동의 질병 접수 전체를 분모로 삼았으며 요일별 노출일을 보정한 위험률이 아니다.
7. 14는 분기별 상가 명부의 비중이며 같은 업소를 추적한 패널이 아니다. 선그래프 세로축 표시범위는 **29~36%**다.
8. 15는 2023·2024년 각각 12개월의 시간별 평균방문인구 추정값을 동일 가중 평균했다. 2025년은 제외했다. 고유 방문자 수·신고 당사자 수가 아니다.
9. 16은 2024년의 동일 지표로 비교했다. 2023·2024년 원 XLSX의 분모 문구가 달라 두 해를 동일 기준의 추세로 연결하지 않았다. 문구 차이만으로 실제 산식 변경을 확정한 것은 아니다.

## 6. 재현 파일

`code/`에는 생성 코드, `display-data/`와 `support-metadata/`에는 추가 그림용 표시 집계, 각 JSON에는 입력·출력 해시와 검사 결과를 보존했다. 실행 시 원 저장소의 입력 경로가 필요하며 ZIP만으로 전체 분석 원자료를 복원할 수 있는 구성은 아니다. ZIP에는 원본 신고자료나 개인정보 동의서를 넣지 않았다.
