- 원자료 행: 고혈압 치료 4964, 고혈압 교육 5030, 당뇨병 치료 5516, 당뇨병 교육 5582. 추출 CSV에 원파일·행 번호를 보존했다.
- 출처: 질병관리청·각 구 보건소, [2024 지역사회 건강통계](https://chs.kdca.go.kr/chs/recsRoom/healthStatsMain.do). 조사 기간 2024.5.16–7.31. 독립 검증: `data/processed/신고보건심화-20260917/verification/verification.md`.
- 단위·분모: 30세 이상 해당 질환 진단 경험자의 조사 가중비율(%). `n`은 해당 공표표의 비가중 표본 수이며 가중 비율의 계산분모가 되는 주민 총인구가 아니다. 고혈압은 사하구 n=282·북구 n=243, 당뇨병은 사하구 n=141·북구 n=123.
- 표시: 점은 공표 추정치, 가로선은 기존 CSV의 `estimate±1.96×SE` 근사 95% 구간(0–100 범위). 검정 결과나 인과 효과를 표시한 것이 아니다.

**삽입 캡션:** 2024년 사하구와 북구의 고혈압·당뇨병 진단 경험자 치료율은 93.9–98.5%, 관리교육 이수율은 4.6–8.0%였다. 치료 이용과 교육 경험을 구분해 기존 상담·교육의 연결 단계를 검토할 근거다. 구 조사값을 다대·금곡 또는 119 신고 당사자의 건강 상태로 해석하지 않는다. 교육 4개 값의 상대표준오차는 모두 25% 이상이므로 작은 차이로 구 순위를 정하지 않으며, 두 지표를 차감해 미충족 수요나 미교육 인원을 추산하지 않는다.

**축약 캡션:** 구 단위 조사에서 치료율과 관리교육 이수율을 별도로 확인했다. 차이를 미충족 수요로 해석하지 않으며, 교육지표는 정밀도에 주의한다(2024 지역사회건강조사).

**원고에서 대체 가능한 부분:** 치료율·교육 이수율을 반복 나열하는 표·문장. 본문에는 “구 조사에서 확인한 관리교육 경험을 기존 센터의 연결 절차 점검에 활용하였다”는 해석만 남긴다.

## 그림 09. 기존 상담에서 교육 완료까지, 연결을 점검한다

- PNG: `output/report-visual-edit-20260918/charts/09-기존대응-보완후보-평가.png`
- SVG: `output/report-visual-edit-20260918/charts/09-기존대응-보완후보-평가.svg`
- 설계 근거 CSV: `output/report-visual-edit-20260918/charts/09-보완평가-근거행.csv`
- 입력: `data/processed/신고보건심화-20260917/regional-improvement-and-evaluation.csv`의 H1(북구 금곡동)·H2(사하구 다대동). 기존 센터·프로그램은 공식 안내로 확인했고, 보완 시범의 효과는 아직 측정하지 않았다.
- 기존 대응 출처: [다대 건강생활지원센터](https://www.saha.go.kr/health/contents.do?mId=0404060000), [사하구 심뇌혈관질환 예방관리](https://www.saha.go.kr/health/contents.do?mId=0404040000), [북구 마을건강센터](https://www.bsbukgu.go.kr/health/index.bsbukgu?menuCd=DOM_000000503001006000), [북구 심뇌혈관질환 관리](https://www.bsbukgu.go.kr/health/index.bsbukgu?menuCd=DOM_000000503001004000). 2026.9.18 재열람 근거는 `output/report-audit/support-evidence.md`에 정리했다. 현행 안내를 2020–2024 전기간 동일 운영으로 소급하지 않는다.
- 단위: 정책 제안의 단계이며 집계 건수나 실증 성과를 나타내지 않는다.
- 30일 지표: 첫 교육 완료자 / 교육 연결을 희망한 적격 신규 참여자. 적격은 해당 질환 진단 경험·관리교육 미경험·참여 희망·동의 등 운영기관과 사전 고정한다.
- 90일 지표: 90일 후 약속된 상담 이행자 / 첫 교육 완료자. 자가관리 핵심내용 확인 결과는 별도 보조지표로 수집할 수 있다.
- 평가 조건: 현행 안내와 예약·완료 확인 연계를 단계적으로 비교하고 모집기간·계절·모집경로·추적 누락 처리·분모를 사전에 고정한다. 30일·90일은 제안 기간이며 실증된 최적 기간이나 법정 기준이 아니다.

**삽입 캡션:** 다대 건강생활지원센터와 금곡 마을건강센터의 기존 상담·교육을 활용한다. 최근 실적에서 교육 희망 적격자의 연결 누락이 확인되는 경우에 한해 예약·참여·첫 완료 확인을 보완한다. 30일 내 첫 교육 완료율과 90일 후 상담 이행률을 현행 절차와 비교하며, 동일 절차가 이미 작동하거나 부담만 늘면 추가 도입하지 않거나 수정·중단한다. 현재 동별 미충족 수요·신고 감소·건강 개선 효과는 입증하지 않았다.

**축약 캡션:** 기존 사업의 실제 연결 누락을 먼저 확인한 뒤, 교육 예약·완료 관리의 시범 효과를 평가한다. 새 센터나 문자 안내를 일괄 신설하는 제안이 아니다.

**원고에서 대체 가능한 부분:** 활용방안의 실행단계·평가 절차 설명. 필요하면 표에는 적용 대상과 수정·중단 기준만 간단히 남긴다. 119 응급대응과 보건기관 예방·관리의 역할은 별도 본문 한 문장으로 구분한다.

## 그림 10. 조건을 바꿔 재비교하고, 근거로 돌아간다

- PNG: `output/report-visual-edit-20260918/charts/10-웹-반복활용흐름.png`
- SVG: `output/report-visual-edit-20260918/charts/10-웹-반복활용흐름.svg`
- 구현 근거 CSV: `output/report-visual-edit-20260918/charts/10-웹흐름-구현근거.csv`
- 입력: `web/final/index.html`, `web/final/assets/current-map.js`, `web/final/analysis/index.html`.
- 실제 지도 기능: 연도, 신고 종별·세부 유형, 처리 조건, 구·군·동명 검색 및 선택, 시간·주민·보완안 상세, 이전 지역 복귀, 분석 페이지 연결.
- 실제 분석 페이지: 16개 구·군 비교, 같은 유형의 동 비교, 주민·지역 배경, 기존 대응·보완안, 자료 기준·CSV 내려받기. 지도와 분석 페이지 간 연결이 구현되어 있다.
- 기간·단위·분모: 사용 흐름 도식 자체에 수치 분모는 없다. 탐색 대상 신고는 2020–2024이며 표시 건수는 선택한 처리 조건·연도·유형에 따라 달라진다. 주민 값은 해당 연도 말 행정동의 배경이며 신고 당사자의 속성이 아니다.
- 범위: 기관의 실제 사업 수행 실적을 입력하거나 외부 API로 자동 갱신하는 기능은 구현한 것으로 표시하지 않았다. 기존 지도에서 사용하는 배경지도와 향후 기관 업무 API 연계는 구분한다.

**삽입 캡션:** 이용자는 신고 조건과 지역을 선택하고, 같은 유형의 동별 특성과 주민 행정동 후보를 확인한 뒤 분석 페이지의 기존 대응·보완안·CSV 근거로 이동한다. 조건을 변경해 재비교할 수 있다. 현재 구현은 탐색과 근거 확인 기능이며 업무시간 단축이나 정책 효과는 측정하지 않았다. 기관 실적·API 연계는 별도 협의·개발이 필요한 향후 과제다.

**축약 캡션:** 지도에서 조건·지역을 선택하고 분석 근거로 이동한 뒤 다시 비교하는 반복 활용 흐름. 업무효율과 정책 효과는 미측정이며 기관 API 연계는 현재 구현 범위 밖이다.

**원고에서 대체 가능한 부분:** 웹 기능과 이용단계를 길게 나열한 문단. 현재 실제 동작과 향후 확장 범위는 이 그림과 한 문장으로 정리할 수 있다.
