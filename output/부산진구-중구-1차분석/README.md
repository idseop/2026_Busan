# 부산진구·중구 1차 분석 공유 안내

## 결과 읽기

- [통합 PDF](../pdf/부산진구·중구_신고기반_정책검토_통합분석.pdf): 결과·기간 기준·시각화 12개·추가 필요자료를 모은 16쪽 내부 분석자료. 공모전 제출용 10쪽 보고서와 구분한다.
- [분석보고서](분석보고서.md): 근거와 한계를 포함한 정리본.
- [시각화 모음](시각화.html): 저장소를 받은 뒤 브라우저로 열면 그림 12개를 볼 수 있다. `figures/부산진구-중구-1차분석/`도 함께 받아야 한다.
- [분석 설계 PDF](../pdf/부산진구·중구_신고기반_정책제안_분석설계.pdf): 8개 분석 축의 설계. 완료된 결과와 구분한다.

이 폴더의 CSV는 결과 집계표다. 접수번호·개별 신고 정밀좌표·행별 신고 원본은 포함하지 않는다. `04_관서연결_검증.csv`의 좌표는 신고 위치가 아니라 소방관서 위치다.

## 기간과 결론

신고 규모·유형·동명·센터 구성은 2020-2024 합산, 시간대는 5년 통합, 월별·연간 추세와 인구는 연도별이다. 고령층 구성 그림은 2024년 말, 소방자원 원표 기준일은 미확인이다. 접근성·실제 돌봄 지원 공백·정책 효과는 아직 검증되지 않았다.

## 재현

1. 데이터 카탈로그의 [분석 입력](../../docs/20-데이터카탈로그/부산진구-중구-분석입력.md)을 따라 원본을 별도로 준비한다. Git에는 원본을 올리지 않는다.
2. 로컬 신고 전처리는 `analysis/00_공통/preprocess_local_receipts.py`, 검증은 `verify_local_receipts.py`를 사용한다. 실행마다 새 전처리 폴더가 만들어지므로 분석 코드의 `PRE`를 해당 경로로 맞춘다.
3. `.venv/Scripts/python.exe -X utf8 analysis/01_쏠림진단/analyze_two_districts.py`
4. `.venv/Scripts/python.exe -X utf8 analysis/01_쏠림진단/verify_two_districts.py`
5. PDF 재생성: `analysis/01_쏠림진단/build_integrated_analysis_pdf.py`. 설계 PDF는 `build_policy_framework_pdf.py`. Windows 맑은 고딕 폰트 경로를 사용하므로 다른 OS에서는 설치된 한글 폰트로 경로를 바꿔야 한다.

`manifest.json`은 분석 실행 당시 입력·출력의 SHA256, `독립검증.json`은 집계 합계·해시 대조 결과다. 원본을 별도로 확보하지 않아도 PDF·HTML·집계표를 읽을 수 있다.
