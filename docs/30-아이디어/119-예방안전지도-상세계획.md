# 부산 119 예방안전 지도 — 건물·상권 특성에 따른 예방점검 우선지역

> 상태: **원자료 실사 전 / 조건부 추진안**. 이 문서의 산식·기준·일정은 설계 제안이며 관측 결과가 아니다.
> 기존 관광 주제 문서는 보존한다. 팀 전체 주제 확정과 실제 분석 착수는 데이터 실사 결과를 보고 결정한다.

## 1. 제안의 핵심

119 사건 이력과 건물 용도·노후도·상권 구성을 행정동 단위로 결합해, **어느 동에서 어떤 사고가 두드러지는지와 어떤 예방활동을 우선 검토할지**를 보여준다. 주 이용자는 소방서 예방업무 담당자와 구·군 안전관리 담당자다. 담당자가 다음 점검계획을 세울 때 지역을 선택하고, 사고 유형·발생률·피해·자료 품질을 확인한 뒤 근거가 붙은 검토 목록을 내려받는 흐름을 목표로 한다.

차별점은 사고 위치 표시를 넘어 **지역 특성 → 관측된 사고 패턴 → 예방활동 후보 → 판단 근거와 한계**를 연결하는 데 있다. 사고 감소 효과나 개별 건물의 위험 확률은 아직 검증하지 않았으며 제시하지 않는다.

### 연구 질문과 해석 범위

|---|---|---|---|

## 2. 최소 구현 범위와 확장 조건

- 공간: 저장소 규칙에 따라 **부산 행정동**으로 통일한다. 법정동을 행정동으로 이름만 바꿔 사용하지 않는다.
- 시간: 동일 기준으로 수집 가능한 연속 다년 자료를 우선하며, 목표 기간은 최근 3~5년이다. 실제 확보 기간을 화면에 표시한다.
- 사건: 화재를 핵심으로 한다. 가스 누출·승강기 갇힘 등 생활안전은 세부 유형과 행정동 자료가 확보될 때 추가한다.
- 환경: 건물 주용도·규모·사용승인일, 음식점·숙박업 등 업종 구성. 건축물대장 주용도와 개별 점포 업종은 별도 속성이다.
- 제외: 구급 질환 분석, 실시간 사고 예측, 개별 업소 위험등급, 자동 점검주기 결정, 효과가 검증되지 않은 사고 감소율.
- 정밀 주소가 있어도 공개 화면은 행정동 집계만 제공한다. 원시 신고 내용·개인정보·사건별 주소는 공개 저장소 및 웹에 포함하지 않는다.

## 4. 전처리와 결합 규칙

### 사건 단위 정리

원자료의 신고·출동·사고를 각각 구분한다. 동일 사건에 여러 신고나 출동이 있으면 익명 사건번호로 확인 사고를 한 번만 센다. 식별자가 없으면 시각·장소가 유사하다는 이유로 무조건 병합하지 않고, 중복 의심 건을 표시해 집계 전후 차이를 검토한다. 중복 해소가 불가능하면 지표명을 '출동 건수'로 유지하고 실제 사고 건수로 표현하지 않는다.

원본 유형코드와 표시용 대분류를 모두 보존하고, 화재 조사 완료 여부와 원인 미상을 별도로 둔다. 등록일을 발생일로 대신 사용하지 않는다. 피해 0과 피해 미상을 구별한다.

### 공간·시간 연결

좌표가 있으면 좌표계와 부산 범위·경계점 검사를 거쳐 기준 행정동 경계에 결합한다. 정확한 주소만 있으면 지오코딩 결과의 정밀도와 연결 실패를 기록한다. 법정동이 여러 행정동에 걸치고 상세 위치가 없으면 건수를 인구 비례 등으로 임의 배분하지 않는다. 변환 불가 건은 미배정으로 남긴다.

분동·합동은 공통 경계로 재집계할 수 있는지 먼저 확인한다. 재집계할 수 없는 연도는 비교에서 제외한다. 점포·건물은 사건 시점의 분모에 맞춘다. 현재 영업 중 점포만으로 과거 음식점 화재 발생률을 계산하면 폐업 누락 편향이 생기므로 금지한다.

건물 결합은 건물 식별자 또는 검증된 주소를 우선한다. 복합건물의 주용도만으로 모든 사고를 음식점 사고로 분류하지 않는다. 건물 단위 연결이 불가능하면 동별 상권 특성과 동별 사고의 연관성만 분석한다.

### 산출 테이블 설계

| 테이블 | 한 행의 단위 | 핵심 필드 |
|---|---|---|
| 사건 정제표 (비공개) | 확인 사건 또는 출처가 정의한 출동 | 익명번호, 발생일시, 행정동, 유형, 장소, 원인, 피해, 중복/미상/연결 상태 |
| 지역 환경표 | 행정동 × 기준연도 | 용도별 건물 수·면적, 업종별 점포 수, 사용승인 연도 분포, 출처·기준일 |
| 분석 집계표 | 행정동 × 기간 × 사고유형 | 건수, 대응 노출량, 발생률, 신뢰구간, 비교값, 자료 품질, 순위 제외 사유 |

공개용 집계표의 키는 행정동 코드·기간·유형으로 유일해야 한다. 실제 필드명과 코드북은 원자료 실사 후 확정한다.

## 5. 지표와 우선지역 선정

### 지표 정의

| 지표 | 산식 또는 정의 | 해석 제한 |
|---|---|---|
| 발생 부담 | 동일 기간 확인 사건 수 N | 지역 규모의 영향을 포함하는 업무 수요 지표 |
| 규모 보정 발생률 | N / 대응 노출량 E × 표시 배율 | 음식점 화재에는 음식점 노출량, 건물 화재에는 건물 노출량 사용 |
| 유형 구성비 | 해당 유형 사건 / 동일 범위 전체 사건 | 원인 미상 비중을 함께 표시. 위험 확률이 아님 |
| 비교 발생률비 | 해당 동 발생률 / 해당 동을 제외한 비교집단 합산 발생률 | 비교집단 발생률은 건수 합/노출량 합. 동별 비율 단순 평균 금지 |
| 피해 부담 | 인명피해 합계, 재산피해 합계 및 중앙값 | 원자료 단위·가격 기준·결측을 표시. 한 대형사고의 영향을 분리 확인 |
| 반복성 | 동일 기준에서 높은 수준이 반복된 연도 | 확보 연도가 적으면 '판단 불가' |

노출량 E는 가능하면 운영 개월을 반영한 점포-년 또는 건물-년으로 만든다. 연간 스냅샷뿐이면 연도별 수의 합을 근사 분모로 쓰고 근사임을 명시한다. 표시 배율은 가독성을 위한 설계값이다. 여러 해 사건 합계를 현재 한 해 점포 수로 나눠 연간 발생률이라고 부르지 않는다. E가 0·미상인 경우 발생률은 결측 처리한다.

### 비교집단과 통계 해석

기본 비교는 동일 사건 정의·기간·노출량을 가진 부산의 나머지 지역이다. 확장 분석에서는 사고 결과를 보지 않고 사전에 정한 용도·상권 구성으로 유사 동을 묶는다. 비교집단 정의와 포함 동을 공개한다. 군집 수 등을 결과가 가장 잘 보이도록 반복 선택하지 않는다.

발생률에는 포아송 가정의 신뢰구간을 초기안으로 검토하고, 과산포·연도별 의존성이 크면 모형 또는 재표집 방법을 재검토한다. 신뢰구간 폭과 원건수를 함께 표시한다. 여러 동의 탐색 결과를 유의한 위험지역으로 발표하려면 다중비교 보정이 필요하다. 최소 표본·연결률·미상률 기준은 원자료 분포를 보고 분석 전에 기록하며, 기준 변경에 따른 후보 목록 변화를 검증한다.

### 우선 검토 목록의 규칙

임의 가중치로 단일 종합 위험점수를 만들지 않는다. **검토 목적별 목록**을 제공한다.

1. 업무 수요 목록: 자료 품질 조건을 통과한 지역을 발생 건수 기준으로 표시.
2. 상대 발생 목록: 대응 분모가 있는 지역만 발생률비·신뢰구간·반복성으로 검토.
3. 피해 대응 목록: 인명·재산피해를 분리 표시하고 대형 단일 사건 여부 병기.
4. 자료 보완 목록: 위치 누락·원인 미상·분모 미확보로 판단이 어려운 지역 표시.

담당자가 검토 가능 지역 수 K를 입력하면 선택한 목록의 앞 K개를 표시한다. 이는 **점검 후보 추출 시나리오**이며 예방 효과의 최적화가 아니다. 실사 전에는 어느 실제 동도 높은 위험으로 지정하지 않는다. 동률은 동률로 표시한다.

## 6. 예방활동 연결표

다음은 매핑 설계다. 공식 예방자료의 세부 근거와 담당기관 검토가 완료되기 전에는 모두 '활동 후보'로 표시한다.

| 관측 증거 | 지역 특성의 역할 | 검토할 활동 후보 | 금지하는 도약 |
|---|---|---|---|
| 음식점에서 확인된 조리 관련 화재 | 교육·점검 대상 분포 파악 | 조리시설 점검·종사자 예방교육 | 음식점 밀집만으로 가스 누출 확정 |
| 전기적 요인 화재가 반복 | 건물 연식·용도와 함께 대상 검토 | 전기설비 점검 협의 | 노후 건물 모두 위험하다고 판정 |
| 별도 분류된 가스 관련 사건 반복 | 관련 시설 분포가 있을 때 대상 검토 | 가스안전 점검기관과 점검 검토 | 일반 화재를 가스 사건으로 대체 |
| 숙박시설 화재·인명피해 확인 | 숙박시설 분포와 연결 | 피난동선·경보설비 점검 및 교육 검토 | 투숙객 수 없이 개인 피해확률 산출 |
| 특정 원인 자료 없음 | 상권 특성만 설명 가능 | 일반 화재예방 점검 검토 | 특정 설비 점검주기 자동 결정 |

각 권고에는 관측 기간, 사고유형, 지표, 비교군, 공식 근거, 미확인 사항을 붙인다. 법정 점검 주기를 변경하는 제안은 포함하지 않는다. 원인 미상 비율이 높으면 원인별 권고를 제한한다.

## 7. 웹 화면과 이용 시나리오

### 화면 구성

| 영역 | 표시 내용 | 동작·완료 조건 |
|---|---|---|
| 상단 필터 | 기간, 사고유형, 건수/발생률/피해, 비교 기준 | 변경 시 지도·차트·목록에 같은 조건 적용 |
| 중앙 지도 | 행정동별 선택 지표와 범례 | 동 선택 → 상세 카드. 결측은 회색·자료 부족 표기, 0과 구분 |
| 상세 카드 | 건물·상권 구성, 사고 유형, 발생률비·구간, 품질 | 단위·분모·관측 기간·출처 항상 표시 |
| 시간 차트 | 월별/시간대 분포 | 시각 항목이 없으면 시간대 메뉴 숨김. 부분 수집 월은 비교 제외 |
| 검토 목록 | 선택 목적별 지역과 활동 후보 | 정렬 근거 표시, K 변경, CSV 내려받기 |
| 근거 패널 | 자료 출처·기준일·권고 근거·한계 | 원자료 주소·개인정보 없이 재검토 가능 |

정적 웹과 사전 집계 GeoJSON을 기본 구조로 사용한다. 사건별 기록을 브라우저로 전달하지 않는다. 도구·추가 라이브러리 선택은 구현 단계에서 기존 환경을 확인해 결정한다.

### 담당자 이용 흐름

1. 화재 유형과 비교 기간을 선택하고 업무 수요가 큰 행정동을 확인한다.
2. 발생률 보기로 전환해 건물·점포가 많아서 건수가 높은 경우와 구분한다.
3. 동을 선택해 원인 구성, 반복성, 상권 특성과 자료 부족 여부를 확인한다.
4. 근거가 있는 예방활동 후보를 열고 다음 점검계획 검토 목록을 저장한다.

사고 유형·기간을 바꾸면 기존 선택을 일관되게 갱신한다. 데이터가 없으면 '관측 자료 없음'을 표시한다. 실사 전의 화면 시안은 배치·라벨만 사용하며 가짜 지역별 수치나 지도를 결과물로 커밋하지 않는다.

## 8. 검증·완료 기준

| 검증 | 확인할 내용 | 통과 증거 |
|---|---|---|
| 자료 실사 | 실제 행 수·기간·유형·입도·이용 조건 | 카탈로그와 코드북, 추진 판정 |
| 사건 정합 | 신고/출동/사고 구분, 중복·미상 | 처리 전후 건수와 제외 사유표 |
| 공간 정합 | 좌표·경계연도·법정동/행정동 구분 | 연결/미연결 표, 경계·중복주소 사례 점검 |
| 집계 보존 | 원건수 = 배정 + 미배정 + 명시적 제외 | 단계별 대조표, 다대다 결합으로 증식하지 않음 |
| 지표 정확성 | 분모·기간·0·결측·피해단위 | 일부 지역 수동 대조와 계산 테스트 |
| 안정성 | 연도·표본 기준·비교집단·대형사고 제외 시 결과 | 후보 목록 변화 및 불안정 지역 표시 |
| 과거 분리 검증 | 충분한 연도 확보 시 이전 연도 목록과 다음 연도 부담 비교 | 단순 건수 기준과 비교. 표본 부족 시 생략 사유 |
| 화면 정합 | 필터·지도·표·CSV의 값과 조건 일치 | 실제 집계 자료를 이용한 상호 대조 |
| 권고 추적 | 모든 활동 후보가 증거·근거에 연결 | 원인 미확보 시 구체적 원인 권고가 나오지 않음 |
| 공개 범위 | 재배포 조건, 소수 사건, 원주소 배제 | 공개용 필드 검수와 원자료 미포함 확인 |

예방 효과는 점검 이력과 후속 사건 자료가 확보된 후 별도 평가한다. 초기 성과는 '근거가 붙은 검토 가능 지역 범위', '자료 품질 공개', '목록 작성·이해 가능성'으로 평가한다. 사용자 평가를 실시하지 않았다면 편의성 개선도 실증 결과라고 쓰지 않는다.

## 9. 실행 순서와 작업 분담안

기간은 착수 후 상대 작업일 기준의 제안이다. 외부 승인 대기시간은 별도이며 일정 경과만으로 데이터 확보를 가정하지 않는다.

| 단계 | 제안 기간 | 작업 | 다음 단계 진입 조건 |
|---|---|---|---|
| 자료 실사 | 작업일 1~2 | 소방 샘플·분류·기간·행정동, 상권·건물 분모 확인 | 추진/축소/보류 결정 기록 |
| 지표 확정 | 작업일 3 | 사건 단위·노출량·비교집단·품질 기준 고정 | 코드북과 분석 규칙 합의 |
| 결합·집계 | 작업일 4~5 | 공간 연결·중복 처리·동별 집계 | 보존 검증과 수동 대조 통과 |
| 웹 최소 구현 | 작업일 6~7 | 지도·상세·유형 비교·목록 | 실제 집계 기반 화면 정합 통과 |
| 검증·문서화 | 작업일 8~9 | 민감도·근거 검토·보고서 반영 | 결과와 한계, 재현 절차 완성 |

병렬 작업은 역할별로 분리한다: 소방 자료 실사, 건물·상권·경계 실사, 분석·검증, 화면·보고서. 특정 팀원에게 배정된 것으로 간주하지 않는다. 공통 행정동 코드·기간·집계 스키마 확정 후 결합 작업에 착수한다.

### 공식 보고서에 반영할 내용

이 문서는 내부 상세계획이며 제출 보고서가 아니다. 제출 시 [공모요강의 공식 목차](../00-공모요강.md)를 따른다.

| 공식 절 | 본 주제의 내용 |
|---|---|
| 분석개요 | 지역별 예방활동을 차별화할 의사결정 질문과 확보 자료 |
| 분석방법 | 행정동 결합, 분모 보정, 품질 관리, 검증·시각화 절차 |
| 분석결과 | 실제 자료가 확보된 지도·비교·안정성 결과만 수록 |
| 활용방안 | 점검 후보 목록과 담당기관 검토 과정 |
| 기대효과 | 검토 지원 가능성 및 실제로 측정한 성과 구분 |
| 기타 | 데이터 출처, 예방활동 공식 근거, 재현 정보 |

**이번 문서의 완료 범위:** 상세 기획과 실사·검증 기준 정의. **후속 실행의 첫 완료 조건:** 소방 사건 샘플에서 기간·행정동·유형을 확인하고 기본안/상세안/축소/보류 중 하나를 근거와 함께 결정하는 것.
