# 현행 주제 안내

> 2026-09-13 사용자 결정. 주제 확정과 데이터 실사 완료는 구분한다.

**부산 신고 데이터를 활용한 지역 맞춤 정책제안**

- 축 1: 신고 위경도·발생일시 → 동별 시간·계절 특성 → 동별 연령 구성과 비교.
- 축 2: 상권의 업종·규모·기준시점 → 신고 유형·시간 특성과 비교.
- 분석·데이터·정책 판단은 [현행 실행계획](신고데이터-정책제안-실행계획.md)을 따른다.
- 현재 원본 실사 전. 다음은 신고자료의 공간·시간·유형 컬럼 확인이다.
- 동별 연령으로 신고 당사자의 나이를 추정하지 않는다. 인력 배치·동선·예측은 필수가 아니다.
