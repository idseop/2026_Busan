# 지명 중심 지도 변경 · 2026-09-16

도로·건물·시설이 포함된 OSM 래스터 타일을 제거했다. 부산 구·군 도형을 연녹색으로, 바깥을 옅은 파란색으로 표시하고 선택 지역은 청록 계열로 강조한다. 구·군 지명과 확대 수준 12 이상에서 읍·면·동 지명을 글자로만 표시한다. 충돌하는 지명은 더 확대하면 표시하며, 다른 지역으로 위치를 이동하지 않는다. 부산 바깥 차폐와 이동·축소 제한을 유지한다.

보유 SGIS 2025-06-30 경계로부터 최대 폴리곤 내부 대표점 206개를 생성했다. 모든 반올림한 대표점의 원래 폴리곤 내부 포함, 원본 해시와 기존 감사 속성 일치, 16개 구·군 대응을 검증했다. 현재 206개 지명은 과거 신고·인구 분석의 공간 배정에 사용하지 않는다. 기존 공개 분석 자료 7개 해시는 유지됐다.

생성 및 독립 자료 점검: `scripts/build_place_labels.py`, `data/processed/지도탐색웹-20260915/place-labels-validation.json`. 별도 에이전트가 자료 생성·검증과 지도 코드 읽기 검토를 수행했다. 브라우저 검사는 주 작업자가 별도로 수행했다.

기능 검사 `scripts/check_result_map.py` 190개 통과: 3개 PC 해상도, 지역·연도·조건 수치, 도로 타일 요청 없음, 지명 표시·충돌 방지, 부산 한정 이동, 파일 직접 열기 등. 실제 PC 브라우저 첫 화면과 지역 선택 화면을 캡처해 직접 확인했다. 타일 요청 0개, 브라우저 오류 0개. 기록은 `data/processed/지도탐색웹-20260915/result-map/`에 갱신했다.
