# 부산 119 결과웹: 공공지도 비교와 적용 판단

확인일: 2026-09-16. 이번 비교는 화면 설계 참고 조사이며, 외부 안전정보를 119 분석에 결합한 결과가 아니다. 2020~2024년 검증 집계의 분모·공간 단위는 유지한다.

## 1. 확인 방법

공식 사이트의 화면 문구와 이용안내를 열어 확인한 뒤, Chrome의 실제 표시 모드에서 초기 화면을 각각 한 차례 캡처했다. 지도를 일괄 이동하거나 타일을 미리 수집하지 않았다. 네 사이트 모두 HTTP 200으로 열렸으며 저장한 화면을 직접 시각 검토했다. 기능이 화면에 있다는 확인과 모든 조작을 시험했다는 주장은 구분한다.

- 재현 코드: `scripts/capture_public_map_reference.py`
- 캡처·본문·접속 기록: `data/processed/public-map-reference-20260916/`
- 실제 캡처: `busan-data-map.png`, `safemap.png`, `floodmap.png`, `safekorea.png`
- 캡처는 내부 비교 증거다. 지도 이미지·타일·정부 로고를 우리 웹 배경 자산으로 재배포하지 않는다.

부산생활지도는 부산 공식 데이터 사이트에서 연결을 확인했으나 `https://lifemap.busan.go.kr/` 및 `/li/index.do` 직접 열기는 이번 조회에서 시간초과했다. 검색된 `/html/index.html`은 제목부터 디자인 제안이며, `/html/b.html`에는 미래의 공지 예시도 존재한다. 이를 운영 중인 부산생활지도 화면 또는 정책 실적으로 취급하지 않았다. 대신 위의 실제 실행된 부산 데이터 지도 화면을 부산시 사례로 사용했다.

## 3. 화면 비교로 확인한 현재 웹의 문제

다음은 외부 서비스의 성과 주장이 아니라 우리 웹에 대한 설계 진단이다.

1. 단색 구역 면을 배경으로 사용하면 바다·산지·도시 구역의 차이를 읽기 어렵다. 지명을 줄이려다 지리 정보 전체를 지운 것이 문제다. 도로명·시설 상호를 숨기더라도 실제 도로 형태·수역·녹지·토지 이용 배경은 유지할 수 있다.
2. 클릭 후 건수와 인구만 나오면 사용자는 선택 지역의 의미를 판단하기 어렵다. 이미 보유한 반복 연도, 시간 분포, 지역 내 유형 비중, 처리조건 비교를 먼저 요약해야 한다.
3. 모든 지역을 똑같은 초록색으로 두면 분석 결과가 어디에 있는지 알 수 없다. 기본 지도와 신고 분포·심층 사례 등 결과 주제를 전환해야 한다.
4. 서비스 소개와 보완안의 근거 수준이 분리되지 않으면 기존 서비스를 우리 제안으로 오해할 수 있다. 기존 제공 사실, 분석 결과, 확정한 보완안 상태를 각각 짧게 표시해야 한다.

## 4. 이번 구현의 네 가지 우선순위

### A. 부산 안의 자세한 지리 배경 복원

부산 외부 가림과 이동 제한을 유지하고, 부산 내부의 수역·녹지·도시 토지 이용·도로 형상·확대 수준에 따른 건물 형상을 표현한다. 도로명·상호명·불필요한 아이콘은 숨긴다. 구·군·동 지명은 겹침을 제어해 별도로 표시한다. 정부 화면에서 확인한 지리 정보의 층위를 참고하는 것이며 정부 지도 자산을 복제하는 작업이 아니다.

### B. 지도가 답하는 결과를 선택 가능하게 구성

`기본 지도`, `신고 분포`, `심층 분석`처럼 단위를 가진 주제를 둔다. 신고 분포가 부산 선택 신고 중 구·군 비중이면 범례에도 동일한 정의와 % 단위를 쓴다. 심층 분석은 분석된 사례가 있는 구·군을 표시하는 기능이며 위험도가 높거나 정책 우선순위가 높다는 뜻으로 표현하지 않는다. 원문 동명이 확정 행정동 위치가 아닌 경우 소속 구·군만 강조한다.

### C. 건수 다음에 한 문장 결과와 증거 제시

선택 지역에서 가장 많은 유형, 고정 5년 반복 여부, 실제 분포상 높은 시간대, 전체 선택 신고와의 비교를 동일한 조건으로 보여준다. 예를 들어 제목은 계산한 결과로 작성하고 바로 아래에 해당 건수·비중·기간을 둔다. 근거가 있는 사례는 처리조건 비교와 주민 배경, 기존 서비스의 운영 사실까지 이어서 제공한다. 단순한 증감률을 위험 증가로 바꾸지 않는다.

### D. 기존 서비스 정보와 분석 기여를 명확히 연결

우리만의 차별점은 **부산 지역별 5년 신고의 반복 양상을 주민 구성 및 확인한 서비스 조건과 함께 읽을 수 있는 결과**다. 이는 제작 방향이며, 다른 서비스에 같은 기능이 전혀 없다는 독창성 검증이나 정책 효과 검증은 아니다. 기존 지도에서 얻는 시설 위치·최신 상황과 달리 우리 결과에서는 기간을 맞춘 신고 패턴과 선택 영향, 사례별 대응 비교가 핵심이다. 서비스 부족이 입증되지 않았으면 확정한 보완안이 없다는 상태까지만 제시한다.

## 5. 채택하지 않는 표현과 추가 자료의 범위

- 실시간 재난처럼 깜빡이는 가짜 사건점, 임의 위험 등급, 신고 건수 기반 경보를 만들지 않는다.
- 공식 지도에 자료가 존재한다는 이유로 AED·침수·건설공사 자료를 모두 추가하지 않는다. 선택한 신고 사례를 설명하는 질문과 연결 기준이 확인된 자료만 후속 분석 대상으로 삼는다.
- 홍수지도는 가정에 따른 결과이며 과거 신고와 동일한 사건 기록이 아니다. 해당 페이지에는 공공누리 제4유형 이용 조건도 명시돼 있다. 이번 작업은 화면 구성을 참고하며 그 도형을 복제·수정·결합하지 않는다.
- 현행 시설·서비스 정보는 2020~2024년 당시 운영 상태를 대신하지 않는다.
- 공식 사이트 캡처를 보았다는 것은 해당 데이터의 완전성·좌표·서비스 효과까지 검증했다는 뜻이 아니다.

## 6. 인수 검증 기준

상세 지리 배경이 실제로 표시되고 부산 외부는 보이지 않는지, 주제를 바꾸면 범례·지도·목록·상세의 값과 정의가 일치하는지, 사례가 없는 지역을 위험이 없는 지역처럼 표시하지 않는지, 지역 클릭으로 신고 건수 이후의 검증 결과까지 읽을 수 있는지를 확인한다. 사용성 개선 효과는 구현된 화면과 조작 검증으로 보고하며 실제 주민 대상 사용성 조사로 확정한 효과라고 주장하지 않는다.
