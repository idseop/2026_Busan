# 부산 한정 지도 수정 · 2026-09-16

기존 실제 배경지도 화면에서 부산 밖 지형이 노출되던 문제를 수정했다. 현재 보유한 부산 16개 구·군 도형의 바깥에 불투명 마스크를 적용해 인접 도시의 도로·지명을 가린다. 부산 내부 도로·지명과 구·군 선택 기능은 유지한다. 새로운 동 경계나 신고 위치를 생성하지 않았다.

이동 범위를 부산 경계의 외접 범위로 제한하고, 최소 확대 수준을 화면 크기에 맞춰 계산한다. 전국 범위로 축소되지 않는다. ‘부산 전체’ 버튼은 보유 경계에 포함된 부산의 모든 섬을 포함한다. 마스크는 지리적 비율이나 원본 경계·집계를 바꾸지 않는다.

## 검증

- `scripts/check_result_map.py`: 187개 검사 통과. 1920×1080·1600×900·1366×768 화면, 16개 지역 선택, 연도·처리조건·종별 조합 수치, 빈 결과, 배경지도 실패·재시도, 공개 데이터 7개 파일 해시를 확인했다.
- 이번 추가 검사: 불투명 마스크, 16개 구·군 도형, 김해·양산 위치 차폐와 부산시청 위치 비차폐, 전국 축소 차단, 서울로 이동 차단을 확인했다.
- 자동 검사에서는 외부 타일 요청을 대체했다. 실제 배경지도는 `scripts/view_result_map.py`로 별도 PC 브라우저에서 확인했다. 첫 화면 타일 16개 로딩, 실패 0개, 브라우저 오류 0개. 첫 화면 캡처를 직접 검토해 부산 외부가 가려지고 내부 도로·지명이 보이는 것을 확인했다.
- 이번 수정 검증은 기존 검증과 분리해 로컬에서 수행했으며, 추가 독립 검토자의 승인을 받은 것으로 표현하지 않는다.

검증 기록과 화면: `data/processed/지도탐색웹-20260915/result-map/`. 재현 순서는 `check_result_map.py`, 로컬 서버 실행 후 `view_result_map.py`, `package_result_map.py`이다.

## 실행 및 전달

`web/final/실행.cmd`를 실행하고 http://127.0.0.1:8765/ 를 연다. 실제 배경지도에는 인터넷 연결이 필요하다. 최신 ZIP은 `output/부산119-지도결과웹-20260915.zip`이며, 기존 파일명을 유지해 갱신한다. 타일 제공자와 이용 조건은 기존 실제지도 결과 보고서와 웹 README에 기록돼 있다.
