# 부산 신고 지도: 서비스형 화면 개편

## 현재 문제와 판단

기존 화면은 공식 도형의 작은 외곽 섬까지 같은 화면에 맞춰 주요 지형이 작았다. 검색 항목과 선택값은 9~10px 수준이었으며, 전처리·지역 연결 용어가 기본 화면에 반복됐다. 또한 시간 교차집계와 주민 자료, 네 심층 사례, 공식 서비스 자료가 있었지만 지역 상세에서 분석 흐름을 한 번에 읽기 어려웠다.

따라서 입력을 다시 전처리하지 않고 지도 표시 범위·글자·용어·상세 정보 구조를 수정했다. 원본 공개 데이터 7개는 기존 고정 해시를 기준으로 보존한다. 현재 서비스의 공백이나 정책 효과를 새로 확정한 작업은 아니다.

## 지도와 기본 화면

PC의 주요 지형 보기와 전체 경계 보기를 구분한다. 본토·가덕도·영도를 크게 보여주되 지리적 비율과 원본 도형을 유지한다. 작은 외곽 섬은 전체 보기로 확인한다. 지도 글자의 화면 크기와 검색·필터의 글자 크기를 키우며, 좁은 구의 이름은 배경과 연결선으로 경계선에서 분리한다.

기본 화면에는 지역명, 연도, 신고 조건, 건수와 선택 조작을 남긴다. ‘완전행’, ‘참고 경계’, ‘원문 동명’ 등 내부 분석 용어는 쉬운 표현으로 바꾸거나 도움말로 옮긴다. 자료가 없는 지역을 0건으로 만들거나 동의 실제 위치를 임의 배정하지 않는다.

## 신고에서 검토까지 연결한 상세

`web/final/assets/detail-extension.js`는 기존 집계를 재합산해 선택 지역·기간·처리조건·유형에 맞춘 요약을 만든다. 별도 데이터 다운로드나 외부 API 없이 직접 파일 실행을 지원한다.

1. 선택 조건의 건수와 주요 유형, 가장 많은 4시간 구간을 제시한다. 시간대는 접수 건수의 비교이며 실제 위험률이나 시간당 발생률을 뜻하지 않는다.
2. 2020~2024년 반복 여부와 시간 상세, 같은 연도 말 주민 배경으로 연결한다. 전체 기간 선택 시 인구는 2024년 말 한 시점이다.
3. 네 심층 사례에 해당하면 해당 지역·유형의 질문과 서비스를 연결한다. 구군 상세에서는 사례의 실제 동 이름을 명시한다.
4. 서비스의 대상·시간·이용 방법·지역·기준일·공식 출처를 함께 제공한다. 기관의 운영 정보를 과거 신고 당시 실적으로 간주하지 않는다.
5. 확인된 이용 안내와 아직 판단할 수 없는 서비스 확대를 구분하고, 후속 판단에 필요한 자료를 구체적으로 제시한다.

## 사례별 연결

| 지역·유형 | 화면에서 연결한 내용 | 남은 판단 |
|---|---|---|
| 기장읍·질병 | 건강센터, 방문건강관리, 응급 구급의 역할·대상·이용 방법 | 인지도·미이용 사유·대기 현황을 확인한 뒤 안내·연계 개선 검토 |
| 정관읍·질병 | 같은 군의 기록 차이와 방문건강관리의 이용 조건 | 기록 손실과 실제 미충족 필요 확인 전 자원 배분 순위 보류 |
| 연산동·질병 | 반복·시간 특징, 구급 서비스, 개별 주민 자료 선택 | 상세 주소 연결 전 특정 행정동에 대한 보완안 보류 |
| 금곡동·시건개방 | 반복·포함조건 민감도, 기존 구조 서비스 | 문을 열어야 했던 이유·인명위험 여부 확인 전 특정 서비스 제안 보류 |

네 사례에 해당하지 않는 지역에는 선택한 유형과 관련된 후속 질문과 필요한 자료를 표시한다. 다른 지역의 서비스나 분석 결과를 복사하지 않는다. 벌집제거는 심층 사례에 추가하지 않는다.

서비스 설명의 출처와 정리 기준은 [서비스형 상세 근거 검토](부산-119-서비스형상세-근거검토-20260915.md)에 기록했다. 기존 공식 페이지의 보존본과 검증 자료로 현재 화면 질문에 답할 수 있어 이번 변경에서는 새 외부 자료를 수집하지 않았다.

## 코드·검증·전달

- 화면: `web/final/index.html`, `assets/app.js`, `assets/style.css`
- 상세 요약: `assets/detail-extension.js`, `assets/detail-extension.css`
- 요약 재합산 검증: `scripts/check_detail_stories.py`
- 지도·필터 회귀 검증: `scripts/check_map_explorer.py`
- PC 화면·상세 사례 독립 검증: `scripts/check_pc_map_refinement.py`
- 최종 해시·ZIP: `scripts/package_map_explorer.py`

상세 요약 검증은 16구군과 네 사례 지역의 연도·조건·유형별 1,800개 조합에서 건수, 시간대 합계, 요일 합계, 월 합계를 별도의 공개 지역 집계와 대조했다. 이 검증은 새로운 분석 적합성 또는 대표성 검증을 대신하지 않는다.

검증 결과는 `data/processed/지도탐색웹-20260915/service-stories/`, `browser/`, `pc-refinement/`에 기록한다. 수정 전 화면은 `pc-refinement/large-before/`에 보존한다. 최신 배포 파일은 `output/부산119-지도탐색웹-20260915.zip`이며 압축을 풀고 `index.html`을 PC 브라우저에서 연다.

최종 회귀 검증은 90개 필터 조합·110개 상세 상태를 통과했다. 독립 PC·서비스 검증은 470개 검사를 통과했으며, 세 PC 해상도의 주요 지형과 전체 보기, 지명·필터 크기, 실제 지역 클릭, 연도별 사례 수치와 공식 서비스 연결을 확인했다. 주요 지명은 화면 기준 17px, 필터·정렬은 14px로 표시한다.

최종 ZIP에는 공개 집계와 화면 파일 13개만 포함했다. 압축 CRC와 모든 파일 해시가 원본 웹 폴더와 일치하며, 입력 공개 데이터 7개도 변경되지 않았다. 대표 화면은 `pc-refinement/1600-initial.png`, `1600-detail.png`, `service-population.png`, `service-response.png`, `service-next.png`에 저장했다.
