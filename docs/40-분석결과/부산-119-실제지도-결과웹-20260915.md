# 실제 배경지도와 결과 중심 웹

## 변경 결과

`web/final/`을 Leaflet 1.9.4와 OpenStreetMap 표준 배경지도로 전환했다. 실제 도로·지명·수역이 지도 영역 전체를 채운다. 기존 구군 도형은 투명한 선택용 경계이며, 수치를 지역 위험도로 면색에 표현하지 않는다. 동명 선택 시 소속 구군만 강조한다.

자체 지명 상자·연결선·후광·비례원은 제거했다. 지명은 배경지도에 포함된 표시를 사용한다. UI의 보라색은 남색·청록 계열로 교체했다. 첫 화면은 본토·주요 섬 중심, 전체 보기는 작은 섬까지 포함하며 지리 비율과 원본 도형은 유지한다.

지역 상세의 질문 목록과 FAQ 펼침을 제거했다. 확인된 건수·유형·시간·주민 구성과 기존 서비스 비교 결과를 표시한다. 확정된 보완안이 없는 지역은 상태 한 문장만 제공한다. 전체 연령표는 별도 버튼으로 열 수 있다.

## 목적·문제·대응·결과

부산의 지역별 신고 특성과 주민 구성을 살펴보고 기존 대응과 연결되는 예방·지원 정보를 정리하는 것이 목적이다. 기존 검증 결과의 네 사례를 재사용했다. 주요 신고 유형과 시간 집중은 사실로 제시하지만, 주소와 서비스 이용 실적이 부족하다는 이유로 서비스 공백을 주장하지 않는다.

현재 제공한 결과는 지역별 신고·시간·인구의 연결과 공식 서비스의 역할·대상·시간·이용 조건 비교다. 실제 서비스 부족이나 시설·인력 확대의 효과는 확정하지 않았다. 기장읍의 건강상담·방문관리·응급구급 안내를 구분했으며 다른 지역의 시설로 복제하지 않았다. 벌집제거는 집중 검토에 추가하지 않았다.

상단 ‘분석 결과’에 목적·전체 주요 결과·사례 선정 이유·기존 대응 비교·확정 범위를 묶었다. 원자료 전처리와 7개 공개 입력 파일은 변경하지 않았다. 기존 사실을 결과형 화면에 연결한 작업이며 새 정책 효과 분석은 아니다.

## 지도 선택 근거

[Leaflet 공식 배포](https://leafletjs.com/download.html)에서 안정 버전 1.9.4 및 배포 해시를 확인했고, 로컬 vendor에 라이브러리와 [BSD 라이선스](https://github.com/Leaflet/Leaflet/blob/v1.9.4/LICENSE)를 보존했다.

[OSM 표준 타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/)에 따라 HTTPS URL, 실제 HTTP Referer, 브라우저 캐시, 상시 출처 표시를 사용한다. 타일은 일반 화면 요청으로만 로딩하며 사전 수집·ZIP 포함·오프라인 저장 기능은 없다. 파일 직접 실행에서는 타일을 요청하지 않고 로컬 서버 실행 방법을 표시한다. API 키를 요구하지 않는 방식으로 현재 로컬 결과물에 적용했다.

배경지도는 외부 네트워크에 의존한다. 실패하면 지역 결과와 경계 선택은 유지하면서 연결 오류와 재시도 버튼을 표시한다. 현재 배경지도 상세도가 2020~2024 신고 위치의 정확도를 향상시킨다는 주장은 하지 않는다.

## 검증

`scripts/check_result_map.py`는 실제 외부 타일 요청을 모두 합성 타일로 대체해 3개 PC 해상도, 16구군 선택, 90개 필터 조합, 사례별 수치, 결과 모달, 이동·확대·초기화, 타일 실패·재시도·파일 모드를 검사한다. 새로운 코드의 작성과 테스트는 별도 실행 단계로 수행했으며 이번 버전의 독립 에이전트 최종 검토는 실행 한도로 완료하지 못했다. 이전 버전의 독립 검사 수치를 이번 버전의 검사로 사용하지 않는다.

실제 지도는 별도의 headed Chrome에서 초기 화면과 한 지역 선택을 열어 확인했다. 대량 지도 이동이나 타일 수집은 수행하지 않았다. 증거는 `data/processed/지도탐색웹-20260915/result-map/live/`에 저장했다. 타일 응답 수와 Referer, 브라우저 오류도 기록한다. 합성 타일 검증 캡처를 실제 배경지도 화면으로 전달하지 않는다.
