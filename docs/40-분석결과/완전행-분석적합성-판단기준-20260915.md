# 17개 완전행의 분석 적합성 판단 기준

2026-09-15. 사용자 요청은 ‘70만 건이 남았으니 분석해도 괜찮은지 판단 기준을 잡고 실제로 평가’하는 것이다. 선택한 17개 컬럼과 결측행 제외 방식은 유지한다. 제외 전 자료는 손실 영향을 진단하는 비교 자료로만 사용하며 현재 분석표를 몰래 바꾸거나 결측을 대체하지 않는다.

이 기준은 기존에 확인한 전체 건수·이동전화 집중·종별 잔존 차이를 알고 있는 상태에서 작성했다. 새로운 경로별 결측 원인·분포 거리·후보 민감도 결과를 보기 전에 비교 항목과 판정 논리를 정한 것이며, 완전히 데이터와 독립된 사전등록 연구라고 표현하지 않는다.

## 비교 모집단과 단위

- 지정 원본은 2020~2024 CSV 5개이며 모두 해시로 추적한다.
- 비교 기준은 부산 명시이며 기존 8개 값이 모두 있는 1,334,514행이다. 이것도 지역 미기재 등을 제외한 부분집합이므로 부산에서 발생한 모든 신고·사건의 완전한 모집단은 아니다.
- 현재 분석 집합은 그중 17개 모두 비결측인 704,689행, 제외 집합은 두 집합의 차이인 629,825행이다.
- A 전체 처리, B 정상, C 정상 중 업무운행·훈련출동·구급차소독 제외를 구분한다. 조건별 분모를 섞지 않는다.
- 지리 단위는 검증 전 원문 구군·읍면동 조합이다. 실제 행정동 분석 적합성은 별도의 공간 연결 조건을 통과해야 한다.

## 실행할 진단

1. **경로별 결측 원인:** 일반전화·IP전화·공중전화 등이 선택된 어떤 컬럼의 결측 때문에 빠지는지 연도·경로·컬럼 및 결측 조합으로 집계한다. 컬럼별 결측은 중복 합산하지 않는다. 한 조건을 제외했을 때 복원 가능한 수는 원인 진단이며 실제 분석표 변경이 아니다.
2. **정보 포함 범위:** 연도·경로·종별·구군·원문 동별 잔존율과 완전히 사라진 범주를 확인한다. 이름이 남았다는 것만으로 건수·구성 보존을 인정하지 않는다.
3. **분포 차이:** 구성비 차이(%p)와 TVD=0.5×Σ|제외전 구성비−완전행 구성비|를 계산한다. TVD 0은 관측 범주의 구성비가 같고 1은 겹치지 않음을 뜻한다. 인과관계나 결측 무작위성을 검정하는 지표가 아니다.
4. **이동전화 내부 비교:** 전체 경로 차이와 이동전화 안에서의 추가 선택 차이를 분리한다. 이동전화 비중이 높다는 사실만으로 완전행이 이동전화 전체를 대표한다고 판단하지 않는다.
5. **반복·변화 민감도:** 원문 동×세부유형별 연도 관측 여부와 2020→2024 변화 방향을 전후 비교한다. 0을 기준으로 한 증가율은 만들지 않는다. 작은 수에서 방향이 바뀌는 사례와 규모가 있는 사례를 구분해 원자료 수를 함께 제시한다.
6. **순위 진단:** 상위 10·20·30 목록의 교집합/Jaccard와 동률 처리한 순위 상관을 비교한다. k번째 값과 같은 동률 항목은 전부 포함하므로 목록 수가 k보다 클 수 있다. Spearman은 비교 범주 합집합에 한쪽의 0건도 포함하고 평균 순위를 사용한다. 이는 필터의 영향 점검이며 동이나 정책의 선정 규칙이 아니다.
7. **희소 셀 민감도:** 연간 최소 건수 0·1·5·10·20을 차례로 바꿔 반복 판단이 달라지는지 공개한다. 0 기준도 관측은 양수 건수로 정의해 0건을 관측으로 바꾸지 않는다. 따라서 정수 건수의 0·1 기준은 동일한 결과가 된다. 어느 하나를 결과에 맞춰 선택해 후보를 확정하지 않는다.

TVD 몇 % 이하, 순위 상관 몇 이상이면 무조건 ‘괜찮다’는 임의 통과선을 두지 않는다. 판단은 **질문에 필요한 정보가 남았는지, 관측된 차이가 실제 주장·선정을 바꾸는지**를 근거로 한다. 대규모 표본에서 작은 차이도 유의해질 수 있으므로 p값 중심의 검정을 추가하지 않는다. 결측 메커니즘을 MCAR/MAR/MNAR 중 하나로 확정하거나 보정 가중치를 자동 적용하지 않는다.

## 다음 작업의 결정

- 관측 집합의 기술통계가 검증되면 17개 완전행의 탐색은 계속한다.
- 일반화 조건을 충족하지 못하면 결과 제목과 분모를 ‘선택한 17개가 모두 기재된 신고’로 제한하고, 이 집합만으로 부산 전체 건수나 행정동 우선순위를 확정하지 않는다.
- 방향·반복 판단이 바뀐 항목은 보류 기록에 남긴다. 안정적으로 보인 항목도 공간·기존 대응 검증을 생략하지 않는다.
- 분석 목표에 필요한 정보가 제외됐다면 그 사실과 필요한 기록 규칙·자료를 명시한다. 이번 적합성 평가에서 컬럼/행 선택을 변경하지 않는다.

## 방법 근거와 적용 한계

결측행을 제외한 결과의 편향 여부는 결측 비율이나 남은 수만으로 정해지지 않고, 분석 대상과 결측 발생 과정의 관계에 달려 있다. [Sterne 등, BMJ 2009](https://www.bmj.com/content/338/bmj.b2393). 대규모 자료도 선택 편향을 해결하지 못할 수 있다는 실제 연구 근거가 있다. [Bradley 등, Nature 2021](https://www.nature.com/articles/s41586-021-04198-4). 두 연구는 판단 원칙만 참고하며 임상·백신조사의 수치나 효과를 부산 신고에 옮기지 않는다. 결측 대치나 설문 가중을 본 분석에 도입하지 않았다.
