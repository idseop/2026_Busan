# 부산 119 지도 탐색 웹 개편

주 사용 환경은 **PC 브라우저**다. 1600×1000 화면에서 왼쪽 탐색 패널·중앙 지도·오른쪽 상세 패널을 검증했다. 첫 화면은 상세 패널을 닫아 부산 지도를 더 넓게 보여준다.

## 변경 범위

이번 작업은 검증한 분석 데이터의 재분석이 아니라 `web/final/`의 사용자 화면과 탐색 흐름 변경이다. 지도보다 설명·차트·카드가 먼저 보이던 긴 페이지 구조를 지도 앱으로 재구성한다.

화면 상단에는 짧은 제목과 공통 조작을 둔다. 왼쪽에는 검색·연도·종별·처리조건·구군·정렬과 원문지역 목록, 가운데에는 화면 높이를 채우는 부산 지도, 오른쪽에는 선택 지역의 상세 정보를 둔다. 문서 전체를 스크롤하는 대신 좌우 패널 내부만 스크롤한다. 모바일에서는 검색 패널과 상세 시트를 열고 닫으며 지도로 돌아간다.

## 데이터와 공간 단위

신고는 2020~2024년 선택17 완전행 704,689건의 기존 집계를 재사용한다. 기존 지도·지역시간·주민 인구·사례·공식 서비스 자료는 변경하지 않는다. 입력 해시는 `data/processed/지도탐색웹-20260915/input_freeze.json`에서 관리한다.

지도 클릭은 **구군 집계 상세**, 원문 동 목록 클릭은 **원문 동 집계 상세**를 연다. 위치가 확정되지 않은 원문 동은 소속 구군을 강조하며 임의의 동 점이나 경계를 생성하지 않는다. PC 가독성 개편에서는 경계를 가리던 비례원과 상시 숫자 상자를 정리하고, 지역명과 경계 중심으로 탐색하도록 변경한다. 건수는 마우스 올림·키보드 초점·상세 정보에서 확인한다. 현재 경계를 과거 5년의 동일 경계로 간주한 면적 위험지도는 만들지 않는다.

주민 인구는 같은 연도 말 자료를 사용하고, 5년 전체 신고 선택 시에는 2024년 말 주민 배경을 표시한다. 구군 인구는 해당 구군의 서로 다른 행정동 코드를 한 번씩 합산하며 원문 동 이름별로 중복 합산하지 않는다. 원문 동은 검증된 코드 후보를 사용하고 여러 후보는 개별 선택한다.

## 탐색 흐름

1. 첫 화면에서 부산 전체 지도와 왼쪽 탐색 패널을 본다. 지역 상세는 아직 선택하지 않은 상태다.
2. 지도에서 구군을 고르거나 왼쪽에서 원문 지역을 검색한다.
3. 선택한 공간 단위의 요약·추세·시간·주민·기존 대응을 오른쪽에서 확인한다.
4. 필터를 변경하면 지도 기호와 목록·상세의 수치가 같은 조건으로 갱신된다.
5. 상세를 닫거나 초기화하면 지도를 넓게 탐색할 수 있다.

건수 정렬과 이름 정렬은 탐색 편의 기능이며 위험 순위가 아니다. 세부유형은 기존에 교차집계가 있는 사례의 상세로 제공하고, 전체 지역에서 지원되지 않는 세부분류 필터를 만들어 표시하지 않는다. 그래프와 긴 설명은 오른쪽 상세 또는 도움말 안에 둔다.

## 실행

`web/final/index.html`을 직접 열면 실행된다. 외부 CDN·배경 타일·API 키 없이 기존 공식 참고 도형과 공개 집계만 사용한다. 로컬 서버를 사용할 경우 프로젝트 루트에서 다음 명령을 실행한다.

```powershell
.venv-check/Scripts/python.exe -m http.server 8080 --bind 127.0.0.1 --directory web/final
```

접속 주소는 `http://localhost:8080/`이다. 원본 신고 파일과 구버전 시제품은 서버나 웹 ZIP에 포함하지 않는다. 상세 분석과 해석은 [지도·심층 사례 보고서](부산-119-지도와-심층사례-20260915.md)를 따른다.

## 실행 검증과 전달물

- `scripts/check_map_explorer.py`: 연도·처리조건·종별 90개 조합에서 16구군 지도 수치를 원본 공개 집계와 대조하고 상세 110개 상태를 확인했다. PC 화면의 지도 크기, 지역 선택·검색·필터·확대·이동·초기화 및 직접 파일 실행과 HTTP 실행을 검증했다.
- 독립 검토 `analysis/00_공통/review_map_explorer_20260915.py`: 124개 검사 통과. 구군 인구 중복 합산, 원문동 시간 집계, 복수 인구 후보의 개별 선택과 빈 상태를 확인했다.
- 기존 공개 데이터 7개는 입력 고정 해시와 같으며 새 분석값을 만들지 않았다. 브라우저 검증 기록은 `data/processed/지도탐색웹-20260915/browser/result.json`, 독립 검토 기록은 같은 폴더의 `independent_review.json`이다.
- 최신 배포 ZIP: `output/부산119-지도탐색웹-20260915.zip`. 압축을 풀고 `index.html`을 PC 브라우저로 열면 된다. 패키지 검증은 `scripts/package_map_explorer.py`로 실행하며 모든 압축 파일의 해시와 CRC를 대조한다.
- PC 첫 화면: `data/processed/지도탐색웹-20260915/browser/desktop-initial.png`
- PC 지역 선택 화면: `data/processed/지도탐색웹-20260915/browser/desktop-selected.png`
- 수정 전 화면: `data/processed/지도탐색웹-20260915/before/desktop-map.png`

이번 완료 범위는 PC 지도 탐색 화면의 재구성과 검증이다. 위치 미확정 원문동의 실제 행정동 배정이나 정책 효과 검증을 새로 완료했다는 뜻은 아니다.

## PC 가독성 후속 개편

사용자 피드백에 따라 지도 영역 안에서 부산 지형이 차지하는 크기, 지역 경계를 가리는 표시, 지명 배치, 상단 문구와 연도 선택을 개선한다. 화면 기준은 1920×1080·1600×900·1366×768이다. 기존 해석 기준과 공개 집계는 유지한다.

상단 제목은 ‘부산 신고 지도’, 왼쪽 제목은 ‘지역 검색’으로 정리한다. 연도는 전체 기간과 2020~2024년 개별 버튼으로 선택한다. 화면의 반응은 즉시 갱신되지만 데이터는 과거 기록이며 실시간 상황을 뜻하지 않는다. 실시간 현황을 제공하려면 별도의 공식 갱신 자료와 이용 권한·공개 범위·갱신 주기 검증이 필요하다.

수정 직전 PC 화면은 `data/processed/지도탐색웹-20260915/pc-refinement/before/`에 보관한다. 이전 절의 검증 수치는 해당 실행 버전의 기록이며, 후속 개편의 화면 검증은 `scripts/check_pc_map_refinement.py`와 `pc-refinement/`의 기록으로 구분한다.

### 실제 적용 결과

- 지도 viewBox를 `130 -45 570 650`에서 `130 30 570 515`로 변경했다. 도형 좌표와 지리적 비율은 유지하면서 상하 여백을 줄였다. 독립 브라우저 측정에서 지도 투영의 화면상 면적 배율은 수정 전 대비 약 1.59배이며, 1366×768의 상세 패널 열린 상태에서는 약 1.55배다.
- 비례원과 상시 숫자 상자를 제거했다. 지명은 검증된 구군 내부 대표점 가까이 두고 좁은 곳만 짧은 연결선으로 보완했다. 마우스·키보드 초점에 건수 툴팁을 제공한다.
- 옅은 청색 배경, 중립 연보라 육지, 보라색 선택 강조, 맞춤 조작의 앰버 색을 적용했다. 색은 위험도나 지역별 신고 순위를 나타내지 않는다.
- 연도 버튼은 지도·목록·상세·선택 표시와 연동된다. 필터 초기화 시 전체 기간으로 복원한다.
- 최종 코드에서 기존 회귀 검증 90개 필터 조합·110개 상세 상태를 다시 통과했다. 변경 전후 공개 데이터 7개는 해시가 동일하다.
- PC 독립 검사에서는 기본 화면·상세 화면, 연도 연동, 16개 지명 클릭·마우스·키보드 동작 등을 포함한 269개 검사를 통과했다. 3개 해상도에서 지도 경계·지명 잘림과 지명 간 겹침은 없었다. 마지막 시각 검토에서 발견한 추세 그래프 첫 값과 세로축 눈금의 간섭은 첫 값 왼쪽 정렬·마지막 값 오른쪽 정렬로 수정하고 추가 검증했다.

후속 화면은 `pc-refinement/1920-initial.png`, `1600-initial.png`, `1366-initial.png`와 같은 이름의 `-detail.png`에 기록했다. 상세 독립 검사와 최종 파일 해시는 `pc-refinement/result.json`, ZIP 검증은 `delivery.json`에서 확인한다. 검증 코드 실행 순서는 `scripts/check_map_explorer.py` → `scripts/check_pc_map_refinement.py` → `scripts/package_map_explorer.py`다.
