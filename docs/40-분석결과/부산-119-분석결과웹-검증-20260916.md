# 분석 결과 및 웹 전달 검증

2026-09-16. 기존 원본·7개 동결 공개 데이터는 변경하지 않았다. 새 분석은 별도 경로에서 수행하고 웹에는 집계된 결과 보고서를 추가했다.

- 분석·인구·연보의 독립 재계산: `data/processed/예방지원-근거분석-20260916/verification/independent_counts.json`과 `independent_review.md`. 작성 코드와 별개 검증 코드 사용.
- 새 결과 웹: `scripts/check_action_report_20260916.py`. 1920×1080·1600×900·1366×768, 10개 사례와 6개 그림 로드, 가로 넘침 없음, 파일 직접 열기, 지도→결과 페이지 이동을 실행했다. 브라우저 자바스크립트 오류 없음.
- 기존 지도 회귀: `scripts/check_result_map.py`의 200항목 통과. 이 검사는 배경 타일을 차단하는 실패 상태 검사도 포함하며 실제 외부 타일 로딩 검증과 구분한다. 이번 변경은 새 결과 링크와 정적 결과 폴더다.
- 결과 화면 PNG 직접 확인: 1600 PC 첫 화면과 주택화재 사례, 시간·연도 시각화. 사상구 한정 서비스가 기장·온천에 연결되던 부분을 제거했다. 해당 사례에는 부산 단위 공식 지원 정보만 표시한다.
- 독립 보고서 검토에서 연보 발행연도와 실적연도 표현, 모집 달성률과 차이의 구분, 미기재 자료 기준일, 독립 ZIP 내부 지도 링크를 수정했다.
- ZIP은 `zipfile.testzip()`으로 손상 여부를 확인했다. 각 결과 폴더의 `manifest.json`에 파일별 SHA-256을 기록했다.

## 실행
프로젝트 루트에서 `.venv-check/Scripts/python.exe web/final/serve.py --no-browser`를 실행하고 `http://127.0.0.1:8765/results/`를 연다. 서버가 이미 실행 중이면 다시 띄우지 않는다. 지도는 `/`에서 열고 상단 ‘예방·지원 결과’를 누른다.

별도 서버 없이 `output/부산119-예방지원-분석결과-20260916/index.html`을 열어도 그림·표·사례를 확인할 수 있다. 공식 출처 페이지와 지도 배경은 인터넷이 필요하다. 로컬 주소는 공개 배포 URL이 아니다.
