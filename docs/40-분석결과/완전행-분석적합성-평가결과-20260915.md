# 70만 완전행으로 무엇을 분석할 수 있는가

2026-09-15. **704,689건의 17개 완전행은 해당 관측 집합을 설명하는 기술통계·탐색에 사용한다. 그러나 이 자료만으로 부산 전체 동의 신고 규모·위험·정책 우선순위를 정하는 것은 현재 목적에 적합하지 않다.** 건수가 적어서가 아니라, 결측 제외가 접수경로와 지역에 따라 다르게 작동하고 일부 반복·증감 판단도 바꾸기 때문이다.

사용자 요청대로 17개 컬럼과 ‘하나라도 결측이면 해당 행 제외’ 조건은 그대로 유지했다. 이번에는 제외 전후를 비교하여 결과의 사용 범위를 결정했다. 과거의 ‘현재 분석 입력으로 채택’은 전처리 집합의 확정이며 전체 지역 비교의 대표성까지 확인했다는 뜻이 아니었다. 이번 평가로 그 해석 범위를 구체적으로 제한한다.

## 1. 판단 기준과 비교 대상

[판단 기준](완전행-분석적합성-판단기준-20260915.md)을 추가 진단 결과 확인 전에 기록했다. 기존에 알려진 이동전화 비중·종별 잔존 차이는 알고 작성했음을 명시했다. 임의 종합점수·보편적인 최소 표본 수·TVD 통과선은 만들지 않았다.

비교 기준은 부산 명시이며 기존 8개 값이 모두 있는 1,334,514행이다. 그중 현재 17개 완전행 704,689행과 추가 제외행 629,825행을 대조했다. 기준 자료도 지역 미기재 등이 빠진 부분집합이며 부산에서 발생한 모든 사건의 모집단이라고 보지 않는다. A 전체 처리, B 정상, C 정상 중 업무운행·훈련출동·구급차소독 제외를 각각 계산했다.

판정 항목은 원본 추적·결측 및 집계 검증, 접수경로 포함 범위, 연도/유형/동/시간 분포 변화, 이동전화 내부 선택 영향, 반복·증감·규모 순위의 민감도, 행정동 연결의 검증 상태다.

## 2. 일반전화가 빠진 실제 이유

| 접수경로, A조건 5년 | 기존 8개 완전행 | 17개 완전행 | 확인한 결측 |
|---|---:|---:|---|
| 일반전화 | 141,540 | 0 | 사고발생 경도·위도가 각각 141,538행에서 결측. 좌표가 있는 2행도 현장구군이 결측 |
| IP전화 | 16,676 | 0 | 사고발생 경도·위도가 전부 결측 |
| 공중전화 | 568 | 0 | 사고발생 경도·위도가 전부 결측 |
| 이동전화 | 973,466 | 704,396 | 선택한 컬럼의 동시 기재 조건을 통과한 비율 72.36% |

일반전화라는 값을 삭제한 것이 아니다. 해당 경로의 신고 행에 다른 선택 컬럼의 값이 없어 제외된 것이다. 이것은 직접 방문 접수를 누락한 문제와 다르다. 왜 제공기관에서 해당 경로의 좌표를 그렇게 기록하는지는 별도 기록 규칙 확인이 필요하다. ‘일반전화는 기술적으로 위치 확인 불가’ 같은 원인은 이 결과만으로 단정하지 않는다.

한 컬럼의 비결측 조건만 해제했을 때 복원 가능한 건수도 진단했다. 일반전화는 현장구군 조건을 해제할 경우 2행만 복원 가능하며, IP·공중전화는 어느 단일 컬럼 조건을 해제해도 복원 행이 없다. 좌표 한 쌍 등 여러 결측이 겹치기 때문이다. **실제 필터는 바꾸지 않았다.**

## 3. 이동전화끼리 비교해도 지역별 제외 비율이 다르다

이동전화 내부 종별 구성은 5년 합계에서 비교적 비슷했다. 구급 비중은 77.7973%→78.0159%(+0.2186%p), 종별 TVD는 0.002727이었다. 다만 연도별 종별 TVD는 2020년 0.012464로 더 컸고, 합계의 안정성을 모든 연도에 그대로 적용하지 않는다.

| 원문 지역, 이동전화 A조건 5년 | 제외 전 | 제외 후 | 잔존율 |
|---|---:|---:|---:|
| 기장군 정관읍 | 18,036 | 7,491 | 41.53% |
| 기장군 기장읍 | 20,595 | 19,442 | 94.40% |
| 북구 금곡동 | 12,276 | 11,216 | 91.37% |

이 사례들은 지역별 정보 손실을 설명하기 위한 것이며 예방 대상 선정이 아니다. 같은 이동전화라는 이유만으로 동별 비교가 균등하게 보존되는 것은 아니다. 원문 지역명이 아예 사라지는 경우가 없어도 건수와 비중은 달라질 수 있다. 위 이름은 원문 지역이며 검증된 행정동별 총신고로 해석하지 않는다.

이동전화 내 현장구군 결측은 262,681행이었다. 그 조건 하나만 해제하면 나머지 16개 조건을 충족하는 225,256행이 복원 가능하다. 이 역시 결측 원인 진단일 뿐 조건 변경이나 값 대체가 아니다.

## 4. 유형·시간·동 분포와 후보 판단에 미친 영향

TVD는 두 구성비 분포의 절대 차이를 합해 2로 나눈 값이다. 0은 같은 분포, 1은 겹치지 않는 분포를 뜻한다. 아래는 C조건의 연도별 최소~최대 값이며 무작위 결측 검정이나 정책 효과가 아니다.

| 비교 차원 | 5개 연도 TVD 범위 |
|---|---:|
| 종별 | 0.0439~0.0667 |
| 세부유형 | 0.0528~0.0720 |
| 원문 동 | 0.0505~0.0565 |
| 월 | 0.0047~0.0224 |
| 시간 | 0.0099~0.0169 |
| 요일 | 0.0037~0.0131 |

관측된 비교에서 시간 구성의 변화가 유형·동보다 작았지만, 이것만으로 시간 특성이 부산 전체를 대표한다고 승인하지 않는다. 비슷한 주변 분포가 동×유형×시간의 모든 교차 분포가 같음을 뜻하지도 않는다.

벌집제거를 제외한 원문 동×세부유형 조합에서 다음 변화가 나타났다.

| C조건 진단 | 제외 전 | 제외 후 또는 반전 수 |
|---|---:|---:|
| 5년 모두 1건 이상 관측 | 3,010조합 | 2,325조합: 685조합이 5년 관측 조건에서 빠짐 |
| 매년 5건 이상 | 1,687조합 | 1,180조합 |
| 매년 10건 이상 | 1,228조합 | 838조합 |
| 매년 20건 이상 | 874조합 | 526조합 |
| 2020→2024 증가·감소 방향 반전 | 비교 합집합 6,869조합 | 401조합 |
| 위 반전 중 전후 두 연도 건수가 모두 20건 이상 | 사례 범위 제한 | 50조합 |

최소 연건수 0·1·5·10·20은 민감도 비교용이며 어느 하나를 정책 대상의 통과선으로 채택하지 않았다. 0 기준도 양수 관측을 요구하므로 정수 건수에서 1 기준과 같다. 685는 완전히 사라진 동이나 유형의 수가 아니라 ‘5개 연도에 모두 관측된다’는 조건에서 빠진 조합 수다.

실제 예로 C조건 원문 북구 구포동의 구급 ‘부상’은 제외 전 261→280건으로 증가했지만, 17개 완전행에서는 143→134건으로 감소했다. 이는 두 끝 연도의 단순 변화이며 시계열 추세검정 결과가 아니다. 특정 원인을 확인한 것도 아니지만, 결측 제외가 분석의 방향을 바꿀 수 있음을 보여준다.

원문 동 규모의 전체 순위상관은 높았어도 동×유형의 상위 목록은 달랐다. C조건 동×유형 상위 10개 목록의 Jaccard는 연도별 0.538~0.818이었다. k번째 건수와 같은 동률 항목은 모두 포함했고 k=10·20·30을 함께 비교했다. 높은 전체 상관계수를 이유로 같은 대상이 선정된다고 판단하지 않는다.

## 5. 목적별 최종 사용 결정

| 분석 용도 | 결정 | 적용 방법 |
|---|---|---|
| 17개가 모두 기재된 신고의 연도·유형·시간 특성 | 사용 가능 | 704,689행의 관측 집합으로 명시하고 A/B/C 분모 구분 |
| 선택된 신고의 위치·현장지역·관할 기록 품질 | 사용 가능 | 불일치·좌표 정의·미확인 정확도를 기록. 자동 대체 금지 |
| 동·유형의 반복성 및 변화 탐색 | 조건부 사용 | 원문명칭 기준, 제외 전후 민감도를 함께 표시. 민감한 결과를 확정 주장으로 사용하지 않음 |
| 이동전화 전체의 동별 분포 대표 | 단독 사용 부적합 | 같은 이동전화 내부에도 지역별 잔존 차이가 확인됨 |
| 부산 전체 신고 규모·구성 대표 | 단독 사용 부적합 | 실제 존재하는 일반전화 등 접수경로가 전부 빠짐 |
| 행정동 위험 순위·집중 예방 대상 확정 | 보류 | 선택 영향·실제 동 배정·기존 대응 근거를 함께 해결해야 함 |
| 주민 연령과 개별 환자 연령 연결 | 사용 불가 | 동별 연말 인구는 배경이며 연령별 사건 수를 대신하지 않음 |

‘부적합’은 70만 행을 버리라는 뜻이 아니다. 질문별로 허용되는 사용을 분리한다. 전체 접수를 설명하거나 지역 우선순위를 확정하는 데는 필요한 정보가 선택적으로 빠졌고, 그 영향을 상쇄할 근거가 현재 없다는 판단이다. 표본 수가 크면 선택 편향이 자동으로 없어지지 않는다는 방법론 근거는 [판단 기준의 참고문헌](완전행-분석적합성-판단기준-20260915.md)을 따른다.

## 6. 반영한 후속 작업과 추가 확인

17개 완전행과 그 분석 결과는 유지하고, 이후 보고·지도 결과의 범위를 ‘17개가 모두 기재된 신고’로 제한했다. 기존 8개와의 비교 결과는 품질·민감도 근거로만 연결한다. 전처리 원본·제외 기록·해시는 변경하지 않았다. 전체 부산 또는 동별 위험 순위를 확정하는 단계는 진행하지 않는다.

지금 가능한 후속 분석은 검증된 17개 관측 집합의 기술통계, 원문 동별 특성에 대한 포함조건 민감도, 공식 동 후보 대응과 기록 품질 확인이다. 다음 외부 확인 질문은 접수경로별 좌표 기록 규칙, 지역별 현장구군 미기재의 기록 과정, 당시 경계와 실제 신고 위치의 대응이다. 새로운 시설·서비스나 정책을 먼저 고르지 않는다.

필요한 검증이 끝나기 전까지 ‘신고가 적은 동’, ‘수요가 감소한 동’, ‘대응 공백이 큰 동’ 같은 결론을 이 부분집합의 건수만으로 확정하지 않는다. 최종 정책 단계가 가능해지려면 빠진 정보를 확보하거나 분석 대상의 범위를 근거에 맞게 별도로 정해야 한다.
