# 부산 동별 119 신고 특성과 예방·지원 검토 결과

**최신 후속 결과:** [지도와 지역별 심층 사례](부산-119-지도와-심층사례-20260915.md)에서 지역×시간 교차집계, 네 사례, 공식 서비스 대조, 지도 중심 웹 개편을 이어서 확인할 수 있다. 아래는 최초 최종 집계의 기준 기록이다. 현재 `web/final/`은 후속 결과를 통합하며, 지도는 검증한 원문 구·군 집계를 비례기호로 표시한다. 이전의 단순 지도 탐색 설명과 최초 웹 검증은 당시 버전에 대한 기록이고, 최신 검증은 `data/processed/심층분석-20260915/`를 따른다.

대상 기간은 2020~2024년이다. 선택한 17개 컬럼이 모두 기재된 신고접수 704,689행을 분석하고, 결측 제외에 따른 선택 영향·공식 동 대응·주민 전체 연령 배경을 함께 정리했다. 결과는 `web/final/`의 독립 웹페이지로 제공하며 구버전 웹의 신고·인구 집계를 사용하지 않는다.

**결론의 범위:** 이 결과는 완전행에 기록된 신고의 기술통계와 추가 검토를 위한 탐색이다. 부산 전체 동의 위험 순위나 새로운 정책의 효과를 확정하지 않는다. 행정동 위치 미확인·조건부 인구 연결·기존 대응의 미확인 항목은 결과의 일부로 공개한다.

## 1. 무엇을 분석했는가

원본은 지정된 2020~2024년 신고 CSV 5개와 같은 해 12월 말 읍면동별 주민 연령 인구 5개, 소방본부 컬럼 설명서다. 원본·전처리본·제외·미연결 기록을 분리했고 파일 해시가 검증 기록과 일치하는 데이터를 재사용했다.

선택한 신고 컬럼 17개 중 하나라도 결측인 행은 제외했다. 17개에는 식별번호·신고일시·재난지역·유형·처리결과·접수경로·두 좌표쌍·현장지역·관할기관이 포함된다. 시간 중복 필드는 검증한 신고일시에서 파생한다. 컬럼 설명서의 38개 정의와 현재 5개 CSV 헤더가 모두 대응함을 확인했다. [컬럼별 선택과 제외 근거](컬럼-사용목적과-전체결측조건-20260915.md).

| 단계 | 신고접수 행수 | 해석 |
|---|---:|---|
| 지정 원본 전체 | 4,552,768 | 접수행이며 사건·출동·환자 수가 아님 |
| 재난시도 부산 명시 | 1,342,960 | 시도 미기재를 부산 밖으로 판단하지 않음 |
| 기존 8개 완전행 | 1,334,514 | 제외 영향 비교용 기준 |
| 현재 17개 완전행 | 704,689 | 이번 신고 분석의 관측 집합 |

시도 미기재 3,209,808행, 부산 명시 중 기존 8개 결측 8,446행, 추가 9개 결측 629,825행을 별도 추적한다. 단계별 제외는 중복되지 않지만 컬럼별 결측은 중복될 수 있어 합산하지 않는다.

구급이 가장 많다. C조건에서 구급은 2022년 106,641→2024년 93,652건, 구조는 11,921→13,942건으로 서로 다른 변화를 보였다. 처리조건을 바꾸면 분모와 유형 구성도 달라지므로 화면에 선택한 조건을 명시한다.

월·계절·요일·시간대는 같은 연도·처리조건·종별에 맞춰 비교한다. 관측 일수와 달력 일수, 구간을 구분하며 모든 날짜에 기록이 있다는 사실을 원천 추출의 완전성으로 해석하지 않는다.

C조건 구급은 5년 여름 합계 127,746건/460일(일평균 277.71건), 겨울 111,668건/452일(247.05건)이었다. 겨울은 같은 달력연도의 1·2·12월이다. 4시간 구간으로 나누면 08~11시가 102,952건으로 가장 많았다. 이는 선택집합의 접수시점 비교이며 발생 원인·생활인구 대비 위험을 뜻하지 않는다.

## 3. 지역 차이를 얼마나 신뢰할 수 있는가

현재 완전행은 이동전화 접수 704,396행(99.9584%)에 집중된다. 일반전화 141,540행·IP전화 16,676행·공중전화 568행은 선택한 다른 필드의 결측 때문에 모두 제외됐다. 일반전화라는 범주 자체를 삭제한 것은 아니다.

같은 이동전화 안에서도 원문 정관읍은 제외 전 18,036→7,491행(41.53%), 기장읍은 20,595→19,442행(94.40%)이 남았다. 동 이름이 남아 있다는 사실만으로 동별 규모와 구성이 균등하게 보존됐다고 볼 수 없다.

C조건에서 벌집제거를 제외한 원문 동×세부유형의 5년 모두 관측된 조합은 3,010→2,325개로 줄었다. 벌집제거를 제외한 C조건 전체 원문 동×세부유형 6,869개 조합 중 2020→2024 증가·감소 방향이 반전된 조합은 401개였고, 필터 전후 두 연도에 모두 20건 이상인 사례가 50개 포함됐다. 401개는 앞의 5년 반복 목록 2,325개에 한정한 수치가 아니다. 원문 구포동의 구급 ‘부상’은 제외 전 261→280건이지만 완전행에서는 143→134건이었다. 실제 동 위험이나 원인을 뜻하는 사례가 아니라 필터 민감도를 설명하는 사례다.

따라서 지역·유형 탐색에는 잔존율·반복성·포함조건 민감도를 함께 제시한다. 전체 순위상관이 높아도 최종 대상의 안정성을 보장하지 않는다. [분석 적합성 평가](완전행-분석적합성-평가결과-20260915.md).

## 4. 원문 동과 주민 배경은 어떻게 연결했는가

5년 모든 부산 명시 원문지역×연도 조합 976개(결측 포함)에 공식 코드 후보와 보류 이유를 부여했다. 단일·다중·미등록·시점 불확실을 구분했고 여러 행정동에 걸친 명칭을 인구 비례로 나누지 않았다.

연중 코드기록·단일 후보·연말 코드 조건을 통과한 664개 원문명칭×연도 행에 주민 배경을 조건부로 연결했다. 서로 다른 원문명이 같은 행정동 인구를 참조할 수 있어 연결표의 인구를 합산하지 않는다. 이 연결은 실제 신고 위치나 해당 행정동의 총신고가 확정됐다는 뜻이 아니다. [공식 동 대응 검증](원문동-행정동-대응검증-20260915.md).

최종 작업에서 일광면·읍의 기록을 접수일과 대조했다. 2022년 완전행의 원문 일광면 652건 중 338건은 개편일 전, 314건은 2022-04-01 이후였다. 일광읍 509건은 모두 개편 후였지만 2023년에도 일광면 4건이 남았다. 옛 명칭의 일괄 치환 없이 구간별 상태를 보존했다. 당시 경계의 공식 SGIS 신청은 로그인 필요 상태여서 과거 경계 확보·신고 공간 배정은 완료로 표시하지 않는다.

인구는 매년 205개 읍면동을 모두 유지하며 0~99세와 100세 이상 인원·비중을 제공한다. 부산 읍면동 인구 합계는 2020년 3,391,946명에서 2024년 3,266,598명으로 줄었고 65세 이상 비중은 19.39%에서 23.90%로 늘었다. 다만 전체 연령 구성을 유지하며 이를 ‘고령자의 신고가 증가했다’고 바꾸지 않는다. 인구는 12월 말 주민 구성이고 연간 신고와 관측 시점이 같지 않다.

![부산 주민 전체 연령 구성의 변화](../../data/processed/최종결과-20260915/figures/04_population_age_composition.png)

## 5. 어떤 대상을 더 검토할 것인가

웹의 원문 동·유형 반복 탐색은 대상 확정을 위한 순위표가 아니다. 관측 연도 수·연간 최소 건수·제외 전후 변화·연결 상태를 확인하는 탐색 기록이다. 최소 연건수 1·5·10·20을 바꿔 볼 수 있도록 하되 어느 하나를 최종 정책 대상의 통과선으로 고정하지 않는다. 벌집제거는 이 탐색과 추가 조사·제안에서 제외한다.

확인할 질문은 다음으로 좁힌다.

1. 관측된 구급 중심 신고 특성과 관련해 이미 제공되는 신고·정보전달·상담 서비스는 무엇인가?
2. 접수경로별 좌표와 현장구군 기록은 왜 다르게 기재되는가?
3. 연중 행정구역 개편 후에도 옛 동명으로 기록된 신고는 어떻게 해석해야 하는가?
4. 실제 위치·공간 연결이 확인된 이후, 어느 지역·유형의 반복성이 포함조건을 바꿔도 유지되는가?

이 질문에 필요하지 않은 상권·공사·생활인구 자료는 보유하고 있다는 이유만으로 결합하지 않는다. 보완자료의 채택과 보류, 현재 서비스와 과거 신고의 시점 차이는 별도 공식 근거 문서에 기록한다.

## 6. 기존 대응과 보완 후보의 해석

현재 데이터에는 관할소방서·센터 이름이 있지만 운영 시간·이용 조건·서비스 범위·가용 자원·성과까지 포함돼 있지 않다. 공식 서비스 근거와 실제 신고 관측을 대조하되 관할 이름이나 시설 거리만으로 대응 공백을 인정하지 않는다.

검토 기록은 ‘이미 확인한 대응’, ‘아직 모르는 이용·운영 범위’, ‘그 정보가 필요한 이유’, ‘추가 확인 뒤 판단할 보완 가능성’을 분리한다. 특정 지역에 새 시설·순찰·돌봄을 배치해야 한다는 결론은 현재 근거로 확정하지 않는다. 피해 감소나 신고 감소 효과도 약속하지 않는다.

| 기존 대응 | 확인한 사실과 시점 | 지역별 보완안을 위해 남은 질문 |
|---|---|---|
| 119안심콜 | 2023·2024 공식 안내에서 사전 등록·등록 전화번호 사용·정보 변경 시 수정 조건을 확인. 전국 서비스로 부산에 적용되지만 동별 이용 범위는 미확인 | 동별 등록·갱신·실제 활용률과 등록지원의 운영 범위는 어떠한가? |

안심콜의 등록상담창구 시간, 다매체의 채널별 장애·응답목표, 과거 구급상황관리센터의 인력·대기시간은 확보 근거에서 확인되지 않았다. 2026년 공지를 2020~2024년 운영 증거로 사용하지 않는다. 자료의 원문/웹 추출/공식 검색 추출 구분과 URL·조회일·해시는 `response_evidence.json`에 남겼다. [최종 보완자료 공식 근거](최종-보완자료-공식근거-20260915.md).

## 7. 웹에서 결과를 읽는 방법

`web/final/index.html`이 현재 결과의 진입점이다. 연도·처리조건·종별로 신고 지표와 시간 분포를 바꾸고, 원문 지역 상세에서 잔존율과 동 연결 상태를 확인한다. 주민 배경은 해당 연도의 행정동 코드 기준으로 별도 탐색한다. 인구를 5년 합산하지 않는다.

지도는 공식 경계의 확인된 기준일을 명시한 지역 탐색용이다. 검증되지 않은 과거 동별 신고를 지도에 색칠하지 않고 미연결을 0건으로 표시하지 않는다. 원문 지역 선택이 적용되지 않는 부산 관측집합 시간 차트는 그 범위를 별도로 밝힌다.

웹에는 집계만 제공하며 접수번호·정밀 신고 위치·원본 행 기록은 넣지 않는다. 기존 웹의 구버전 데이터는 결과 패키지에 포함하지 않는다.
