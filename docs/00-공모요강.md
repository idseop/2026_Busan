## ⚠️ 미확인 항목과 작업 가정

**주최측 문의는 하지 않기로 결정했다 (2026-08-19).**
따라서 아래 항목은 답을 기다리지 않고 **가정을 세워 진행한다.**
가정이 틀릴 경우의 손실을 줄이는 방향(= 보수적으로 더 준비하는 쪽)으로 잡았다.

| # | 미확인 항목 | **작업 가정** | 틀렸을 때 |
|---|---|---|---|
| 1 | 접수 시 제출물 범위 | **기획서까지 낸다고 가정** — 문제정의·데이터·예상결과물·제안 + 차트 1~2장 | 신청서만이었다면 남는 산출물은 본선에서 그대로 쓴다. **손실 없음** |
| 2 | 양식·분량·파일 형식 | **A4 5~10쪽 PDF** 가정. 양식 종속 요소를 최소화해 작성 | 양식이 공지되면 내용 재배치로 대응 가능 |
| 3 | 심사 배점 | `critic` 에이전트의 잠정 배점을 기준으로 삼는다<br>(문제정의 25 / 데이터실현성 25 / 분석설계 20 / 시각화 15 / 제안 15) | 실제 배점과 달라도 다섯 축은 어느 심사에나 공통 |
| 4 | **오픈랩 데이터 접근 방법** | **접근 불가로 가정.** 공개 공공데이터만으로 성립하는 주제를 고른다 | 접근 가능해지면 보강 재료로 추가. **주제가 흔들리지 않음** |
| 5 | 팀원 개별 신청 필요 여부 | 작년 규정대로 **전원 개별 제출 필요**하다고 가정, 팀원 일정 미리 확보 | 불필요했다면 손실 없음 |
| 6 | 공고문 원본 PDF | 미확보 상태로 진행 | — |
| 7 | 개회식/OT 유무 | 없다고 가정 | 공지되면 일정에 추가 |

> **가정 4가 주제 선정에 직접 영향을 준다.** 오픈랩 데이터에 의존하는 아이디어는
> 채점에서 데이터 실현성을 낮게 준다. 공개 데이터만으로 완결되는 주제를 우선한다.
