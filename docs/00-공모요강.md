## 제출물 — 공식 서식으로 확정 (2026-08-21)

| 항목 | 확정 내용 |
|---|---|

| **분량** | **10P 이하 (표지 제외) — "준수 필요"** 명시 |

### 공식 목차 (붙임 2)

```
1. 분석개요
   ▢ 문제 정의   ◦ 배경  ◦ 필요성
   ▢ 분석 요약   ◦ 활용데이터  ◦ 분석도구  ◦ 분석기법  ◦ 추진과정
   ▢ 분석결과
   ▢ 활용방안 및 기대효과
2. 분석방법
   ▢ 활용데이터  → 표: 데이터명 / 형식 / 대상기간 / 출처 / 비고
   ▢ 분석방법    ◦ 분석도구(툴)
                 ◦ 데이터 전처리 내용 및 검증 여부
                 ◦ 분석기법 및 분석절차
                 ◦ 분석결과 검증방법        ← 별도 항목이다. 빠뜨리면 감점
                 ◦ 시각화 방법
3. 분석결과
   ※ 인사이트 / 시각화 결과 / 검증 결과 / 결과의 한계 및 보완점
4. 활용방안
   ▢ 적용부문   ▢ 정책 활용 방안
5. 기대효과
   ▢ 정량적     ▢ 정성적
6. 기타 (참고문헌)
```

> **서식이 직접 요구하는 것 두 가지에 주의한다.**
> - **분석결과 검증방법** — "결과가 맞다는 걸 어떻게 확인했나"를 별도 항목으로 요구한다
> - **결과의 한계 및 보완점** — 한계를 스스로 쓰라고 명시했다. 숨기면 오히려 감점 요인

### ★ 붙임 4 — 추가 가점 항목

**공식적으로 가점이 붙는다.** 서식에 별도 붙임으로 존재한다.

| 가점 항목 | 서식이 요구하는 기재 내용 |
|---|---|
| **1. 데이터 오픈랩 방문** | 방문일시 / 방문자 / 사용데이터 |
| **2. Big-데이터웨이브 사용** | 데이터명 + **브라이텍스(Brightics) 사용결과 캡처** |

서식의 활용데이터 표 **예시**가 이것이다:
`동백전 사용내역 / csv / 년.월∼년.월 / 출처: 부산 빅데이터 오픈랩`
→ 오픈랩이 실제 데이터 제공처이며, **동백전(지역화폐) 같은 민간 데이터**를 제공한다는 뜻.
서식에 *"제공한 민간데이터 외 추가 활용한 민간데이터 있을 시 반드시 기재"* 라고 적혀 있다
= **주최측이 참가자에게 민간데이터를 제공한다.**
