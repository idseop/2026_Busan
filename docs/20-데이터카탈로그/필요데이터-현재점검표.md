## 실제 열어본 결과의 의미

이전 점검에서 119·전국 인구 10개와 상권 20개·생활인구 2개의 실제 헤더·원본 해시를 기존 전행 검사와 대조했다. 당시 원본이 바뀌지 않았음을 확인한 뒤 기존 전행 검사 수치를 재사용했으며 신고 건수를 다시 분석한 것은 아니다. 컬럼 설명 38개도 읽었다. 현재 인구 입력은 전국 공식 다운로드에서 행정구역 코드가 26으로 시작하는 부산 222행만 추출한 5개 CSV로 전환한다. 원본의 310개 열 값과 CP949 인코딩을 유지하며, 직접 새로 내려받은 부산 전용 공식 파일로 표현하지 않는다. 과거 전국 감사 기록과 현재 추출본의 해시를 혼동하지 않는다.

- 신고의 사고발생 좌표 설명은 환자발생 위치이고, 손상지역 좌표는 손상 발생 지역이다. 둘의 공란 수가 다르다는 이유만으로 임의 대체하지 않는다. 동 이름에 법정동·행정동이 어떤 기준으로 기록됐는지도 확인해야 한다.
- 주민등록 인구는 시·구군·동의 계층과 계·남·여를 포함하므로 중복 합산하지 않는다. 동의 인구 비율로 실제 환자 나이를 만들지 않는다.
- 상권에는 상호·업종·주소·행정동/법정동 코드·좌표가 있다. 실제 공사현장의 위치·공사기간·진행 상태를 보여주는 자료는 아니다. 업체 주소와 작업 현장을 구분한다.
- 상권은 판본 내 깨진 행·업소번호 중복이 없으나 표준산업분류·건물번호 등 일부 열이 비어 있다. 정확한 누락 수는 분기별 감사 기록에 있다.
- 건축자료는 허가·착공·사용승인 단계와 여러 건물 행을 포함한다. 한 행을 한 현장으로 보거나, 행정처리일을 실제 공사 시작·종료 시점으로 단정하지 않는다. 위치를 지도에 표시하려면 주소의 공간 변환·검증도 필요하다.
- 생활인구 시간표와 연령표는 별도 자료다. 임의로 시간×연령 교차값을 만들지 않는다. 20대 미만·60대 이상 범주에서 아동·65세 이상만 정확히 분리할 수 없다.

## 빠진 것과 확인 순서

1. **신고를 동에 연결할 기준:** 좌표 정의·좌표계, 당시 동 경계, 행정동·법정동 코드 대응. 파일을 보유한 것과 공간 연결 검증 완료를 구분한다.
2. **선택한 예방안의 기존 대응:** 화재 장비 위치·이용 조건·진입 여건, 돌봄·안전활동의 실제 대상·구역·시간 등. 기관 위치만으로 운영 공백을 확정하지 않는다.
3. **보완자료의 적용 조건:** 상권 분기의 시간 대응, 건축 단계 간 연결과 주소 확인, 생활인구·1인세대의 제한된 기간. 없어도 가능한 비교와 반드시 필요한 비교를 구분한다.

다음 작업은 위 목록에서 미확보·정의 미확인 항목의 제공 경로와 연결 조건을 확인하는 것이다. 아직 예측모형이나 특정 예방안을 결정하지 않으며, 데이터 점검을 마친 뒤 프롬프트를 다시 작성한다.
