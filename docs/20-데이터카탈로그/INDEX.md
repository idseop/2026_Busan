# 데이터 카탈로그 — 단일 진실 원천

**실사(내려받아 실물 확인)를 마친 데이터셋만 등재한다.**
목록에서 제목만 본 것은 등재하지 않는다. 여기 없는 데이터로 만든 주장은 무효다. (CLAUDE.md 하드 룰 3)

등재는 `/datacheck` 또는 `data-scout` 에이전트가 수행하며, 기존 행은 보존하고 추가만 한다.
