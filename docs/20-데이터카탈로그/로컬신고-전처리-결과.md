# 로컬 신고 전처리 결과

출력: `data/processed/신고17개-로컬전처리-20260917-133450`

부산 명시·선택17개 공란 제외 기준을 원본에 직접 적용했다. 헤더 대소문자만 통일하며 값은 보존했다.

| 연도 | 원본 | A | B | C | 기존 보고서 A/B/C 일치 |
|---|---:|---:|---:|---:|---|
| 2020 | 838,114 | 114,236 | 100,073 | 99,661 | True |
| 2021 | 937,504 | 139,189 | 113,965 | 113,037 | True |
| 2022 | 1,013,380 | 158,478 | 127,241 | 126,252 | True |
| 2023 | 896,935 | 149,390 | 121,311 | 120,187 | True |
| 2024 | 866,835 | 143,396 | 116,822 | 115,525 | True |

A/B/C는 연도별 CSV.GZ로 저장했다. 압축 해제하거나 pandas.read_csv로 바로 읽는다.

- A: 부산 명시 및 선택17개 모두 기재, 총 704,689건.
- B: A 중 처리결과 `정상`, 총 579,412건.
- C: B 중 분류명 `업무운행`·`훈련출동`·`구급차소독` 제외, 총 574,662건.
- 각 파일은 선택17개와 원본 파일·행 번호, 연도·월·시간·요일·계절을 포함한다.
- `제외기록_연도.csv.gz`는 A에 포함되지 않은 모든 행의 원본 위치·지역 상태·결측 컬럼을 기록한다. B/C의 추가 제외는 A의 처리결과·분류명으로 재현한다.

```python
from pathlib import Path
import pandas as pd

folder = Path('data/processed/신고17개-로컬전처리-20260917-133450')
df = pd.concat([
    pd.read_csv(folder / f'C_{year}.csv.gz', dtype=str, keep_default_na=False)
    for year in range(2020, 2025)
], ignore_index=True)
```

실행은 저장소 루트에서 `.venv/Scripts/python.exe analysis/00_공통/preprocess_local_receipts.py`로 한다. 매번 새로운 출력 폴더를 생성한다.

원본 해시 유지·행 수 대사·일시 유효성·선택17개 공란 0·B/C 포함조건·출력 재독검증을 확인했다.

별도 `verify_local_receipts.py`로 원본 4,552,768행이 A 또는 제외기록에 정확히 한 번씩 포함되는지, C⊆B⊆A인지 확인했다. 연도별 9행씩 총45행은 원본의 17개 값과 출력 문자열이 동일한지도 대조했다. 결과는 출력 폴더의 `독립검증.json`에 있다. 원문 값 대조는 표본검사이며 전수 문자열 비교는 아니다.

좌표 0·숫자 변환 불가·도 단위 범위 이상은 별도 집계만 하며 임의 제거하지 않았다. 세계 경위도 범위 검사는 좌표계 검증이 아니다.

빈값 제거에 따른 접수경로·지역 선택 편향이 있으므로 부산 전체 위험도로 해석하지 않는다. 행정동 배정·인구 및 상권 결합은 수행하지 않았다.

행별 제외 사유와 원본 행 번호는 출력 폴더에 보존했다. 접수번호·정밀좌표가 포함된 전처리 파일은 Git에 올리지 않는다.
