# 2025년 데이터 확보와 목표 기간

**이 문서는 이전 기간 검토 기록이다. 현재 확정 기간은2020~2024년5년이며2025년 추가 확보를 진행 조건으로 삼지 않는다.** 현재 입력은 `data/interim/분석입력-2020-2024/manifest.json`을 따른다.

목표는2023~2025년3년이다.2025년 부산119 접수 원본과 같은 시점의 보완자료를 확보하면2020~2025년6년으로 넓힐 수 있다.2010년대는 새 분석에 포함하지 않는다. 현재 보유한2018~2024년 전체 원본을 삭제하라는 지시는 아니며, 기존 원본·감사 기록의 수치를 새 기간의 결과로 표시하지 않는다.

상품402에 보이는2025-12-15는2024년 파일의 등록일이다. 상품404의2025년 자료는 특정소방대상물 현황으로 신고접수 원본을 대신하지 않는다.2025년 통계연보의 시 전체 수치를 동·좌표별 신고로 배분하지 않는다.2025 접수 원본은 존재하지 않는다고 단정하지 않으며, 이번에 확인한 공개 목록에서는 찾지 못한 상태다.

상권의 실제 과거 목록은2020~2024 각 연도0331·0630·0930·1231판을 표시한다.2025년은0331·0630·1030·1231판으로,20251030을20250930으로 임의 치환하지 않는다.20230630판의 등록일이2023-01-30으로 표시되는 불일치도 있어 파일명·등록일만으로 관측시점을 확정하면 안 된다. 원본 다운로드 가능성·실제 기준일·부산 포함·누락은 목록 확인 다음에 검사해야 한다. 근거는 `data/interim/기간검토-20260913/상권15083033_실제과거버전.json`이다.

다음 확보 경로는 제공기관에2025년 부산 전체 접수 원본 또는 동×시기×세부 유형 공식 교차집계의 제공 가능성과 공개 일정을 확인하는 것이다. 원본은 기존38열과 호환되는지, 실제 관측기간이2025-01-01~12-31인지, 좌표·처리 조건이 어떻게 제공되는지 확인해야 한다. 기관 연락·예약·신청은 이번 검토에서 실행하지 않았다.2025 미확보 상태에서3년 확보 완료를 선언하거나2010년대로 범위를 대신 넓히지 않는다.

## 문제제기와 방법론의 연결

부산소방의2025년 통계연보 발간 보도자료는 전체 신고 감소와 실제 출동지령 변화가 다르다는 점을 설명한다. 이는 전체 건수만으로 대응 수요를 판단하기 어렵다는 문제 배경에 활용할 수 있다. 해당 발표 자체도 데이터 기반 상황관리 개선을 추진한다고 밝히므로, ‘부산은 신고 분석을 하지 않는다’는 주장은 적절하지 않다.

검토할 연구 질문은 **‘부산의 동별 신고 유형·시간 특성과 인구·상권 배경을 함께 살폈을 때, 기존 시설·지원 범위와 맞지 않아 추가 검토가 필요한 구간은 어디인가’**다. 현재 공백이 이미 입증됐다는 문장이 아니라 데이터를 이용해 답할 질문이다. 과거 수난시설 개선 사례는 이 흐름의 선례로 참고하되 대상 지역·당시 공백을 현재로 복사하지 않는다.

작업에는 점-동 공간 결합, 유형 구성비 비교, 시간·계절 프로필을 우선 적용할 수 있다. 이후 필요할 때 공간 군집 검정·상권과 신고의 동반 분포 검정을 추가하고, 기존 시설·후보지·접근 조건이 확보되면 최대 커버 입지모형을 검토한다. 모델의 복잡함보다 어떤 결정을 돕는지와 자료가 그 결정을 뒷받침하는지가 우선이다. 상세 설명은 [방법론 보고서](../30-아이디어/신고기반-정책제안-방법론-딥리서치.md)에 있다.
