# 부산 신고 기반 예방·지원활동 — 확장 수집 결과

2026-09-10 현재. **부산 전체의 신고 특성에서 출발해 예방·지원활동 우선지역을 고르고 지도에서 비교한다는 방향을 유지한다.** 데이터 확보가 곧 인력 투입이나 순찰의 효과 입증을 뜻하지 않는다. 노인일자리 인력을 순찰에 투입하는 방안은 제외한다.

사용자 확정 분석기간은 **2018~2024년, 7년**이다. 연령별 주민등록인구도 해당7년 원본을 모두 확보했다. 7년을 확보하지 못한 자료는 실제 제공기간을 표시한다.

## 확보한 원본과 역할

샘플을 수집하지 않았다. 전국 단위로 배포되는 자료는 전체 원본을 보존하고, 실제 부산 행만 별도 추출했다. 시설 공식 웹페이지는 CSV로 오인하지 않도록 HTML 원본과 표 추출본을 구분했다.

위 확장분은 인구·1인세대 CSV10개, 시설 CSV3개·HTML2개, 교통 CSV2개와 아래 공식 경계 ZIP1개로 **원본18개**다. 이전에 확보한 119 원본·연보는 별도다. 원본 존재 여부와 사용 적합성은 구분한다.

## 전수 검사에서 확인한 사실

- 인구·1인세대 CSV10개는 각각310열, 전국 총38,654행이다. 결측·숫자오류·중복 지역코드·연령 및 성별 합계 불일치가 없었다. 부산은 각309개 숫자 열 모두 시 합계=16구군 합계=당해 읍면동 합계다. 읍면동은2018~2019년206개, 2020~2024년205개다. 상·하위 지역 행을 함께 더하면 중복 집계된다.
- 2024.12 부산 주민등록인구는 3,266,598명, 65세 이상은 780,576명이다. 1인세대는 661,868세대, 그중65세 이상은231,223세대다. 65세 이상 수치는 원본1세별 열을 정확하게 합산한 결과이며 신고 대상자를 추정한 값이 아니다.
- 시설 CSV3개 전국3,344행에서 열 수 오류0, 부산258행에서 완전 중복0이다. 치매시설57개의 주소1·좌표·법정동코드 공란0. 정상 범위의 좌표라는 검사와 실제 건물 위치 검증은 다르다.
- 교통 CSV2개는 CP949, 각각15열이다. 전국7,582행에서 행 길이 오류0. 부산831행에서 빈 셀·FID 중복0, 경위도 범위 검사 통과. 폴리곤 JSON이 읽히며 어린이 자료에는 MultiPolygon5행도 있어 단일 Polygon만 처리하는 지도 코드는 부적합하다.
- 모든 확보 파일에 SHA-256·출처·다운로드 조건 또는 URL을 기록했다. 이러한 검사는 수신 파일의 구조와 내부 일관성 확인이며, 제공기관이 원천 사건을 빠짐없이 공개했다는 증명은 아니다.

## 교통 자료는 연도 검증 후 사용

공식 소개는 어린이12세 이하, 노인65세 이상을 명시한다. 어린이는 1년간 반경200m 내 대상사고3건 이상(사망 포함시2건 이상), 노인은2021년부터 최근3년 사망·중상사고를 대상으로 반경100m 내5건 이상으로 기준이 바뀐다. 두 대상의 수를 같은 기준의 위험률처럼 비교할 수 없다.

다운로드 파일명은 `12_25_child.csv`, `12_25_oldman.csv`지만, 소개 페이지의 조회기간은2012~2024로 표시된다. 실제 CSV에는 **관측연도 열이 없고**, 사고다발지ID 앞4자리는2013~2026이다. ID접두·파일명만으로 발생연도를 만들어 붙이지 않았다. 관측기간 대응을 확인하기 전에는 2024년119 신고와 연도 결합하거나 연도별 순위를 내지 않는다. 원본 파일의 구군 등장 여부는 모든 시기를 합친 검사이며, 각 연도 모든 구군에 다발지역이 있다는 뜻이 아니다. 미등장 지역을 사고0으로 처리하지 않는다.

## 분석과 웹으로 이어지는 순서

공식 [SGIS 행정구역 통계 및 경계](https://www.data.go.kr/data/15129688/fileData.do) 전체 ZIP도 확보했다. 2025-06-30 경계에는 부산 시도1·구군16·읍면동206개가 있다. ZIP 269,032,521바이트의 전체53개 멤버 CRC 검사와 SHP/SHX/DBF 레코드수 대조를 통과했다. **SGIS 부산코드는21, 행안부는26이며, 경계는 Korea 2000 Unified 투영좌표(m)다.** 경위도로 간주하거나 코드 앞자리로 곧바로 연결하면 안 된다. 2024 인구205읍면동과도 수가 다르므로 당시 경계 대응 없이2018~2024 신고를 결합하지 않는다. 현재 역할은 공식 지도 경계 확보이며 연령 결측 보완 자료가 아니다.

[SGIS 자료제공](https://sgis.mods.go.kr/view/pss/requestData)의 공식 목록에는2018~2024년별 센서스용 행정구역 경계가 있으나, 다운로드 과정에서 로그인 안내로 전환됐다. 해당7년 원본은 미확보다. 공공데이터포털의 이번 공개 ZIP은2025년판이며, 이를7년의 당시 경계로 복제하지 않는다.

1. 부산 전체 접수를 처리결과·유형·시간별로 정리하고, 위치 결측을 유형별로 함께 표시한다. 지도에 표시 가능한 사건만 별도로 구분한다.
2. 지역 명칭·코드·경계 시점을 확인해16구군에서 비교를 시작한다. 읍면동은 행정동/법정동 대응이 검증되는 자료에 한해 세분한다.
3. 인구·1인세대·지원시설·교통사고 자료는 역할과 시점을 밝힌 별도 지도 레이어로 제공한다. 다른 모집단의 수를 더하거나 임의 가중치로 위험점수를 확정하지 않는다.
4. 대상별 구급 원본을 확보하면 제공기관의 대상 기준에 따라 별도 지역 비교를 한다. 확보 전에는 아동·노인 신고 우선지역을 확정했다고 주장하지 않는다.
5. 우선지역의 사건 특성이 확인된 뒤 적합한 예방·지원활동을 검토한다. 경로는 도로망·활동방식·운영시간 등 실제 제약이 확보됐을 때 설계한다. 현재 시설 위치만으로 인력 배치·고독사 예방 효과를 산출할 수는 없다.
