# 부산 119 원본 실사 기준

현재 입력 기간은 2020~2024년이다. 전체 원본 수집·감사 결과는 `data/interim/분석입력-2020-2024/manifest.json`과 [최신 확보 현황](2020-2024-추가확보와-공식출처.md)을 우선한다. 과거 2018~2024년 합계는 현재 5개년 수치로 표시하지 않는다.

실사에서 접수 행·처리결과·실제 유형·위치·시간·결측·중복·해시를 확인한다. 접수는 독립 사고나 환자 수가 아니며, 대상자 나이는 미확보다. 지역 인구나 공식 연보의 주변집계로 개별 신고 연령을 만들지 않는다.

원본 검사 코드는 analysis/00_공통/audit_119_receipts.cjs, 감사 요약 코드는 summarize_119_audit.cjs다. 이번 정리에서는 코드 문법만 검사했으며 데이터 분석·감사 재실행은 하지 않았다. 원본별 실제 검증 범위는 연결된 manifest를 따른다.
