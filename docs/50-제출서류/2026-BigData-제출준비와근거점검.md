### 2-3. 서식 자체의 확인과 원고 분량 검증의 구분

원본 XML에 더해 별도 숨김 한글 인스턴스에서 **공식 서식 사본만** 열어 문서 구조와 출력 환경을 확인했다. 사용자가 열어 둔 한글 창과 원본 파일은 변경하지 않았다. 전체 서식은 한글 문서 기준 8쪽이며 붙임 2는 3쪽의 표지와 4~5쪽의 본문 예시다. 이 2쪽 예시가 제출 본문 분량 제한을 뜻하는 것은 아니며, 명시된 제한은 표지 제외 10쪽 이하다.

이번 최신 요청에 따라 보고서 **MD 원고의 번호·내용·흐름을 수정**했으며 이 원고를 HWPX에 조판하지는 않았다. 따라서 본문 앞의 10쪽 배치표는 편집 목표로 표시하고 최종 분량 통과를 주장하지 않는다. 서식·환경 확인 증거는 `output/report-audit/hwp-render-capability.md`와 `output/report-audit/form-layout/`에 있으며, 시험 서식 PDF는 제출용 분석보고서가 아니다.

웹 `web/final/data/fire-stations.json`과 좌표·인원·차량 대수 91행은 모두 일치했다. 체험관 차종 원값 ‘해당없음’ 1행만 JSON 빈 문자열로 표시 생략한다. 원본 인원 0은 16행, 차량 0은 1행이며 의미가 확인되지 않았으므로 결측·인력 부재·출동불가로 임의 해석하지 않는다. 여러 차종이 한 행에 나열되어 전체 대수를 차종별 또는 구급차 수로 배분할 수 없다. 좌표계·정확한 현장 위치의 독립 검증과 세 CSV 상호 일치는 별개다.

두 구 보조표는 부산진구 6기관행/5위치/5안전센터, 중구 4기관행/2위치/2안전센터를 표시한다. 인원 원표 합계는 193/103명, 차량은 29/23대이나 실시간 가용량·부족 여부는 아니다. 중구 신고에 서구 소재 부민·충무센터 기록이 존재하여 소재지 경계로 관할을 닫을 수 없다는 보조 단서가 있다. 출동·도착시간·동시출동·관할 이력이 없으므로 자원 재배치 효과를 주장하지 않는다. 이전 불완전 49기관/47위치 목록과의 차이를 신규 기관 증가로 읽지 않는다.

참가 인원과 팀원 전원의 참가·개인정보 제공 동의는 확인되지 않았다. 개인 참가자는 팀원 정보에 `없음`을 입력한다. 개인 참가 시 지정 ZIP명의 팀명 부분 대체 방식은 확인된 규정처럼 만들지 말고 실제 폼 안내를 확인한다. 제목·분석요약 등 확인되지 않은 별도 폼 입력란을 추가하지 않았다.

## 8. 제출 파일 구성과 남은 작업

아래는 **제출 구성안**이다. 내부 파일명은 권장안이며 공식 지정 이름은 최상위 ZIP뿐이다.

```text
분야1. 빅데이터 분석 및 시각화_팀명.zip        [최대 1GB, 파일 1개]
├─ 01_분석보고서.hwpx                       [붙임2,접수번호공란]
├─ 01_분석보고서.pdf                        [표지제외10쪽이하]
├─ 02_시각화_1장.pdf                        [별도1쪽]
├─ 03_활용데이터/
│  ├─ 실제사용_신고2020-2024·설명서/
│  ├─ 실제사용_주민2020-2024·지역관계/
│  ├─ 실제사용_소방관서3종/
│  ├─ 실제사용_상권·생활인구·SGIS·보건/
│  └─ 집계CSV·출처·자료기간·해시목록/
└─ 04_근거와이용안내/                      [필요시 부가자료]
   └─ 데이터별사용범위·조건·코드·출처설명

개인정보_수집이용_동의서_전체.pdf            [ZIP과별도,최대100MB,파일1개]
```

실제 사용 원본·가공 CSV의 포함 범위와 제출 가능 범위를 확정하고 명세에 기록한다. 활용데이터 요구를 웹용 집계 JSON이나 링크만으로 대체하지 않는다. 원본에 분석 외 연도·지역이 함께 있다면 실제 사용 범위를 명세에 표시한다. 제한된 보조집계도 사용목록에 남기고 주 결론 채택 여부를 구분한다. 용량 때문에 원자료 대신 일부 집계만 내는 것이 허용된다고 단정하지 않는다. 파일별 목록·해시와 최종 ZIP 크기는 제작 후 검증해야 한다.

`output/부산119-최신지도와분석결과-20260918.zip` 등은 **웹 실행·공유 ZIP**이다. 이미 존재하더라도 HWPX 보고서·1장 PDF·현재 활용데이터를 갖춘 **대회 제출 ZIP**과 다르다. 두 구 분석의 기존 PDF도 공식 붙임2 보고서나 별도1장 시각화의 완성본이 아니다. 웹은 운영 검토의 부가 구현물로, 제출 필수물 대신 업로드하지 않는다.

| 항목 | 이번 작업 상태 | 다음 작업 |
|---|---|---|
| 최신 근거·커밋·분모 대조 | 완료 | 새 분석이 생기면 해당 수치만 같은 방식으로 갱신 |
| 공식 6항목·하위항목 원고·표·캡션 | 항목 대응과 본문 수정 완료 | 공식 HWPX 편집 단계에서 지면·가독성 확인 |
| 웹 제작 이유·지속 활용·API/배포조건 | 원고 반영 | 실무 사용자 평가·운영 협의는 후속, 완료실적으로 쓰지 않음 |
| 본문 별도 검토·수정 | 공식 하위 요구·논리·근거의 독립 검토, 3문서 번호·표·폼 항목 검사 수행 | 최종 HWPX 편집 후 쪽수·가독성 별도 검증 |
| 보고서 HWPX·PDF | **미제작** | 표지제외10쪽·표그림가독성 렌더링검증 |
| 1장시각화 PDF | **구성·문안만 작성** | 벡터편집·1쪽출력·인쇄가독성검증 |
| 실제활용데이터 제출패키지 | **미제작** | 현재 사용목록기준 파일선정·명세·압축크기·해제검증 |
| 주요 ZIP | **미제작** | 필수4종준비 후 정확한ZIP명·1GB이하 확인 |

| 폼 실화면·첨부·동의·제출 | **미수행** | 사용자가 실제화면과내용을 최종확인·직접제출 |

이번 원고의 분석은 완료된 기존 결과에 근거한다. 후속 시범 운영·API 개발·효과 평가는 제안의 적용 조건과 평가 설계이며, 접수 후에야 이번 분석을 완료하겠다는 일정이 아니다.
