## 스크립트 규약

예: `analysis/01_신고시공간/01_동별시간집계.py`. 아직 구현된 스크립트가 아니라 이름 예시다.
최종 그림과 웹 데이터는 노트북이 아닌 재현 가능한 스크립트로 만든다.

```python
import sys, pathlib
sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1]))
from style import setup, save, source, choropleth, C, SEQ
ROOT = pathlib.Path(__file__).resolve().parents[2]
setup()
```

경로는 `__file__` 기준으로 잡는다. 실행은 `.venv/bin/python` 또는 Windows `.venv/Scripts/python.exe`를 사용한다.

## 결합·해석

- 위경도 → 행정동, 발생일시 → 시간·계절. 좌표계·부산 경계·경계 위 점·실패 건수를 검증한다.
- 지역 결합은 행정동 코드와 기준기간으로 한다. 한 동의 연령별 행과 업종별 행을 그대로 다대다 결합해 신고 건수를 증식시키지 않는다. 축별 집계표를 별도로 만든다.
- 동별 인구와 상권은 지역 설명변수다. 신고 당사자의 연령, 개별 업소 사건, 인과효과로 바꾸지 않는다.
- 신고·출동·사건, 결측·0, 최신 상권 스냅샷·과거 상권을 구분한다.
- 검증은 마지막 단계에서만 하지 않는다. 모든 집계·결합에서 입력·출력 행 수와 제외 건수를 남긴다.
